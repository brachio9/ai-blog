Rules

지킬 것

  • radius 는 0 이다. 태그 칩만 2px. 지면에는 둥근 모서리가 없다.
  • 그림자는 없다. --shadow-lg 는 다이얼로그 하나에만 쓴다. 지면은 떠 있지 않다.
  • 섹션은 카드로 감싸지 않는다. 여백과 얇은 선이 나눈다.
  • 가운데 정렬 히어로를 만들지 않는다. 첫 화면은 마스트헤드 한 덩이와 곧바로 목록이다.

피할 것 — 둥근 사각형 카드 격자, 유리(backdrop blur), 네온 글로우, 보라·인디고 그라디언트, 가운데 정렬 히어로, 이모지 아이콘. 전부 "자동으로 만들어진 화면"의 표식이다.
