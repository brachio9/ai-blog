Rules

지킬 것

  • 글꼴 이름을 직접 쓰지 않는다. var(--font-heading) · var(--font-body) · var(--font-ui) · var(--font-mono) 뿐이다.
  • mono 자리에 한글을 넣지 않는다. 날짜·식별자·수치·도메인만.
  • UI 산세리프는 작은 라벨에만. 본문을 산세리프로 돌리지 않는다 — 명조가 이 사이트의 목소리다.
  • 제목에 letter-spacing 을 더 손대지 않는다. 스케일에 이미 -0.015em 이 들어 있다.
