# PRD: AI 동향 블로그

## 목표

HuggingFace 블로그·arXiv 논문 등 영문 AI 최신 동향을 한글 요약으로 정리해 공개하는 1인 운영 블로그.

## 사용자

- **독자** (외부 공개): AI 기술 동향을 한글로 빠르게 훑고 싶은 개발자·연구자. 로그인 없이 열람, GitHub 계정으로 댓글.
- **운영자** (1명): 글을 작성·발행·수정한다. GitHub OAuth 로그인.

## 카테고리

설정 파일로 데이터화한다. 카테고리 추가는 설정 수정만으로 되어야 한다.

| slug | 이름 | 성격 |
|---|---|---|
| `hf-blog` | 허깅페이스 소식 | HF 블로그 글 요약 + 원문 링크 |
| `papers` | 최신 논문 | arXiv 논문 리뷰. 수식·도표 비중 높음 |
| `notes` | 수집 자료 | 개인 스크랩·메모 |

## 핵심 기능

**공개**
1. Intro — 임팩트 히어로 + 카테고리별 최신글
2. 카테고리별 목록 (페이지네이션·태그 필터)
3. 글 상세 — TOC, 출처·라이선스 표기, 읽기 시간, 이전/다음
4. 본문 표현 — 수식(KaTeX) · 차트(Recharts) · 다이어그램(Mermaid) · 고급 표 · 이미지(캡션·확대)
5. 검색(클라이언트), RSS, sitemap, OG 이미지
6. 댓글(Giscus), 조회수

**관리자** (`/admin`, 로그인 필수)
7. 글 목록 대시보드 (발행/초안, 조회수)
8. MDX 에디터 + 실시간 프리뷰
9. GitHub 커밋으로 발행 → Vercel 자동 재배포
10. 이미지 업로드 (Cloudflare R2)

## MVP 제외 사항

- HuggingFace/arXiv **자동 수집** — 별도 phase
- Claude API 자동 요약·번역 생성 — 별도 phase
- 다중 저자 / 권한 등급
- 뉴스레터·이메일 발송
- 다국어 (한글 전용)
- 유료화·광고 (Vercel Hobby 약관상 불가)
