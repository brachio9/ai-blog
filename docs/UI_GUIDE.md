# UI 디자인 가이드

「초록」— 영문 AI 원문을 한글로 **추려 적는** 사이트. 화면은 **편집된 지면**이어야 하고 개인 블로그 템플릿처럼 보이면 안 된다.

## 정본은 `design/` 이다

디자인 시스템 **「초록 Chorok」** 이 정본이고 코드가 따라온다. 이 문서는 그 요약이며, 값이 갈리면 `design/` 이 이긴다.

| 파일 | 무엇 |
|---|---|
| `design/brief.md` | **새 화면을 설계하기 전에 읽어라.** 계보·독자·재료 상자·긴장 축·시그니처·파격 예산·빈칸·실패 신호 |
| `design/styles.css` | **토큰의 정본.** 색·활자·간격·치수 |
| `design/readme.md` | 손잡이 표와 이미 만들어져 있는 클래스 목록 |
| `design/foundations/*.html` · `design/components/*.html` | 실제 크기 프리뷰. 어떻게 생겨야 하는지는 여기를 봐라 |

**앱은 값을 복제하지 않는다.** `globals.css` 는 `design/styles.css` 의 토큰 블록을 옮겨 담는 곳이고,
컴포넌트에서 hex·글꼴 이름·px 리터럴이 발견되면 그건 고쳐야 할 결함이다.

## 계보 — 신문 지면

학술지도, 블로그 템플릿도, 대시보드도 아니다. 물려받는 것: **급(級)이 뚜렷할 것** · 굵은선/얇은선 쌍 ·
마스트헤드 · 데이트라인 · 표제/부제/리드 3단 · 단신 묶음 · 색인.
물려받지 않는 것: 종이 질감·접힘 같은 **스큐어모프**, 신문의 다급함(빨강 속보·감탄부호).

## 불변 넷

이것만 지키면 무엇을 해도 「초록」이다. **나머지는 전부 열려 있다.**

1. **두 목소리** — 옮겨 적은 한글은 명조, 남겨 둔 원문(날짜·식별자·도메인·수치)은 mono. 섞지 않는다.
   mono 자리에 한글을 넣지 마라. 이유: IBM Plex Mono 에 한글이 없어 폴백으로 샌다.
2. **안료 팔레트** — 낮은 채도, OKLCH 공통 명도 척도. 형광·그라디언트·발광 없음.
3. **손으로 정한 척도** — 간격이 8의 배수가 아니다. 눈으로 정한 값이라는 뜻이니 "정리"하지 마라.
4. **떠 있지 않은 지면** — 그림자로 높이를 만들지 않는다. 다이얼로그·팝오버만 예외.

## 시그니처 셋

1. **두 목소리** (위 불변과 같다)
2. **추린 비율** — 원문을 몇 분의 일로 줄였는지. 목록에서는 데이트라인 안의 한 조각(`.ratio`),
   기사면에서는 확장형(`.ratio-scale`)을 **한 번만**. 데이터는 frontmatter `source.words`.
3. **1면 편집** — 머리기사 하나 + 단신 묶음. **지면당 머리기사는 하나.** 둘이 되면 편집이 아니라 나열이다.
   선정은 frontmatter `lead` 이고, 없으면 가장 최근 글이 자동으로 머리기사가 된다.

## 분류 축은 셋이고 색을 쓰는 것은 하나뿐이다

| 축 | 부호 | 목록 항목에 싣는가 |
|---|---|---|
| **주제** (`axis`, 6개) | **번호(mono `01`~`06`)** — 색 없음 | **아니다** |
| **소스** (`category`, **5개**) | **안료 3색 + 먹 2단계** | 그렇다 (구분 라벨) |
| **포맷** (`format`, 5개) | 없음 | 아니다 |

**카테고리 5칸의 부호** (2026-08-15 개편):

| 카테고리 | 부호 | 왜 |
|---|---|---|
| `papers` 논문 | 草綠 `--color-accent` | |
| `releases` 릴리즈 | 朱土 `--color-accent-2` | |
| `news` 소식 | 藍 `--color-accent-3` | |
| `community` 커뮤니티 | **먹 中** `--color-neutral-600` | 원문이 여럿이라 하나를 가리킬 수 없다 |
| `notes` 기록 | **먹 濃** `--color-neutral-800` | 옮길 원문이 아예 없다 |

**먹 2칸이 곧 정보다.** 네 번째·다섯 번째 안료를 만들지 않은 것은 타협이 아니라 부호 선택이다 —
남은 hue 는 종이 바탕(hue 85)에 묻히는 황토와 위에서 금지한 보라뿐이고,
**색을 안 쓰는 것이 「출처가 하나가 아니다」를 정확히 말한다.**

**축에 안료를 주지 마라.** 안료와 먹은 카테고리 전용으로 예약돼 있다.
새 이름으로 `text-cat-xxx` 를 쓰면 Tailwind v4 가 `@theme` 에 없는 클래스를 안 만들어 **조용히 무색**이 된다.

축은 번호로 부호화한다. `01`~`06` 은 `.voice-source`(mono·tabular)에 정확히 맞아 **불변 1(두 목소리)을 오히려 강화한다.**

**목록 항목(`PostTable`·`PostBrief`·`PostIndexRow`)에는 축을 싣지 않는다.** 카테고리 라벨과 축 라벨이
나란히 서면 제목의 왼쪽 끝이 흔들린다 — blog-7 이 실측으로 잡은 문제다.

## 파격 예산 — 대담하게

**화면마다 다른 시도를 해도 된다.** 홈(1면)과 글 상세(기사면)가 꽤 달라 보여야 정상이다.
표제를 스케일 밖으로 키우거나, 한 화면만 단을 다르게 잡거나, 한 곳에서만 안료를 크게 쓰는 것 — 전부 허용된다.
다만 파격은 **의도한 자리에** 둔다. 화면 전체가 파격이면 그냥 무질서다.

> 옛 지침의 "모든 목록 행 높이가 같아야 한다"는 **폐기됐다.** 무엇을 얼마나 크게 싣는지가 편집이다.
> 대신 지켜야 할 것은 **제목의 왼쪽 끝이 흔들리지 않는 것**(레일 폭 고정)이다.

## 읽는 사람 셋

정독자는 주 대상이 **아니다.** 예산을 본문 조판이 아니라 **훑기와 찾기**에 쓴다.

| 누구 | 화면에 필요한 것 |
|---|---|
| 매일 훑는 단골 | 급이 뚜렷한 1면 · 10초 안에 "오늘 새것" 판단 |
| 검색으로 한 번 오는 사람 | 글 하나의 완결성 · 원문 링크 · "여긴 뭐 하는 곳인가" 5초 안에 |
| 나 자신 (기록용) | 색인 · 아카이브 · 태그 · 훑어서 되찾기 |

## 실패 신호

미학이 아니라 목표다. 수단은 발명하라.

- 원문 링크를 못 찾으면 **실패** (출처 표기는 `CLAUDE.md` 의 CRITICAL 규칙이다)
- 단골이 10초 안에 "오늘 새 글"을 못 고르면 **실패**
- 검색 유입자가 5초 안에 "여기가 뭐 하는 곳인지" 모르면 **실패**
- 6개월 전 글을 30초 안에 못 찾으면 **실패**
- 두 화면을 나란히 놨는데 구분이 안 되면 **실패** — 파격 예산을 안 쓴 것이다

## AI스러움 — 목록이 아니라 진단

금지 목록으로 막지 않는다. 목록은 늘 새 유형에 뚫린다.

AI스러움은 특정 색이나 모양이 아니라 **결정을 회피한 흔적**이다. 모든 카드가 같은 높이인 것은 무엇이 더
중요한지 정하지 않았다는 뜻이고, 모든 여백이 8의 배수인 것은 눈으로 보지 않았다는 뜻이고, 가운데 정렬은
어디에 무게를 둘지 고르지 않았다는 뜻이다.

> **이 화면에서 내가 내린 결정이 무엇인가?**

답할 수 있으면 통과다. 답이 "기본값을 썼다"뿐이면 그게 AI스러운 화면이다.

그래도 아래 것들은 위 진단을 거의 항상 실패하므로 손대지 마라: backdrop-filter blur · 그라디언트 텍스트 ·
글로우 애니메이션 · 보라/인디고 브랜드색 · 배경 gradient orb · 이모지 아이콘 · 스크롤 트리거 등장 애니메이션 ·
아이콘 라이브러리 도입(lucide·heroicons — 그 기본 룩 자체가 템플릿 신호다).

## 한글 조판 (필수)

```css
word-break: keep-all;      /* 단어 중간에서 끊지 않는다 */
overflow-wrap: break-word; /* 긴 URL 은 예외적으로 끊는다 */
```

`word-break: normal` 이면 제목이 "…한 / 글로" 처럼 끊긴다. **전역에 적용한다.**
단, `.voice-source`(mono 메타)에는 `overflow-wrap: normal` 로 되돌린다 —
`arXiv:2608.01337` 이 `arXiv:2608.01` / `337` 로 쪼개지면 안 된다. **실측으로 확인한 결함이다.**

한글 명조는 같은 px 에서 산세리프보다 작아 보인다. 본문 16.5px · 행간 1.85 는 그래서 정한 값이다.
표의 날짜·숫자에는 `font-variant-numeric: tabular-nums`.

## 폰트

`next/font/google` 로 self-host 한다. **`korean` 서브셋은 존재하지 않는다** — `subsets:["latin"]` 만 지정해도
CSS 에 한글 유니코드 범위가 들어가고 한글은 정상 서빙된다. `korean` 을 넣으면 컴파일 에러다.

| 역할 | 폰트 |
|---|---|
| 제목·본문 (`--font-heading` / `--font-body`) | **Noto Serif KR** |
| 작은 한글 라벨·태그·버튼 (`--font-ui`) | **IBM Plex Sans KR** |
| 날짜·식별자·수치·도메인 (`--font-mono`) | **IBM Plex Mono** — 한글 없음 |

글꼴 이름을 컴포넌트에 직접 쓰지 마라. 토큰만 쓴다.

## ⚠ 런타임 JS 에서 색을 읽을 때 (Recharts·Mermaid)

토큰은 두 겹으로 존재한다. **런타임에는 원시 변수를 읽어라.**

| 계층 | 이름 | 런타임 조회 |
|---|---|---|
| 원시 (`:root` / `.dark`) | `--chart-1` · `--color-accent` … | **항상 가능** |
| Tailwind 노출 (`@theme inline`) | `--color-chart-1` … | 마크업에서 그 유틸리티를 실제로 쓸 때만 존재 |

Tailwind v4 는 **사용되지 않는 `@theme` 변수를 빌드에서 제거한다.** 없는 변수를 받은 Recharts 는
경고도 빌드 실패도 없이 **그냥 검정으로 칠한다.**

**`--chart-1` … `--chart-5` 라는 이름을 바꾸지 마라.** `src/components/mdx/Chart.tsx` 가 이 이름으로 읽는다.

## 레이아웃

- 지면 컨테이너 `--page-max` (1080px) · 본문 폭 `--measure` (68ch) · 좌측 메타 레일 `--rail` (136px)
- **좌측 정렬이 기본이다.** 가운데 정렬 히어로를 만들지 마라 — 첫 화면은 마스트헤드 한 덩이와 곧바로 목록이다
- 남는 오른쪽 여백은 비워 둔다. 채우지 않는다
- 640px 아래에서 레일은 본문 위로 접힌다. **목록에서 가로 스크롤 금지** (표·차트·코드블록은 자체 스크롤 허용)

## 애니메이션

- **허용**: `transition-colors` / `transition-opacity` 150ms.
- **그 외 전부 금지.** 스크롤 트리거, transform 확대·이동, 무한 루프, glow, 패럴랙스.
- `prefers-reduced-motion` 을 존중한다.

## 아이콘

- **`src/components/ui/icons.tsx` 하나에 모아 둔다.** 파일마다 인라인 SVG 를 새로 그리지 마라.
- 헤어라인 1.25px, 끝을 자른 획(butt), 채우기 없음, `currentColor`.
- 둥근 배경 박스로 감싸지 마라. 이모지를 아이콘 대용으로 쓰지 마라.

## 접근성

- 본문 대비 최소 4.5:1, 큰 텍스트 3:1. **안료를 텍스트로 쓸 때도 지켜야 한다** —
  안료-바탕 대비는 아이콘·굵은 글자·인터페이스 요소 기준이라 본문 크기 글자에 그대로 쓰면 안 된다.
  본문 크기에는 깊은 단계(낮 바탕 `--color-accent-700`)를 써라.
- 포커스 링을 지우지 마라 — `:focus-visible { outline: 2px solid var(--color-accent); outline-offset: 3px; }`
- 색만으로 정보를 전달하지 마라. 카테고리는 색 **과 함께** 라벨을 붙인다.
- 표에 `<caption>` 또는 `aria-label`. 차트에 텍스트 요약 또는 원본 표 병기.

## 본문 요소

| 요소 | 규격 |
|---|---|
| **표** | `overflow-x-auto` 로 감싼다. 좁은 화면에서 표만 스크롤되고 페이지는 밀리지 않는다 |
| **이미지** | `<figure>` + `<figcaption>`. `next/image` + `alt` 필수 |
| **차트** | 축·격자선은 `--color-line`, 라벨은 `--color-muted`. 다크에서 자동 전환 |
| **다이어그램** | Mermaid 테마를 CSS 변수에 맞춰 라이트/다크 각각 설정. 배경 투명 |
| **수식** | KaTeX. 별행 수식은 넘칠 때 자체 가로 스크롤 |
| **코드블록** | 이중 테마(단일 테마는 색이 인라인으로 박혀 다크 전환이 안 된다) + 복사 버튼 |
| **콜아웃** | 좌측 보더 + 안료. 아이콘은 인라인 SVG |
