모바일 앱을 스토어에 올릴 때 가장 번거로운 작업 중 하나는 등록용 이미지 준비다. 시뮬레이터를 띄워 화면을 하나씩 캡처하고 디자인 도구에서 기기 테두리와 배경, 문구를 입히며 언어별로 반복해야 한다. 화면이 조금만 바뀌어도 이 과정을 처음부터 다시 해야 하므로 릴리스 때마다 미루기 쉬운 작업이다.

Goldie는 이러한 과정을 명령 하나로 처리하는 CLI 도구다. Software Mansion이 만든 argent를 활용해 iOS 시뮬레이터나 안드로이드 에뮬레이터에서 사용자 흐름을 재생하고 화면을 자동으로 캡처한다. 이후 Goldie가 캡처된 화면에 기기 테두리와 배경, 헤드라인을 입히고 클립을 이어 붙여 미리보기 영상을 만든다. SwiftUI, Flutter, React Native 등 프레임워크를 가리지 않고 동작하며 완성된 결과물이 스토어 규격에 맞는지 검사한다.

이 도구는 코딩 에이전트와 함께 쓰도록 설계되었다. 저장소에서 'create app store screenshots using goldie'라고 요청하면 에이전트가 목표 스토어를 확인하고 앱을 탐색해 설정 파일을 작성한다. 이후 '배경을 어둡게 바꿔 줘' 같은 후속 요청도 동일한 파일을 수정하는 방식으로 반영된다. 프로젝트 이름과 달리 명령어와 패키지명은 모두 소문자 goldie로 표기한다.

기존 방식이나 다른 도구와의 비교에서 Goldie의 특징이 드러난다. ASO App Store Screenshots 같은 도구는 코드베이스 분석과 이미지 생성 모델을 활용해 화면을 다듬는 반면, Goldie는 실제로 동작하는 앱을 재생해 화면을 얻고 스토어 규격 검증까지 책임진다. 이미지 자체를 생성 모델로 꾸미지 않으므로 실제 앱의 모습을 정확히 반영하고자 할 때 유용하다.
