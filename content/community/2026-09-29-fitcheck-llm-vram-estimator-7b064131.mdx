대형 언어모델을 학습하거나 서비스할 때 가장 먼저 걱정되는 것은 GPU 메모리가 부족하지 않은가 하는 점이다. FitCheck는 이 질문에 답하기 위해 개발된 도구로, LoRA나 QLoRA 같은 파인튜닝 방식은 물론 전체 파인튜닝까지 포괄해 피크 VRAM 사용량을 추정한다. 모델 가중치를 다운로드하거나 PyTorch 및 CUDA 환경을 구축할 필요 없이 Hugging Face의 config.json과 메타데이터만 읽으면 되므로 별도의 GPU 없이도 용량 체크가 가능하다.

이 도구는 메모리 사용 내역을 상세히 보여주며, 사용 가능한 GPU 용량 대비 여유 공간(headroom)과 적합성 판단 결과를 제공한다. 특히 추론(serving) 환경에서는 모델 가중치와 KV 캐시를 고려한 추정치를 산출하고, 배치 크기나 시퀀스 길이, LoRA 랭크 등을 조정하며 최적의 설정을 탐색하는 어드바이저 기능도 지원한다. 이를 통해 실제 실행 전 어떤 미세배치 크기가 GPU에 들어갈 수 있는지 미리 파악할 수 있다.

글쓴이는 Tesla T4 단일 GPU를 대상으로 57회의 교정 및 반복 실험을 진행해 추정치의 정확도를 검증했다고 주장한다. 그 결과 전체 프로세스 추정치의 평균 절대 오차는 2.4%로 나타났으며, 최악의 경우 절대 오차는 13.9%였다. 별도의 홀드아웃 테스트에서는 평균 절대 오차가 5.4%였고, 적합성 경계 판단은 12회 중 12회 모두 정확히 맞았다. 다만 이 수치는 특정 GPU 환경에서의 결과이므로 보편적인 정확도 보장으로 해석하기는 어렵다.

FitCheck는 OOM 오류를 완벽하게 막아주는 보증서가 아니라 용량 산정 도구임을 명시한다. 현재 Hugging Face Space와 GitHub에서 공개되어 있으며 pip install fitcheck-llm 명령어로 설치할 수 있다. 작성자는 결과의 가독성, 추가 테스트가 필요한 모델 구성, 실제 측정치와의 일치 여부 등에 대한 피드백을 요청하며 추정치의 오차를 줄이고 재현 가능한 측정을 통해 도구를 개선해 나간다는 목표를 밝혔다.
