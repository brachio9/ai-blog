로컬에서 대규모 언어 모델을 실행하려 할 때 가장 큰 장벽은 내 컴퓨터의 성능에 맞는 모델을 찾는 것이다. 모델 카드만으로는 메모리 요구량을 정확히 알 수 없어, 수 GB짜리 파일을 다운로드한 후 실행해야 비로소 속도가 느리거나 메모리가 부족하다는 사실을 알게 되는 경우가 많다. 이러한 시행착오를 줄이기 위해 작성자가 소개한 llmfit는 터미널 기반 도구로, 사용자의 CPU 코어 수와 RAM, GPU 및 VRAM 용량 등을 자동으로 감지한다.

llmfit는 내장된 카탈로그에 있는 수백 개 모델을 품질, 속도, 적합도, 컨텍스트 길이 네 가지 기준으로 점수화해 표로 정리한다. 각 모델이 현재 환경에서 어떤 양자화 수준으로 실행 가능한지, 예상 초당 토큰 생성 속도는 얼마인지, 메모리 사용률은 몇 퍼센트인지를 한눈에 볼 수 있다. 특히 속도 수치 중 공식 계산치와 동일 하드웨어에서의 실제 측정치를 등급으로 구분해 표시하므로, 신뢰도에 따라 모델을 선택하는 데 도움이 된다.

이 도구는 Rust로 작성되어 의존성 없이 가볍게 실행되며, 대화형 터미널 UI와 CLI, JSON 출력 모드를 제공한다. Ollama나 llama.cpp, LM Studio 등 로컬 런타임 제공자를 자동으로 감지해 이미 설치된 모델을 표시하거나 새 모델 다운로드를 바로 연결할 수 있다. 또한 llmfit serve 명령을 통해 REST API 서버를 실행해 클러스터 스케줄러나 대시보드에서 노드 정보를 읽어갈 수도 있다.
