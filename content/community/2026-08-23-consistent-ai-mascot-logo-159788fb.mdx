이미지 생성 모델로 회사 마스코트를 만들어 본 경험자라면 알겠지만, 진짜 문제는 생성 품질이 아니라 일관성이다. 같은 프롬프트를 입력해도 디테일 과잉이나 구도 흔들림이 발생하며 로고에 필요한 단순한 실루엣과 제한된 색상 적용이 매번 달라진다. 따라서 더 좋은 모델보다는 생성 모델에게 마스코트 로고의 제약을 일관되게 강제하는 지침이 필요하다.

s1dashu가 소개한 IP as Logo는 이러한 지침을 하나의 에이전트 스킬로 압축한 프로젝트다. 이 스킬은 사랑스러운 캐릭터 매력, 굵고 둥근 실루엣, 엄격한 복잡도 제한, 하단 중심 구도, 단색 배경 등을 우선하도록 설계되어 있다. 특정 에이전트 제품에 종속되지 않으며, 본체는 지침 문서인 SKILL.md 하나로 구성되어 있어 별도 설치나 스크립트 실행 없이 이미지 생성 기능이 있는 에이전트와 함께 사용할 수 있다.

이 스킬의 핵심은 모델에게 무엇을 그리라고 시키는 대신 무엇을 못 하게 막는 규칙 목록이다. 대략 4~7개의 큰 기본 도형으로 이루어진 지배적인 실루엣 하나만 그리도록 하고, 날카롭거나 부서지기 쉬운 디테일 없이 두껍고 둥근 형태를 유지하게 한다. 또한 기본값으로 IP 본체 색 2가지와 배경색 1가지 등 총 3가지 의미 색상만 사용하도록 제한한다.

사이드 프로젝트나 초기 제품에 붙일 마스코트가 필요하고 이미 이미지 생성 에이전트를 사용하고 있다면 시도해 볼 만하다. 하지만 벡터 원본이 필요한 브랜드 작업이나 인쇄용 로고 시스템에는 적합하지 않다. 결과물이 래스터 이미지이며, 이미지 생성 모델의 확률적 특성상 같은 요청도 매번 다르게 나오는 것을 의도적으로 걸러내지 않기 때문이다.
