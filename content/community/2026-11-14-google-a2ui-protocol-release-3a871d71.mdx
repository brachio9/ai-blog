Google A2UI 팀은 에이전트와 사용자 간의 상호작용을 개선하기 위한 오픈 프로토콜 A2UI 1.0을 발표했다. 기존의 텍스트 기반 에이전트 방식은 복잡한 계획 승인이나 상품 비교 작업에서 한계가 명확했다. A2UI는 에이전트가 화면을 어떻게 보여줄지 JSON 메시지로 설명하고, 앱이 등록된 카탈로그를 통해 이를 실제 화면으로 렌더링하는 구조를 제안한다.

이번 1.0 버전에서는 양방향 함수 호출과 한 화면 내 여러 카탈로그 혼용 기능이 추가되었으며, 단 한 번의 호출로 화면을 구성하는 방식이 도입되었다. Google은 자체 평가를 통해 A2UI Express라는 압축 문법이 기존 JSON 방식보다 입력 토큰을 45.4%, 생성 코드 토큰을 63.2% 줄이면서도 동일한 정확도를 유지한다는 점을 강조했다.

기술적 지원 측면에서 A2UI 1.0은 React, Angular, Lit, Flutter, SwiftUI를 지원하며, Jetpack Compose는 아직 이전 버전을 지원하는 상태다. 현재 프로토콜은 공개되었으나 실제 배포되는 패키지 버전은 0.x 단계에 머물러 있다. 개발자들은 Apache 2.0 라이선스로 공개된 저장소를 통해 프로토콜 명세와 SDK를 확인할 수 있다.
