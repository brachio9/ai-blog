LLM 모델을 서버에 배포한 후 응답 속도를 측정하려 할 때 개발자들은 주로 curl이나 간단한 파이썬 스크립트를 사용한다. NVIDIA 기술 블로그에 따르면 이러한 방식은 단일 프로세스의 한계나 파이썬의 전역 인터프리터 잠금(GIL)으로 인해 신뢰할 수 없는 결과를 초래한다. 특히 LLM 추론은 긴 스트리밍 응답을 처리해야 하므로 부하 생성기가 서버보다 먼저 병목이 되면 측정값이 왜곡된다.

AIPerf는 NVIDIA가 이러한 문제를 해결하기 위해 개발한 전용 벤치마크 도구다. 기존 Triton Inference Server의 GenAI-Perf를 계승하며 독립된 저장소로 관리되고 Apache License 2.0으로 공개되어 있다. 이 도구는 클라이언트 측의 처리 능력에 구애받지 않도록 설계되어 서버의 실제 성능을 정확히 반영하는 측정값을 제공한다.

NVIDIA는 AIPerf가 부하 생성기 자체의 성능 한계로 인한 오류를 제거한다고 주장한다. 이를 통해 개발자들은 GPU 추가 구매 등 중요한 인프라 결정을 내릴 때 신뢰할 수 있는 데이터를 기반으로 판단할 수 있다. 원문 저자들에 따르면 이 도구는 복잡한 LLM 추론 환경에서의 정확한 성능 측정을 위해 필수적인 요소로 자리 잡을 것이다.
