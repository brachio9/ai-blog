옷장 정리를 위해 사진 속 옷을 일일이 손으로 자르는 작업은 번거롭고 지루하다. tandpfun이 공개한 Wardrobe는 이 과정을 자동화하는 도구로, OpenAI API를 활용해 사진 속 옷을 검출하고 배경과 착용자를 제거한 깔끔한 컷아웃을 만들어준다. 필요시 참조 이미지를 넣어 그 옷을 입은 듯한 편집 화보풍 이미지까지 생성할 수 있어 개인용 카탈로그 제작에 유용하다.

이 프로젝트는 React와 Vite로 구축된 단일 페이지 앱에 Node 스크립트를 결합한 구조다. 별도의 데이터베이스 설치나 계정 생성 없이 로컬에서 바로 실행 가능하며, 처리된 원본과 결과물, JSON 데이터베이스는 모두 프로젝트 폴더 내 data 디렉토리에 저장된다. 다만 옷 검출 및 이미지 생성 과정은 OpenAI 서버를 거치므로 사진이 외부로 전송됨을 유의해야 한다.

처리 과정은 크게 네 단계로 나뉜다. 먼저 OpenAI Responses API가 사진에서 옷 아이템을 하나씩 찾아내고, 이어 OpenAI Images API가 배경을 제거한 컷아웃을 생성한다. 이후 선택적으로 참조 이미지를 기반으로 착용 컷을 만들 수 있으며, 모든 작업 기록과 생성된 이미지는 로컬에 보관된다.

실행에는 Node 22 이상이 필요하며, MIT 라이선스로 공개되어 있다. 유료 요금제나 관리형 서비스는 제공하지 않고, 사용자는 자신의 OpenAI API 키를 등록해 발생하는 비용을 직접 부담한다. 환경 변수를 통해 사용할 모델과 경로를 유연하게 설정할 수 있어 다양한 용도에 맞게 조정 가능하다.
