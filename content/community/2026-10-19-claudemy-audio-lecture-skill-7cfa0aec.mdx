새로운 주제를 배울 때 수십 시간짜리 강좌를 듣기 부담스럽고, LLM에게 직접 가르쳐 달라고 하면 근거 없는 정보가 섞일 수 있다는 점을 문제의 출발점으로 삼은 Assaf Kipnis는 Claudemy를 만들었습니다. 이 Claude Code 스킬은 `teach me <주제>`라는 한 줄 명령으로 작동하며, 웹 페이지 20~40개를 조사해 2분 안팎의 2인 대화형 오디오 강의 약 12개와 함께 강의 카드 및 규칙 파일을 생성합니다. 개발자는 첫 테스트에서 검색 모델이 추천한 URL 중 상당수가 죽은 링크였음을 확인하고, 이를 해결하기 위해 실제 존재하는 페이지만 근거로 삼는 검증 과정을 도입했습니다.

Claudemy는 주제를 하위 주제로 나누고 공식 문서나 연구 요약 등 다양한 출처를 수집한 후, 여러 에이전트가 페이지를 나눠 읽으며 인용이 달린 노트를 만듭니다. 이후 다른 에이전트가 이 노트들을 주제별로 묶어 각 아이디어에 대해 몇 개의 출처가 동의하는지 집계합니다. 이렇게 생성된 강의 계획에는 전문가들의 의견이 갈리는 지점도 별도 항목으로 정리되며, 첫 번째 강의를 먼저 만들어 사용자의 반응을 들은 뒤에 나머지 내용을 작성하고 녹음하는 방식으로 진행됩니다.

생성된 결과물은 MP3 파일과 마크다운 카드, 규칙 모음 파일로 구성되며, 음성은 ElevenLabs API 키가 있으면 해당 서비스를, 없으면 macOS 내장 음성을 사용합니다. 다만 현재 Claudemy는 언어 설정 항목이 없고 대본 분량 검사나 금지 표현 목록이 영어 기준이라, 한국어 강의를 원하면 음성과 검사 기준을 직접 조정해야 합니다. 또한 인용 검사기는 URL이 저장되어 있는지만 확인할 뿐, 해당 페이지가 강의의 주장을 실제로 뒷받침하는지는 검증하지 않는 한계가 있습니다.

이 프로젝트는 소규모 사업체 자동화 점검을 컨설팅하는 Assaf Kipnis의 개인 작업이며, 데모에서 보이는 웹 앱 인터페이스는 Claudemy 스킬의 일부가 아닌 별도로 제작된 Base44 앱입니다. 따라서 Claudemy를 사용하면 MP3 파일과 마크다운 파일을 받아 일반 플레이어나 에디터로 내용을 확인하게 됩니다. 이 도구는 복잡한 설정 없이 주제 하나만으로 구조화된 학습 자료를 빠르게 얻을 수 있게 해주지만, 아직은 영어 중심의 검증 로직을 가지고 있어 한국어 환경에서의 활용도를 높이기 위해서는 사용자의 추가적인 튜닝이 필요합니다.
