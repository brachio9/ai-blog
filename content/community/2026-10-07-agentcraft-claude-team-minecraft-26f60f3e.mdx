여러 코딩 에이전트를 동시에 실행할 때 터미널 로그만으로는 각 에이전트의 진행 상황이나 막힌 지점을 파악하기 어렵다는 문제의식에서 출발한 AgentCraft는 마인크래프트: 자바 에디션 내의 Fabric 모드와 노드 기반 오케스트레이터로 구성된다. 작성자 블렌디는 이 프로젝트를 통해 사용자가 게임 속 사무실 공간에 들어가 에이전트들이 각자의 책상에서 어떤 파일을 읽고 수정하는지 실시간으로 지켜볼 수 있게 했으며, 필요시 에이전트가 사용자에게 직접 걸어와 질문을 던지는 인터랙션을 구현했다.

작업 흐름은 리드 에이전트가 목표를 분석해 작업 카드를 생성하고, 작업자 에이전트들이 별도의 깃 워크트리에서 코드를 작성하는 방식으로 진행된다. 이때 에이전트의 깃 푸시 명령이나 외부 네트워크 접근, 파일 쓰기 권한 등은 게임 내 시스템에 의해 차단되며, 모든 변경 사항은 사용자의 명시적 승인을 기다린다. 즉 사용자가 게임 내 리뷰 화면에서 병합 버튼을 누르기 전까지는 어떤 코드도 메인 브랜치에 반영되지 않아 안전성을 확보한다.

이 프로젝트는 윈도우나 맥OS 환경에서 자바 25와 노드 22 이상이 필요하며, 마인크래프트 정품 계정과 클로드 API 사용 비용이 발생한다는 점을 고려해야 한다. 현재는 개발용 클라이언트에서만 실행되며 한 사람이 한 대의 컴퓨터에서 테스트하는 단계라고 밝힌 블렌디는 모장이나 마이크로소프트, 앤스로픽과는 무관한 개인 프로젝트임을 강조하고 있다. 에이전트의 실제 코딩 과정을 시각적으로 모니터링하며 인간의 판단을 개입시키는 이 방식은 복잡한 다중 에이전트 협업의 투명성을 높이는 새로운 시도로 평가된다.
