APIGOTO 팀원은 OpenAI 호환 API 게이트웨이를 통해 vLLM이나 Ollama 등 다른 서버도 동일하게 접근 가능하다고 설명한다. 먼저 curl 명령어로 모델 목록을 조회해 정확한 모델 ID를 확인한 후, Python SDK에서 base_url과 api_key 두 줄만 수정하면 연결이 완료된다. 코드 변경 없이 OPENAI_BASE_URL 환경변수를 설정하는 방식도 지원하므로 기존 프로젝트에 쉽게 적용할 수 있다.

동일한 프롬프트로 여러 모델을 비교하려면 max_retries를 0으로 설정해 SDK 재시도가 시간 측정에 영향을 주지 않도록 해야 한다. APIGOTO는 업스트림 실패 시 최대 3회까지 자동으로 다른 경로로 재시도하므로, 특정 모델이 느릴 경우 요청 로그에서 재시도 여부를 먼저 확인해야 한다. 단회 실행 결과는 신뢰할 수 없으므로 여러 번 반복해 중앙값을 산출하는 것이 정확하며, temperature를 0으로 해도 출력 결과가 항상 동일하지는 않을 수 있다.

연결 과정에서 흔히 발생하는 오류로는 base_url에 /v1 이후 경로를 중복 입력해 생기는 404 에러와 모델 ID의 대소문자 불일치로 인한 not found 오류가 있다. 인증 실패(401)는 키의 공백 문제나 다른 서비스 키 사용에서 비롯되며, 일부 모델은 max_tokens 대신 max_completion_tokens를 요구할 수 있다. 또한 스트리밍이 아닌 일반 요청 기준에서 usage 정보가 비어 있을 수 있으므로 각 모델의 특성을 고려해 스크립트를 작성해야 한다.
