Claude Code나 Codex, Gemini CLI 같은 코딩 에이전트는 각각 독립적인 터미널 화면(TUI)을 제공해 왔습니다. 이를 Emacs에서 사용하려면 에디터와 에이전트 간 연동을 별도로 구축하거나, 터미널 에뮬레이터 버퍼에 에이전트를 그대로 띄워야 하는 불편함이 있었습니다. Álvaro Ramírez가 개발한 agent-shell은 이러한 문제를 해결하기 위해 Agent Client Protocol(ACP)이라는 공통 프로토콜을 도입했습니다. 이를 통해 서로 다른 코딩 에이전트들을 Emacs의 일반 버퍼 하나로 통합해 동일하게 다룰 수 있게 되었습니다.

agent-shell은 Emacs 내장 comint-mode를 기반으로 구축된 셸 버퍼입니다. 기존 터미널 에뮬레이터처럼 문자 모드와 줄 모드 간 전환이 필요 없으며, 평소 사용하던 버퍼 편집 및 이동 명령을 그대로 적용할 수 있습니다. 에이전트와의 통신은 같은 저자가 만든 acp.el 라이브러리가 담당합니다. 현재 Claude Code, Codex, Gemini CLI를 비롯해 Goose, Cursor, Kimi Code CLI 등 19개 이상의 에이전트를 공식 지원 목록에 포함하고 있어, ACP를 지원하는 대부분의 에이전트를 연결해 사용할 수 있습니다.

사용 인터페이스는 상단 헤더에 현재 실행 중인 에이전트, 모델, 세션 모드, 컨텍스트 사용량 등을 표시합니다. 또한 에이전트가 제공하는 기능과 모델 목록을 접을 수 있는 항목으로 정리해 직관적으로 접근할 수 있게 구성했습니다. 이는 복잡한 터미널 명령어 대신 에디터 환경에 익숙한 방식으로 코딩 에이전트의 기능을 탐색하고 제어할 수 있음을 의미합니다.

이 프로젝트는 Álvaro Ramírez의 개인 개발 작업입니다. 기존 LLM용 Emacs 셸 도구들을 이어받아, 다양한 AI 코딩 도구를 하나의 표준화된 인터페이스로 통합하려는 시도의 일환입니다. 에이전트별 고유한 터미널 경험을 포기하지 않으면서도 에디터 내부에서의 일관된 워크플로우를 원하는 사용자에게 새로운 선택지를 제시합니다.
