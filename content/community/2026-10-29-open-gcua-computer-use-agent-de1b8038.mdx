기존의 컴퓨터 사용 에이전트(CUA)는 화면을 보고 마우스나 키보드 동작을 하나씩 실행하는 방식이었다. 하지만 이러한 방식은 반복적인 작업이 필요한 경우 매번 모델을 다시 호출해야 한다는 한계가 있다. 이에 대응하여 OpenGCUA는 모델이 GUI 조작, 셸 명령, 접근성 트리 활용을 하나의 파이썬 프로그램으로 묶어서 실행하도록 하는 에이전트 하네스와 SDK를 제공한다.

OpenGCUA는 모델이 무엇을 관찰하고 어떻게 행동할지를 스스로 결정하는 구조를 지향한다. 이를 위해 모델이 반복문과 조건문이 포함된 코드를 실행할 수 있게 하고, 스크린샷 확인 시점이나 진행 상황 기록 방식을 하네스의 규칙이 아닌 모델의 선택으로 넘기는 설계를 채택했다. 이는 최근 상용 시스템들이 단순 클릭보다 프로그래밍 방식의 도구 활용을 권장하는 흐름과 궤를 같이한다.

개발팀은 기술 보고서를 통해 모델을 새로 학습하지 않고 하네스만 변경하여 측정한 결과를 발표했다. 개발팀은 OSWorld-v2 오프라인 82개 과제에서 기존 모델 8종의 평균 부분 점수가 45.3점에서 64.9점으로 상승했으며, 과제당 단계 수가 평균 53.0% 줄어들었다고 주장했다. 현재 공개된 자료에는 프롬프트, 참조 에이전트 코드, 8개 모델의 평가 궤적 등이 포함되어 있으며, 학습된 GCUA 모델은 차후 공개될 예정이다.
