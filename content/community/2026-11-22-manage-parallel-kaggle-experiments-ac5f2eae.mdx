연구 팀이 여러 명의 공동 저자와 협업할 때, 각자의 Kaggle 계정에서 노트북을 실행하고 상태를 확인하는 과정은 매우 번거로운 작업이다. 개발자는 이러한 반복적인 수동 작업을 줄이기 위해 KaggleFleet이라는 도구를 개발했다. 이 도구는 여러 계정의 GPU 쿼터를 활용하면서도 연구 워크플로우가 끊기지 않도록 돕는 데 목적이 있다.

KaggleFleet을 사용하면 로컬 환경에서 코드를 편집하고 Git 저장소를 유지하면서도, 명령어를 통해 여러 계정으로 노트북을 동시에 배포할 수 있다. 각 계정은 독립적인 인증 샌드박스에서 실행되므로 데이터가 섞이지 않으며, T4나 P100 같은 가속기 유형을 선택하여 실행 상태와 로그를 실시간으로 추적할 수 있다. 또한 웹 패널을 통해 팀원들의 계정별 GPU 사용량과 작업 상태를 한눈에 파악할 수 있는 기능을 제공한다.

이 도구는 AI 에이전트와의 호환성도 고려하여 설계되었다. 모든 CLI 명령은 JSON 출력을 지원하며, 에이전트용 워크플로우를 위한 문서도 포함되어 있다. 별도의 복잡한 런타임 의존성 없이 공식 Kaggle CLI와 파이썬 표준 라이브러리만으로 작동한다는 점도 특징이다.
