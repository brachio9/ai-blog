코딩 에이전트를 사용할 때 가장 큰 고민 중 하나는 실행 과정의 불투명함이다. 작업이 끝난 후 남는 것은 긴 로그 파일뿐이며, 오류가 발생하면 그 원인을 찾기 위해 수백 줄의 텍스트를 뒤져야 한다. Simon Patole는 AI 게임 제작 플랫폼 개발 과정에서 이러한 디버깅의 번거로움을 해소하기 위해 Agent Flow를 만들었다. 이 도구는 에이전트의 실행 과정을 단순한 로그가 아닌 상호작용 가능한 노드 그래프로 펼쳐 보여준다.

Agent Flow는 Claude Code와 Codex 두 런타임을 동시에 감시하며 각각의 세션을 나란히 표시한다. Claude Code는 경량 HTTP 훅 서버를 통해 이벤트를 직접 수신하는 반면, Codex는 롤아웃 파일을 읽어서 정보를 가져온다. 특히 Codex의 경우 런타임이 집계한 토큰 수와 도구 호출 정보를 그대로 시각화하므로 별도의 추정이 필요 없다. 이러한 구조로 인해 각 에이전트의 실행 흐름과 비용 발생 지점을 명확하게 구분할 수 있다.

화면 중앙에는 실행 중인 에이전트와 하위 에이전트가 노드로 표시되며, 각 노드에는 누적 토큰과 비용이 함께 나타난다. 오른쪽 패널에서는 에이전트별 및 도구별 비용을 세분화하여 보여주며, 아래쪽 타임라인을 통해 전체 실행 과정을 시간축으로 파악할 수 있다. 또한 파일 주목도 히트맵과 메시지 트랜스크립트 패널 등을 제공하여 복잡한 에이전트의 동작을 입체적으로 분석하는 데 도움을 준다.

이 도구는 VS Code 확장으로도 제공되며, 감시할 런타임을 선택적으로 제한할 수 있다. Codex를 기본 경로가 아닌 곳에 설치한 경우 환경 변수 설정을 통해 대응 가능하다. Agent Flow는 에이전트가 문제를 어떻게 쪼개고 어떤 순서로 도구를 호출했는지 시각적으로 드러냄으로써, 개발자가 에이전트의 판단 과정을 더 쉽게 이해하고 디버깅할 수 있도록 지원한다.
