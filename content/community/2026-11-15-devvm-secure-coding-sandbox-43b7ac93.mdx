코딩 에이전트를 로컬 환경에서 실행하면 에이전트가 실행하는 셸 명령이나 패키지 설치가 사용자의 전체 권한으로 실행되는 보안 문제가 발생한다. 특히 프롬프트 인젝션이나 악성 패키지를 통해 홈 폴더의 SSH 키나 다른 프로젝트 파일이 노출될 위험이 있다. 개발자 CJ는 이러한 위험을 방지하기 위해 프로젝트 폴더마다 전용 VM을 할당하여 에이전트와 빌드 과정을 가두는 devvm을 개발했다.

devvm은 Lima를 기반으로 작동하며 프로젝트 폴더만 읽기/쓰기 권한으로 마운트하고 나머지 홈 폴더 영역은 차단한다. 이를 통해 에이전트가 잘못된 명령을 실행하더라도 피해 범위가 해당 VM 내부로 제한된다. 개발자는 프로젝트 폴더 자체는 에이전트가 수정할 수 있으므로 자주 커밋하거나 별도의 클론 모드를 사용할 것을 권장한다.

이 도구는 프로젝트 파일을 분석해 Node.js나 Python 등의 툴체인을 자동으로 구성하며, 공유 도구와 에이전트 설정은 여러 VM이 읽기 전용으로 공유한다. 보안을 위해 GitHub 토큰과 같은 민감한 정보는 호스트에 남겨두고, VM 내부에서는 프록시를 통해 실제 값을 채워 넣는 방식으로 작동한다. 현재 0.1.0 버전에서는 Claude Code, Codex, opencode 등의 에이전트를 지원한다.
