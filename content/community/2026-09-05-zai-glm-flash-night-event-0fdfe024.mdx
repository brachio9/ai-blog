파이토치 한국모임에 올라온 글에 따르면 Z.ai가 9월 20일까지 매일 밤 시간대에 GLM-5.3-Flash 모델 사용량을 늘려주는 이벤트를 진행한다고 한다. 한국 시간으로 오전 0시부터 10시까지 해당되며, 주말과 공휴일에도 적용된다. 유료 플랜 사용자라면 별도 신청 없이 자동으로 혜택이 적용된다고 한다.

혜택의 크기는 사용하는 도구에 따라 달라진다. Z.ai가 직접 만든 에이전틱 개발 환경인 ZCode를 사용할 경우 쿼터 차감 없이 무제한으로 모델을 쓸 수 있다. 반면 Claude Code나 Cline, OpenCode 등 공식 지원 도구 목록에 있는 다른 프로그램을 통해 GLM-5.3-Flash를 호출하면 기본 쿼터의 두 배까지만 사용이 가능하다.

주의할 점은 이 혜택이 GLM-5.3-Flash 모델에만 적용된다는 것이다. 이름이 비슷한 상위 모델인 GLM-5.3을 선택하면 평소대로 쿼터가 소모되므로 설정을 꼼꼼히 확인해야 한다. 또한 공식 지원 도구 목록 외의 도구에 구독 API 키를 연결해 사용하는 것은 이용 정책에 위배될 수 있으므로 주의가 필요하다.

ZCode는 여러 프레임워크 연동과 모바일 원격 제어를 지원하는 에이전틱 개발 환경이다. 설정에서 Anthropic Base URL과 OpenAI Base URL을 각각 Z.ai의 API 주소로 지정하면 구독 쿼터와 연결되어 이벤트를 활용할 수 있다. 원문 작성자는 모델 이름과 도구 설정을 정확히 구분하여 혜택을 누릴 것을 권고했다.
