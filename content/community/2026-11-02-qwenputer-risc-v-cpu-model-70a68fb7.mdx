언어 모델이 복잡한 산술 계산에서 오류를 범하는 문제는 고질적인 과제다. 기존에는 모델이 도구 호출을 요청하면 외부 인터프리터가 계산을 수행하는 방식을 주로 사용했지만, Qwenputer는 계산기를 모델 외부가 아닌 모델의 층으로 직접 통합했다.

이 실험이 가능했던 이유는 Qwen3.5의 하이브리드 구조에 있다. 저자 Divyansh Agrawal은 Qwen3.5에 포함된 Gated DeltaNet(GDN) 층이 토큰마다 갱신되는 상태 행렬을 보유한다는 점에 주목했다. 그는 이 상태 행렬을 조건에 따라 정확하게 읽고 쓰는 메모리 공간으로 활용할 수 있다고 주장했다.

Qwenputer는 Qwen3.5-4B 모델 앞에 11개의 층으로 구성된 32비트 RISC-V CPU를 배치했다. 이 CPU 층의 가중치는 학습이 아닌 컴파일러를 통해 생성되었으며, 모델의 가중치 내에 존재하는 GDN 상태를 CPU의 메모리로 활용한다. 모델은 익힌 도구 호출 형식을 통해 계산을 요청하고, CPU 층이 직접 응답을 생성하는 구조다.

저자의 주장에 따르면 Qwenputer는 DeepMind 산술 세트에서 기본 Qwen 모델과 유사한 수준의 성능을 보여준다. 다만 이 모델은 플러그인이나 샌드박스가 아닌 실험적인 시도이며, 실행을 위해서는 전용 드라이버와 펌웨어가 필요하다.
