dkackman이 개발한 diffusers-workflow는 Diffusers 위에 구축된 선언형 엔진으로, 이미지나 비디오 파이프라인을 Python 스크립트가 아닌 JSON 문서로 정의한다. 이 시스템의 핵심은 MCP 서버를 프론트엔드로 삼아 Claude Code와 같은 에이전트가 생성 작업을 작성하고 검증하며 실행하는 것이다. 웹 UI와 CLI는 보조 수단이며, 에이전트를 일급 운영자로 삼는 것이 주요 설계 목표다.

저자는 LLM이 무인 상태로 GPU를 조종할 수 있게 하려면 두 가지 요소가 중요하다고 강조한다. 먼저 validate_workflow 도구는 모델을 로딩하지 않고 스키마와 실제 파이프라인 시그니처를 확인하여 에이전트의 오타를 사전에 잡아낸다. 또한 GPU 시간이나 디스크 공간을 소모하는 모든 작업은 acknowledged_cost 플래그가 명시되지 않으면 실행을 거부하며, 이는 에이전트가 비용 지출 전에 사용자에게 의사를 확인하도록 강제한다.

워크플로우는 이름이 붙은 단계들의 목록으로 구성되며, 인자는 절대 경로가 아닌 변수나 이전 결과물 참조로 처리된다. 이러한 설계는 다단계 작업을 조합하기 쉽게 만들고 전체 워크플로우를 git diff로 비교 가능하게 한다. 각 실행은 매니페스트와 함께 독립된 디렉토리를 생성하며, 출력물은 생성에 사용된 전체 워크플로우와 시드를 포함하므로 갤러리의 이미지에서 정확한 레시피를 다시 열 수 있다.

이 엔진은 Diffusers의 기능을 재구현하지 않고 동적 임포트를 통해 파이프라인에 접근한다. 따라서 Diffusers에 새로운 모델이 추가되면 어댑터를 새로 작성할 필요 없이 JSON 파일만 추가하면 된다. 양자화 기술이나 캐시 가속기, LoRA 등 다양한 기능도 지원하며, 저자는 이 모든 것이 단일 24GB 그래픽 카드에서 실행 가능하다고 주장한다.
