AI 에이전트가 테스트를 통과했다고 보고해도 실제 입력 처리가 어떻게 변했는지 확인하려면 매번 diff를 확인해야 하는 번거로움이 있다. 개발자는 이러한 문제를 해결하기 위해 Claude Code와 Codex용 오픈소스 플러그인인 Heirloom을 개발했다.

Heirloom은 변경 전후의 코드를 별도의 Git worktree에서 실행한다. 에이전트가 질문에 답하기 전에 실제 출력을 먼저 비교하며, 만약 의도와 다른 결과가 나오면 작업을 반려할 수 있다. 또한 할인 적용 기준과 같은 설계 결정 사항을 관련 코드나 테스트에 연결해 저장하면 다음 에이전트가 해당 파일을 수정할 때 이를 다시 읽어 활용한다.

이 플러그인은 Node.js 20 이상과 Git 환경이 있다면 Claude Code에서 간단한 명령어로 설치하여 사용할 수 있다.
