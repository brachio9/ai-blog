NVIDIA는 Jetson이나 DGX Spark 같은 엣지 플랫폼에서 텍스트, 비전, 오디오 모델을 구동하기 위한 C++ 추론 런타임인 TensorRT Edge-LLM을 발표했다. 이 런타임은 메모리와 전력 자원이 제한적인 환경에서 동작해야 하는 로봇이나 차량용 시스템 같은 피지컬 AI 애플리케이션을 위해 설계되었다. 특히 복잡한 설정 과정을 단순화하기 위해 trtedge라는 명령줄 도구를 제공하며, 이를 통해 모델 다운로드와 특정 GPU 구조에 최적화된 엔진 빌드를 한 번에 처리할 수 있다.

공개된 튜토리얼에서는 DGX Spark 64GB 환경에서 Nemotron 3.5 Lightning 모델을 실행하는 절차를 다룬다. 이 모델은 30B 파라미터 중 3B만 활성화하는 MoE 구조를 사용하며, trtedge chat 명령으로 채팅을 진행하거나 trtedge serve 명령으로 OpenAI 호환 API 서버를 구축할 수 있다. 실습에서 사용된 모델은 NVFP4 형식을 지원하며, 실제 배포 시에는 Jetson Thor와 같은 장치에서 엔진을 다시 빌드해야 한다.

NVIDIA의 측정 결과에 따르면, DSpark 추측 디코딩을 사용할 경우 배치 1 및 출력 128토큰 제한 조건에서 생성 속도가 1.45~1.73배 향상되는 것으로 나타났다. 다만 첫 토큰 지연 시간은 큰 변화가 없었으며, 현재 모델 카드의 지원 언어에 한국어는 포함되어 있지 않다는 점을 유의해야 한다.
