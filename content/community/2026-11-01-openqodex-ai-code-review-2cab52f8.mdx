코딩 에이전트에게 수정을 맡길 때 흔히 발생하는 문제는 에이전트가 자신의 결과물을 스스로 검토하면서 발생한 오류나 편향을 그대로 유지한다는 점이다. OpenQodex는 이러한 문제를 해결하기 위해 코드를 작성한 세션과 분리된 별도의 Claude Code 또는 Codex 프로세스를 사용하여 리뷰를 수행한다. 이 도구는 개발자의 로컬 환경에서 작동하며, 코드가 원격 저장소에 올라가기 전에 검토를 완료하는 것을 목표로 한다.

OpenQodex의 작동 방식은 세 단계로 구성된다. 먼저 gitleaks나 semgrep 같은 정적 분석 스캐너를 실행하여 변경된 부분에서 발견된 결과만 추출한다. 그 다음 별도의 세션을 생성하여 문제 후보를 찾아내고, 검증 세션을 통해 해당 후보를 확인하거나 반박하는 과정을 거친다. 마지막으로 시스템은 판정과 지적 목록이 포함된 영수증을 출력하며, 개발자는 이를 확인하고 수정 여부를 결정한다.

개발사인 Qodex는 자체 벤치마크를 통해 Claude Code 리뷰어가 버그의 84.3~98.0%를 찾아냈다고 주장했다. 다만 실제 PR 데이터를 모은 AACR-Bench에서는 정답 이슈 중 한 줄 이내에 지적이 붙은 비율이 10.7~27.7% 수준으로 나타났다. 이 도구는 별도의 API 키 없이 기존의 Claude Code나 Codex 로그인을 그대로 사용할 수 있으며, 현재 1.0 이전 버전으로 마이너 업데이트에 따라 설정 형식이 변할 수 있다.
