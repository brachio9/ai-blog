브라우저 에이전트 도구들은 대부분 별도의 헤드리스 브라우저를 띄우거나 브라우저 자체를 대체하는 형태라, 이미 로그인해 둔 페이지의 내용을 그대로 다루기 어렵다. Paw Work는 이 문제를 해결하기 위해 현재 열어 둔 웹 페이지에서 이미지나 표 등을 직접 선택하면, 이를 편집 가능한 파일로 변환하는 크롬 확장 프로그램이다. 저자는 무인 조작 에이전트가 아니라 사용자가 범위를 정하면 그 안에서 확인 가능한 결과물을 돌려주는 분업형 도구라고 설명한다.

기술적으로는 Vercel AI SDK의 ToolLoopAgent를 사용해 에이전트 루프를 구성하고, Univer와 tldraw 같은 라이브러리로 스프레드시트나 캔버스 파일을 생성한다. 모델이 생성한 자바스크립트는 WASM 샌드박스 내에서만 실행되며, 파일은 브라우저의 IndexedDB와 OPFS에 저장된다. 별도의 서버나 계정이 필요 없으며, 사용자는 자신의 API 키를 직접 입력하는 BYOK 방식을 따른다.

기존 도구들과 비교할 때 Paw Work는 사용자의 크롬 브라우저에 설치되는 Manifest V3 확장이라는 점에서 차별화된다. Moli나 Obscura처럼 별도 프로세스로 헤드리스 브라우저를 띄우는 방식이나, BrowserOS처럼 브라우저 자체를 대체하는 애플리케이션과는 달리 현재 열어 둔 로그인된 페이지를 그대로 다룬다. 이는 On-Device Browser Agent와 유사한 실행 형태를 지니지만, Paw Work는 선택한 요소를 편집 가능한 파일로 변환한다는 점에 초점을 맞춘다.

이러한 구성은 웹을 대신 돌아다니는 에이전트나 터미널 코딩 에이전트와는 구별된다. 사용자가 직접 범위를 지정하고 확장이 그 범위 안에서 결과를 만들어내는 구조라, 대화형 도구가 제공하는 요약 답변이 아닌 실제 수정 가능한 파일을 얻을 수 있다. 저자는 이를 통해 로그인된 세션과 현재 화면을 그대로 활용하면서도 안전한 환경에서 파일 생성을 가능하게 한다고 주장한다.
