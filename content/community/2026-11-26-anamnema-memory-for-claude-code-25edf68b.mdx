Anamnema는 Claude Code를 위한 오픈소스 메모리 계층으로, AI 어시스턴트가 긴 시간 동안 동일한 사용자와 협업할 때 발생하는 컨텍스트 초기화 문제를 해결하기 위해 설계되었다. 이 시스템은 대화 내용을 외부 저장소에 보관하며, 작은 로컬 모델을 활용해 대화에서 핵심 노트를 추출하고 각 노트가 실제 대화의 어느 부분에서 왔는지 정확한 위치를 참조하도록 만든다.

데이터 저장 및 검색은 Neo4j 그래프 데이터베이스와 벡터 검색을 결합하여 처리하며, CPU 환경에서도 작동할 수 있도록 최적화되었다. 시스템은 Claude Code의 훅을 통해 요청 전이나 특정 단어가 언급될 때 관련 정보를 불러온다. 특히 노트를 검증하여 의심스러운 경우 원문과 대조해 수정하는 자기 수정 기능을 포함한다.

개발자는 시스템의 성능을 확인하기 위해 메모리 사용 여부에 따른 비교 실험을 진행했다. 그 결과, 문서나 코드에 포함된 정보는 메모리 없이도 잘 찾아냈으나, 오직 대화 중에만 언급된 정보에 대해서는 메모리가 활성화되었을 때만 정확한 답변을 얻을 수 있었다고 주장한다. 이 프로젝트는 Apache-2.0 라이선스로 공개되었으며, 개발자는 실제 사용자의 피드백과 평가를 환영하고 있다.
