망고부스트의 김형남은 자체 운영 중인 서버리스 추론 API를 통해 Kimi-K3, DeepSeek-V4-Pro, GLM-5.3, MiniMax-M3 등 대규모 파라미터 모델을 OpenAI SDK 호환 방식으로 호출할 수 있다고 소개했다. 이 서비스는 연구실에서 직접 GPU 환경을 구축하기 어려운 초거대 모델을 외부에서 쉽게 실험할 수 있도록 설계되었으며, 최대 100만 토큰의 컨텍스트를 한 번에 처리할 수 있어 논문 여러 편이나 전체 코드베이스를 동시에 분석하는 용도로 활용 가능하다. 또한 Claude Code나 OpenHands 같은 에이전트 도구와 연동 시 base URL만 변경하면 바로 사용 가능하며, 입력 및 출력 데이터는 학습에 사용하지 않고 저장하지 않는다는 점을 이용약관과 DPA로 명시했다.

김형남은 가입 시 무료 크레딧을 제공하며, 11월 11일까지 전 모델에 대해 30% 할인을 적용한다고 밝혔다. 특히 10월 31일까지 100달러 이상 결제할 경우 결제액만큼 추가 크레딧을 매칭해 주며, 계정당 최대 1,000달러까지 지원한다. 이 혜택은 구글 폼을 통해 신청해야 하며, 결제는 USD 카드로 진행되고 영문 인보이스를 발행한다. 충전한 크레딧은 12개월간 사용 가능하다고 설명했다.

이 API는 chat 기능만 제공하며 embeddings 서비스는 지원하지 않는다고 밝혔다. 모델별 레이트리밋이 설정되어 있어 대규모 상용 서비스의 트래픽 처리보다는 실험, 평가, 합성 데이터 생성 등 연구 및 개발 목적에 더 적합하다고 강조했다. 김형남은 공식 사이트와 문서를 통해 상세 정보를 확인할 수 있으며, 문의는 이메일로 가능하다고 안내했다.
