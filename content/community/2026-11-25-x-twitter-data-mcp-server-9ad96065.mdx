XCROP 개발자는 에이전트가 작업 중에 X(트위터) 데이터를 조회할 수 있도록 돕는 원격 MCP 서버를 구축했다. 이 서버는 별도의 설치 과정 없이 HTTP를 통해 접속 가능하며, XCROP API 키를 통해 인증된다. smolagents와 같이 MCP 클라이언트를 지원하는 에이전트 프레임워크에서 바로 사용할 수 있다.

제공되는 도구는 사용자 프로필, 게시물 검색, 팔로워 목록 확인 등 총 14개의 읽기 전용 기능이다. 게시물 작성이나 좋아요와 같은 쓰기 작업은 포함되지 않으며, 에이전트가 무분별하게 데이터를 호출하여 크레딧을 소모하지 않도록 호출당 리스트 크기가 제한되어 있다.

개발자는 무료 플랜을 통해 매달 10,000 크레딧을 제공하며, 에이전트가 처리하기 어려운 응답 형태가 있을 경우 피드백을 주면 개선하겠다는 의사를 밝혔다. 상세한 도구 목록과 설정 방법은 공식 페이지에서 확인할 수 있다.
