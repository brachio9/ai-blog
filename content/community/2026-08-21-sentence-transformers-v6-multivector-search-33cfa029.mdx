Sentence Transformers는 RAG나 의미 기반 검색에 널리 쓰이는 라이브러리다. v6.0 업데이트에서 Tom Aarsen과 PyLate 개발진인 Antoine Chaffin, Raphael Sourty는 네 번째 모델 유형인 MultiVectorEncoder를 추가했다. 이를 통해 ColBERT 계열의 Late Interaction 검색을 별도 도구 없이 이 라이브러리 안에서 바로 사용할 수 있게 되었다.

기존 밀집 임베딩은 문장을 하나의 벡터로 압축한다. Tom Aarsen 등은 이 방식이 드문 고유명사나 긴 문단의 핵심 정보를 잃어버리는 ‘압축 손실’을 초래한다고 지적한다. 예를 들어 ‘나무 다리와 둥근 쿠션이 달린 초록색 소파’를 검색할 때, 벡터 하나로 여러 조건을 표현하다 보니 다리 모양이 다른 유사한 결과가 섞여 나올 수 있다는 것이다.

MultiVectorEncoder는 문장을 하나의 벡터로 압축하지 않는다. 대신 토큰마다 별도의 벡터를 생성하고 MaxSim 연산으로 점수를 계산한다. 이 방식은 2020년 ColBERT 논문에서 시작되어 PyLate와 ColPali 등을 통해 발전해 왔다. 벡터 크기가 커지는 단점이 있지만, 토큰 수준의 정밀한 대응 정보를 보존해 검색 정확도를 높인다.

v6.0은 기존 Sentence Transformers의 밀집·희소 임베딩과 재정렬 모델에 이 멀티 벡터 방식을 통합했다. PyLate나 Stanford-NLP ColBERT 체크포인트를 그대로 열 수 있으며, OCR 없이 페이지 이미지를 검색하는 colpali-engine 계열 모델도 같은 API로 동작한다. 이제 pip install 명령만으로도 Late Interaction 기반 검색을 표준화된 환경에서 구현할 수 있게 되었다.
