코딩 에이전트는 주어진 목표에 따라 파일과 옵션, 템플릿 코드 등을 자동으로 추가하는 경향이 있습니다. 이러한 과정은 작업이 진행되고 있는 것처럼 보이지만, 실제로는 불필요한 문서와 코드가 쌓이는 결과를 낳기도 합니다. Paperthin은 이런 문제를 해결하기 위해 설계된 오픈소스 프로젝트로, 에이전트가 생성한 필요 없는 요소들을 저장소에서 덜어내는 28가지 스킬을 제공합니다.

프로젝트 관리자는 이 스킬들이 새로운 코드를 작성하는 것이 아니라 기존 초안을 깔끔하게 재구성하거나 흩어진 문서를 통합하는 데 사용된다고 강조했습니다. 또한 여러 코드나 문서에 포함된 주장을 외부 자료와 대조하여 불필요하거나 잘못된 내용을 제거하는 방식이라고 설명합니다. 실제로 28종 중 테스트나 코드 생성을 대신하는 스킬은 없으며, 문서 재작성과 같은 정리 작업에 초점을 맞추고 있습니다.

Paperthin의 핵심은 AI 에이전트가 읽는 마크다운 형식의 지침 파일들로 구성되어 있으며, 작은 Node 런타임이 함께 제공됩니다. 이 런타임은 세션 시작 시 새로운 스킬 업데이트를 확인하고 상태를 기록하며, 하루 한 번만 실행되어 사용자에게 알림만 줍니다. 설치는 Vercel Skills 생태계를 통해 간편하게 가능하며, Claude Code 플러그인 정의도 포함되어 있어 다양한 에이전트 환경에서 활용 가능합니다.
