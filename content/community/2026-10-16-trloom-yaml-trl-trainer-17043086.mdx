Hugging Face 포럼에서 saqlain2204가 개발한 오픈소스 도구 Trloom을 소개했다. 이 도구는 TRL(Transformers Reinforcement Learning) 라이브러리를 기반으로 하며, 사용자가 작성한 하나의 YAML 파일을 읽어 해당하는 TRL 학습기를 자동으로 빌드한다. 설정 파일의 training 블록은 SFTConfig, DPOConfig, GRPOConfig 등 구체적인 학습 설정 객체로 매핑된다.

작성자는 Qwen2.5-0.5B 모델에 LoRA를 적용하고 accuracy_reward를 사용한 GRPO 학습 예시를 제시했다. 해당 YAML 구성에는 모델 경로와 데이터셋 정보, 학습률 및 배치 크기 같은 하이퍼파라미터, WandB 로깅 설정, 그리고 Modal 클라우드 GPU 실행 옵션이 포함되어 있다. 이를 통해 복잡한 Python 코드 대신 간결한 선언형 설정으로 학습 파이프라인을 정의할 수 있다고 주장한다.

사용 방법은 간단하다. pip로 trloom 패키지를 설치한 후, 작성된 YAML 파일을 validate 명령어로 검증하고 run 명령어로 실행하면 된다. Modal GPU에서 실행하려면 run 명령에 --modal 플래그를 추가하면 된다. 현재 이 프로젝트는 v0.1.3 버전으로 초기 단계이며, GitHub와 별도 문서 페이지를 통해 코드와 사용법을 확인할 수 있다.

작성자는 커뮤니티의 피드백을 바탕으로 구성 파일 형식을 개선하고, 요청이 많은 레시피를 추가할 계획이라고 밝혔다. 아직 초기 버전이지만 단일 설정 파일로 모델 미세조정부터 클라우드 실행까지 종단간(end-to-end) 워크플로우를 처리하려는 시도로 평가된다.
