코딩 에이전트가 유용하려면 파일 읽기나 API 호출 같은 권한이 필요하지만, 이는 동시에 보안 위험을 초래한다. 기존 컨테이너 방식은 환경 변수에 API 키가 노출되면 에이전트가 이를 악의적인 서버로 전송할 수 있어 근본적인 해결책이 되지 못한다. NVIDIA는 이러한 문제를 해결하기 위해 에이전트의 접근 권한을 선언형 정책으로 통제하고 커널 수준에서 강제하는 샌드박스 런타임인 OpenShell을 공개했다.

OpenShell은 에이전트를 네트워크가 차단된 격리 환경에서 실행하며, 모든 외부 요청은 신뢰할 수 있는 슈퍼바이저를 경유하도록 한다. 핵심 특징은 에이전트가 실제 자격증명을 전혀 보지 못한다는 점이다. 에이전트는 의미 없는 플레이스홀더 값을 사용하며, 슈퍼바이저가 정책이 허용한 엔드포인트로 가는 요청에만 실제 API 키를 채워 넣는다. 이를 통해 에이전트의 실수나 악의적 행위로 인한 자격증명 유출을 원천적으로 차단한다.

기술적으로는 Rust로 작성되었으며, 파일 접근 제한에는 Landlock LSM을, 시스템 호출 및 네트워크 가로채기에는 seccomp를 활용한다. Docker나 Podman 등 다양한 런타임 위에서 동작할 수 있다. 또한 정책 변경 시 SMT 솔버 기반의 증명기가 형식 검증을 수행하여, 새로운 호스트 접근이나 HTTP 메서드 추가 같은 위험한 확장은 자동 승인되지 않고 사람의 검토를 요구한다.

2026년 9월 말 공개된 버전 0.1.0은 이전 버전과의 호환성이 없는 대규모 변경 릴리스이다. 현재 NemoClaw는 여전히 OpenShell 0.0.116 버전에 고정되어 있어, 최신 기능을 적용하려면 별도의 업그레이드 과정이 필요할 수 있다.
