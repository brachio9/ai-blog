Ryan이 공개한 Anatomy는 기술적 원리를 설명할 때 발생하는 한계를 극복하기 위해 설계되었다. 기존의 다이어그램이 구성 요소의 존재는 보여주지만 실제 동작은 독자의 상상에 의존했다면, Anatomy는 개념을 그대로 수행하는 기계를 에이전트가 직접 발명하고 이를 아이소메트릭 그래픽으로 구현한다.

이 스킬은 "물체 자체가 설명이 되어야 한다"는 원칙을 따른다. 예를 들어 LRU 캐시는 핀 텀블러 자물쇠로, GPU 컨텍스트 구조는 갠트리 플로터로 시각화된다. 모든 수치와 움직임은 실제 모델링된 부품의 동작과 연동되어 데이터와 시각적 표현 사이의 불일치를 방지한다.

Anatomy는 Claude Code를 기반으로 개발되었으며, 결과물로 Node 빌드 스크립트, HTML 페이지, SVG 또는 React 컴포넌트를 생성한다. 에이전트가 스스로 생성한 그림을 검증하는 도구도 포함되어 있으며, 복잡한 시스템일수록 작업 시간이 길어지는 특성을 보인다. 현재 시계 무브먼트나 Raptor 엔진과 같은 복잡한 구조를 시각화하는 데 활용되고 있다.
