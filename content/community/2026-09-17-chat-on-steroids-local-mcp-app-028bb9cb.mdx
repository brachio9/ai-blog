브라우저에서 코딩 보조 모델을 쓸 때 가장 번거로운 점은 대화창과 실제 작업 환경 사이의 단절이다. 모델이 잘 고쳐 준 코드도 사람이 직접 복사해 편집기에 붙여 넣고, 테스트 결과 역시 다시 대화창에 올리는 반복적인 왕복이 필요하다. 이 간극을 메우기 위해 로컬 데스크톱 앱인 Chat On Steroids가 등장했다. 이 앱은 사용자의 컴퓨터에서 MCP 서버를 띄우고, 이를 ChatGPT의 개발자 모드에 커스텀 앱으로 등록함으로써 모델이 승인한 폴더의 파일을 직접 읽고 수정하거나 터미널 명령을 실행할 수 있게 한다.

Chat On Steroids는 Electron 기반의 크로스 플랫폼 앱이며 Windows, macOS, Linux에서 사용 가능하다. 이 프로젝트는 OpenAI와 무관한 독립적인 작업이며 현재 한 명의 개발자가 유지보수하는 베타 버전이다. 별도의 API 키 발급 없이 사용자가 이미 로그인 중인 ChatGPT 계정의 세션을 그대로 활용하므로, 해당 계정에 적용된 모델 가용 범위와 사용량 한도, 컨텍스트 제한이 그대로 따른다.

로컬 작업을 대화형 모델과 잇는 방식은 여러 갈래로 나뉜다. 읽기 전용 연결 방식은 모델이 코드만 읽어 설계나 검토를 담당하고 실제 수정은 다른 에이전트가 수행하도록 역할을 분리한다. 반면 독립 코딩 에이전트는 로컬에서 별도 프로세스로 돌아가며 자체적인 권한 체계를 따른다. Chat On Steroids는 이들과 달리 브라우저상의 ChatGPT 대화 내에서 파일 수정과 명령 실행을 모두 처리하는 구조를 취한다.

이러한 접근 방식의 차이는 모델이 어디에서 실행되며 로컬 시스템에 어떤 쓰기 권한을 부여하느냐에 따라 결정된다. Chat On Steroids는 승인한 폴더 내에서는 파일 수정을 허용하지만, 셸 명령 실행 시에는 폴더 제한 없이 더 넓은 범위의 명령을 수행할 수 있게 한다. 이를 통해 코드를 고치는 능력은 이미 대화창에 존재하는데 통로가 없어서 생기는 비효율을 줄이고자 한다.
