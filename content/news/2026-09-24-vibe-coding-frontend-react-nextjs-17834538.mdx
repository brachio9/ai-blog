바이브코딩으로 만들어진 화면 뒤에서 실제로 어떤 일이 일어나는지 궁금해하는 독자를 위해 양실장의 바이브코딩대학이 뿌리강의 시즌2 3강을 공개했다. 이전 강의에서 백엔드를 다뤘다면 이번에는 프론트엔드의 불확실함을 해소하는 데 초점을 맞췄다. 웹앱이 브라우저와 서버, 데이터베이스와 어떻게 연결되는지부터 시작해 HTML, CSS, JavaScript가 각각 어떤 역할을 하는지 기본 구조를 살펴본다.

React가 등장한 이유와 컴포넌트, Props, State, 렌더링의 개념을 이해하는 과정이 이어진다. 단순히 이론만 설명하는 것이 아니라 React 기반의 간단한 쇼핑몰을 직접 만들어보며 화면이 변하는 원리를 체득한다. 프론트엔드 관점에서 API를 바라보는 시각도 함께 정리하며, 라이브러리인 React와 프레임워크인 Next.js의 차이점을 명확히 구분할 수 있도록 구성했다.

후반부에서는 Next.js의 라우팅과 서버 구조, 서버 컴포넌트와 클라이언트 컴포넌트의 역할, 서버 사이드 렌더링(SSR)을 다룬다. 환경변수와 빌드가 필요한 이유까지 짚으며 전체적인 흐름을 파악한다. 이 강의는 AI가 생성한 코드를 수동으로 따라 쳐봄으로써 데이터의 출처와 화면 변경의 원인을 직접 확인하는 경험을 중시한다.

직접 코드를 따라가며 컴포넌트와 데이터 흐름을 한 번이라도 추적해 보면 바이브코딩으로 생성된 코드가 이전과는 다른 방식으로 인식되기 시작한다. 이번 강의는 React와 Next.js 코드를 볼 때 최소한 무엇이 어디에서 일어나는지 구분할 수 있는 감각을 기르는 것을 목표로 한다. 더 자세한 실습 내용과 커리큘럼은 원문 링크를 통해 확인 가능하다.
