OpenAI의 Dominik Kundel 엔지니어는 Codex 하네스의 내부 설계와 에이전트 최적화 방법을 공개했다. 이 자료는 초고속 모델 환경에서 발생하는 네트워크 문제를 해결하고, 안전한 자동 승인 시스템을 구축하기 위한 실전 아키텍처에 대한 것이다. 독자들은 코딩 에이전트를 개발할 때 어떤 구조적 고려사항이 필요한지 궁금해할 것이며, 이에 대한 답을 찾을 수 있다.

에이전트 구조는 App Server 프로토콜과 Responses API를 활용해 확장성을 확보했다. 도구 지연 로딩과 스킬 사용량 2% 캡 설정을 통해 컨텍스트와 캐시를 최적화하는 전략을 취한다. 또한 각 운영체제별로 Seatbelt나 Bubblewrap 같은 샌드박스를 적용해 격리 환경을 구성하며, Windows의 경우 자체 오픈소스 샌드박스를 활용한다.

사용자 경험을 위해 승인 피로를 줄이는 읽기 전용 Auto Review 서브에이전트를 도입해 위험을 평가한다. 초당 1,000토큰 처리 환경에서 네트워크 오버헤드를 낮추기 위해 WebSocket 상태 동기화를 사용한다. 마지막으로 /goal 명령어를 통한 연속 실행 루프와 서버 사이드 자동 압축 원리가 에이전트의 효율적인 작동을 지원한다.

이 요약은 원문의 앞부분(RSS 요약)만을 바탕으로 작성된 것이다. 전체 설계의 세부 사항이나 추가적인 기술적 논의는 원문을 참고해야 한다. OpenAI Codex 프로젝트의 공식 리포지토리와 관련 링크를 통해 더 많은 정보를 확인할 수 있다.
