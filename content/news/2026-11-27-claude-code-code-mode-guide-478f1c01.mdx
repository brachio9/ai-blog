김플립 - LLM 코딩 채널의 영상이다. 이 글은 **영상 설명란만 보고** 추린 것이다 — 영상에서 실제로 무슨 말을 하는지는 확인하지 않았다.

Claude Code의 Code Mode는 기존에 도구를 하나씩 호출하던 방식과 달리, 코드 한 번으로 묶어서 실행하는 방식을 제공한다. 이 기능은 전화로 심부름을 시키는 것과 쪽지로 심부름을 시키는 것의 차이로 비유될 수 있으며, 사용자의 작업 흐름에 따라 장점과 단점이 뚜렷하게 나뉜다.

Code Mode를 활성화하기 위해서는 Claude Code 버전이 v2.1.323 이상이어야 한다. 이번 세션에서만 일시적으로 사용하려면 환경 변수를 지정하여 실행할 수 있으며, 항상 활성화된 상태를 유지하려면 설정 파일에 해당 환경 변수를 추가해야 한다. 다만 프로젝트 설정 파일에 포함될 경우 무시될 수 있으므로 주의가 필요하다.

이 모드는 실행 시 `/status` 명령어를 통해 활성화 여부를 확인할 수 있으며, 세션을 이어가거나 재개할 때도 동일한 설정을 유지해야 한다. 영상에서는 이 기능이 언제 유용하고 언제 꺼두는 것이 좋은지에 대한 기준을 제시하며 마무리된다.
