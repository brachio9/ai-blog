양실장의 바이브코딩대학 채널의 영상이다. 이 글은 **영상 설명란만 보고** 추린 것이다 — 영상에서 실제로 무슨 말을 하는지는 확인하지 않았다.

바이브코딩대학(VCU)의 온라인 과정 중 일부를 통해 AI 기반 개발자들이 놓치기 쉬운 네트워크 통신의 기초를 소개한다. 단순히 AI로 코드를 생성하는 것을 넘어, 프로그램이 실제로 어떻게 데이터를 주고받는지에 대한 구조적 이해를 제공한다.

콘텐츠는 HTTP 요청의 구성 요소인 시작 줄, 헤더, 바디를 분석하는 것부터 시작한다. URL의 구조와 GET, POST, PUT, PATCH, DELETE 등 주요 메서드의 차이점을 설명하며, 요청 바디와 쿼리 파라미터의 활용법을 다룬다. 또한 응답 구조와 2xx부터 5xx까지의 상태 코드 분류를 통해 서버와 클라이언트의 상태를 확인하는 방법을 포함한다.

이후 API의 실제 동작 메커니즘과 엔드포인트의 개념을 설명하며, Swagger를 활용한 API 명세와 RESTful 설계 원칙을 다룬다. 화면 출력용 주소와 데이터 처리용 API 주소의 차이점 및 JSON 데이터 구조에 대한 기초 지식도 포함된다.

마지막으로 이러한 이론적 지식을 실제 바이브코딩 프로젝트에 어떻게 적용할 수 있는지에 대한 실무적인 연결 고리를 제시한다.
