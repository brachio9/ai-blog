바이브코딩을 통해 화면은 쉽게 만들어낼 수 있지만, AI가 생성한 결과물을 보고 어디를 어떻게 수정해야 할지 막막해하는 경우가 많다. 이때 가장 먼저 필요한 것은 HTML과 UI의 기본 구조에 대한 이해다. 단순히 코드를 작성하기 위한 지식이 아니라, AI가 만든 결과물을 더 높은 해상도로 읽고 판단하기 위한 문해력이 바로 이 부분에서 시작된다.

이 강의는 실제 웹사이트 화면을 뜯어보며 HTML이 어떻게 구조를 표현하는지 살펴본다. 태그와 속성, 헤드와 바디의 역할, 그리고 시맨틱 태그의 중요성을 통해 웹페이지의 뼈대를 이해한다. 또한 폼이나 입력 요소 같은 실제 UI 컴포넌트가 데이터 구조와 어떻게 연결되는지 확인하며, 하드코딩과 동적 데이터의 차이, 사용자 선택에 따른 화면 상태 변화 원리까지 확장해 나간다.

중요한 것은 모든 HTML 태그를 외우는 것이 아니다. 화면을 볼 때 '이 부분은 어떤 구조인가', '사용자가 누르면 어떤 상태가 바뀌는가'라고 질문할 수 있는 사고방식을 기르는 것이다. AI에게 막연하게 수정을 요청하는 것보다, 화면과 구조를 이해한 상태에서 구체적인 변경 사항을 설명할 때 훨씬 좋은 결과를 얻을 수 있다.

앞으로 웹서비스를 사용할 때도 단순한 시각적 요소가 아닌, 그 안에 어떤 UI 컴포넌트와 상태가 있는지 관찰하는 습관을 들이자. 개발 지식은 코드를 직접 모두 작성하기 위함이 아니라, AI의 출력을 더 정확하게 읽고 제어하기 위한 도구로 활용되어야 한다.
