Claude Code의 자동 메모리 기능이 실제 개발 환경에서 유용한지 의문이 제기된다. Theo는 실제 프로젝트의 메모리 파일을 점검하며 자동 메모리가 코드베이스를 오염시킬 수 있는 위험성을 경고한다. AI가 생성한 암묵적인 기록보다는 명시적으로 작성된 코드와 문서가 훨씬 신뢰할 수 있는 기준이 될 수 있다는 주장이다.

에이전트의 컨텍스트 창을 불필요한 정보로 과하게 채우지 않는 것이 중요하다. 필요한 정보만 선별해 전달하고 AGENTS.md나 프로젝트 규칙 파일 등을 활용해 에이전트가 원하는 방향으로 작동하도록 유도해야 한다. 이는 자동 메모리에 의존하는 것보다 훨씬 안정적인 협업 방식을 가능하게 한다.

새로운 스레드마다 에이전트의 상태가 초기화되는 점을 고려하면, 매번 일관된 지시를 내리는 구조를 만드는 것이 효율적이다. 자동 메모리가 완벽하지 않다는 인식을 바탕으로 코드 자체를 가장 확실한 컨텍스트로 삼는 접근이 필요하다.
