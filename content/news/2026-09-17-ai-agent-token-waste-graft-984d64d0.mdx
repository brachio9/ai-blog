최근 Claude Code나 Codex 같은 코딩 에이전트를 사용해 본 개발자들은 공통된 고통을 겪는다. 에이전트가 실제 코드 수정에 들어가기 전에 터미널 검색을 반복하며 토큰을 낭비하고, 결국 컨텍스트 한도에 걸려 작업이 중단되는 현상이다. Tech Bridge는 이러한 고질적인 문제를 해결하기 위해 GitHub 트렌딩 1위를 기록한 오픈소스 도구 'Graft'를 주목한다.

Graft의 핵심은 프로젝트 전체를 단순 텍스트가 아닌 지식 그래프(Knowledge Graph)로 인덱싱한다는 점이다. 기존 벡터 검색이 텍스트 유사도에 의존하는 것과 달리, Graft는 코드 간의 참조 및 의존 관계인 노드와 엣지를 파악한다. 이를 통해 프롬프트 입력 즉시 관련 코드 위치를 매핑하고, 불필요한 파일 탐색 턴을 제거한다. 코드가 변경될 때마다 바뀐 부분만 가볍게 업데이트해 항상 최신 상태를 유지하는 자동 증분 업데이트 기능도 제공한다.

제조사인 TrailHQ의 주장에 따르면, Graft는 162회 테스트를 통해 작업 시간을 60% 단축하고 토큰 사용량을 42% 절감하며 전체 비용을 32% 줄이는 효과를 입증했다. 별도 API 키 없이 기존 구독 환경에서 CLI 또는 MCP 방식으로 바로 연동할 수 있어 진입 장벽도 낮다.

이 글은 Graft의 설치 방법과 Claude Code 연동 설정, 실제 예약 앱 빌드 테스트 결과 등 구체적인 사용법까지 다루고 있다. 코딩 에이전트의 효율성을 높이고 싶은 개발자는 원문을 통해 상세한 벤치마크 데이터와 적용 사례를 확인해 볼 수 있다.
