구글이 오픈AI의 GPT 라이브 계열과 유사한 형태의 새로운 음성-음성 모델인 제미니 3.8 라이브 및 확장 사고 버전을 출시했다. 시몬 윌리슨은 이 문서들을 분석하여 웹 브라우저에서 해당 모델을 직접 체험할 수 있는 인터페이스를 구축했다. 사용자는 원하는 모델과 음성 프리셋을 선택하고 시스템 프롬프트를 입력한 후 마이크를 통해 대화할 수 있으며, 모델이 말하는 도중에도 말을 끊어 응답을 중단시킬 수 있다.

이 웹 UI의 구현 방식은 매우 간결하다. 시몬 윌리슨은 어떠한 외부 라이브러리도 사용하지 않고 순수한 웹 기술을 활용했다. 구체적으로 구글의 제미니 API 웹소켓 엔드포인트에 연결하여 통신하고, 마이크 입력과 스피커 출력을 모두 웹 오디오 API의 오디오 컨텍스트로 처리한다. 이러한 접근 방식은 복잡한 설정 없이 브라우저 환경에서 실시간 음성 상호작용이 가능함을 보여준다.

구현된 인터페이스는 세션 시작 및 종료 버튼, 마이크 음량 미터, 타이머 등을 포함하며 대화 내역을 텍스트로 확인하거나 다운로드할 수 있다. 또한 텍스트 입력창을 통해 메시지를 보내면 현재 진행 중인 음성 응답이 즉시 중단되는 기능을 제공한다. 이는 사용자가 더 자연스럽고 통제 가능한 음성 대화를 경험할 수 있도록 설계된 부분이다.

시몬 윌리슨은 이 도구를 통해 제미니 라이브 모델의 실제 성능과 반응 속도를 확인했으며, 캘리포니아 갈매기에 대한 사실 질문 등 간단한 테스트를 수행했다. 웹소켓을 이용한 제미니 라이브 API 사용법은 구글 개발자 문서에서 별도로 제공되고 있으며, 시몬 윌리슨이 구축한 도구와 소스 코드는 공개된 링크를 통해 직접 확인할 수 있다.
