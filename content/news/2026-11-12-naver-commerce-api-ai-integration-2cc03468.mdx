네이버는 최근 기술 교류 행사에서 커머스 API 플랫폼의 AI 네이티브 과제에 대해 발표했다. 이번 발표는 AI가 단순한 보조 도구를 넘어 시스템의 핵심적인 검수와 답변, 호출 프로세스에 어떻게 통합되는지를 다룬다.

핵심은 기존의 API 스펙을 그대로 유지하면서도 AI를 활용하는 방식이다. 네이버는 올해 세 건의 AI 네이티브 과제를 통해 AI가 데이터를 검수하고, 문의에 대한 답변 근거를 생성하며, 실제 도구로 호출되는 구조를 설계했다.

이 발표는 네이버가 커머스 환경에서 AI를 실제 서비스 운영에 어떻게 녹여내고 있는지에 대한 설계 결정과 실제 운영 결과를 포함하고 있다. 자세한 내용은 네이버 D2의 발표 자료를 통해 확인할 수 있다.
