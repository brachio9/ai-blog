OpenAI가 출시한 ChatGPT Work는 이름만 같을 뿐 실제로는 서로 다른 두 가지 제품으로 구성되어 있다. 웹이나 모바일 앱을 통해 접근하는 클라우드 버전인 Work Cloud와, 데스크톱 앱 설치 시 컴퓨터 내부 파일과 프로그램을 직접 처리할 수 있는 로컬 버전인 Work Local이 그것이다. 로컬 버전은 기존 Codex의 기능을 비개발자 친화적으로 재구성한 형태에 가깝지만, 현재 논의의 중심은 클라우드 기반의 Work Cloud다.

현재 ChatGPT Work는 월 20달러 이상의 유료 구독자에게만 개방되어 있으며, 무료 사용자나 저가형 Go 플랜 사용자는 접근할 수 없다. 인터페이스 상에서는 기존 Chat와 별도의 탭으로 제공되지만, OpenAI가 제시한 '단순 답변은 Chat, 명확한 결과물이 필요한 작업은 Work'라는 구분 기준은 실제 사용 경험과 괴리가 있어 실용성이 떨어진다.

실제 Work Cloud가 일반 Chat와 구별되는 핵심 기능은 모델 선택의 유연성과 확장된 실행 환경에 있다. Sol 대신 Luna나 Terra 모델을 선택할 수 있으며, 인터넷 접근이 가능한 코드 실행 환경과 헤드리스 Chrome 브라우저가 제공된다. 또한 세션 간 지속되는 공유 파일 시스템과 ChatGPT Sites 게시 기능, 그리고 서브 에이전트 세션 실행 능력이 추가되었다.

이 분석은 Simon Willison의 초기 관찰에 기반한 것으로, 아직 완전히 정립되지 않은 기능들의 현황을 보여준다. 더 자세한 기술적 세부사항과 최신 업데이트는 원문을 참고해야 한다.
