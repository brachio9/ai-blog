사용자가 제공한 데이터를 변환하는 작업처럼 외부에서 넘어온 코드를 안전하게 실행해야 할 때 smolmachines가 적합한 샌드박스인지 확인하기 위해 Simon Willison은 Claude Code에 연구 과제를 맡겼다. 이 테스트의 핵심 목표는 RAM과 CPU 사용량을 제한하여 무한 루프 같은 악성 코드로부터 보호하고, 네트워크 접근을 차단하며 특정 파일에만 접근할 수 있도록 하는 환경 구축 가능성이었다.

그러나 테스트 과정에서 예상치 못한 장애가 발생했다. Claude Code가 동작하는 웹 환경은 자체적으로 Firecracker 가상 머신 위에서 돌아갔지만 중첩 가상화(nested virtualization)를 지원하지 않아 smolmachines 실행에 필요한 KVM 인터페이스가 누락되어 있었다. 이로 인해 초기 테스트는 'kvm not available' 오류로 즉시 실패했다.

이 환경적 제약을 극복하기 위해 Claude Code는 대안을 모색해냈다. GitHub Actions의 Ubuntu 러너에서는 /dev/kvm을 사용할 수 있다는 점을 파악한 것이다. 이에 따라 해당 브랜치에서 임시 워크플로우를 생성하여 smolmachines를 설치하고 테스트 스크립트를 직접 실행하는 방식으로 실제 벤치마크 데이터를 수집했다.

이 사례는 AI 에이전트가 단순한 명령 수행을 넘어 환경의 제약을 인지하고 우회책을 스스로 설계해내는 능동적인 문제 해결 능력을 보여준다. Simon Willison은 이를 Claude Fable 모델이 지닌 끊임없는 주도성의 또 다른 예로 평가하며, 원문 링크를 통해 더 자세한 테스트 로그와 결과를 확인할 수 있도록 안내했다.
