AI 코딩 도구가 단순한 코드 생성기를 넘어 소프트웨어 개발 전 과정을 재정의할 것이라는 논의가 이어지고 있다. Anthropic은 Claude Code 팀을 통해 AI 네이티브 SDLC 공식 플레이북을 공개하며, 이 변화의 구체적인 방향을 제시했다. 독자들은 이제 코딩 단계뿐만 아니라 기획과 테스트, 유지보수까지 어떻게 에이전트가 관여하는지 궁금해할 것이다.

공개된 자료에 따르면 개발 과정은 기획 단계에서부터 시작된다. 에이전트와의 인터뷰를 통해 요구사항을 수집하고 이를 intent.md 파일로 생성한다. 이 의도 파일을 바탕으로 설계 명세가 자동으로 생성되며, 거버넌스 가이드라인이 적용되어 일관성을 유지한다. 이는 기존 수작업 중심의 기획 과정을 자동화하는 핵심 단계다.

빌드 및 테스트 단계에서는 plan.md를 수립한 후 서브 에이전트와 git worktrees를 활용해 병렬 개발이 진행된다. 테스트 주도 개발(TDD)과 브라우저 기반 E2E 테스트, 그리고 지속적인 평가(Continuous Evals)가 결합되어 코드 품질을 관리한다. 배포 후에는 Claude가 비동기 방식으로 PR 코드를 검토하고, 장애 발생 시 자율 진단 및 의도 생성을 통해 유지보수를 지원한다.

이 글은 Anthropic이 공개한 공식 플레이북의 앞부분 요약에 기반하여 작성되었다. 전체 프로세스의 세부 구현 방법이나 구체적인 성능 지표는 원문을 참고해야 한다. AI 네이티브 개발 방식이 실제 현장에 어떻게 적용될지는 지속적인 관찰이 필요하다.
