거대 언어 모델(LLM)의 추론 속도를 높이는 기술인 투기적 디코딩(Speculative Decoding)은 특정 도메인에 맞춰 미세 조정된 모델을 사용할 때 성능이 저하되는 문제가 발생한다. 이를 해결하기 위해 매번 드래프트 모델을 새로 학습시키는 방식은 비용이 너무 많이 들기 때문에 효율적인 대안이 필요하다.

연구진은 이러한 문제를 해결하기 위해 EDA라는 프레임워크를 제안했다. EDA는 공유되는 부분과 특정 모델에만 해당하는 부분을 분리하여 모델링하는 구조를 채택한다. 이를 통해 가벼운 구성 요소만 업데이트함으로써 파라미터 효율적인 적응이 가능해진다.

또한 데이터 재생성 전략과 샘플 선택 메커니즘을 도입했다. 미세 조정된 타겟 모델을 활용해 학습 데이터를 다시 생성함으로써 실제 추론 과정과의 정렬을 개선하고, 고가치 데이터를 우선적으로 선택하여 적응 효율을 높인다.

저자들의 주장에 따르면 EDA는 전체 재학습 대비 훨씬 적은 비용으로 미세 조정된 모델의 투기적 디코딩 성능을 효과적으로 복원하며, 더 높은 평균 수락 길이를 달성한다.
