비디오 LLM을 미세 조정(SFT)하는 과정에서 모델은 영상의 실제 내용을 이해하기보다 훈련 데이터에 존재하는 텍스트적 규칙성을 이용해 정답을 맞히는 경향을 보인다. 이러한 지름길 학습은 데이터 크기나 모델 구조와 상관없이 발생하며, 훈련 데이터 내에서는 높은 정확도를 보이지만 실제 상황이 달라지면 성능이 급격히 떨어지는 원인이 된다.

저자들은 이 문제를 해결하기 위해 데이터 자체를 수정하는 대신 미세 조정 과정에서 발생하는 업데이트를 제어하는 VETO(Video-Evidence Training via Orthogonal projection) 기법을 제안했다. 이 방법은 텍스트 정보만으로 구성되는 활성화 공간을 계산하고, 모델의 업데이트를 이와 직교하는 방향으로 투영하여 지름길 학습이 형성되는 것을 억제한다.

저자들의 주장에 따르면 VETO는 7개의 비디오 LLM 모델에서 훈련 데이터의 성능을 유지하면서도 지름길 학습을 효과적으로 억제했다. 또한 6개의 벤치마크에서 기존 SFT보다 높은 성능을 기록했으며, 모델이 지름길에 의존하지 않고 전체 입력 정보를 활용해 답변하도록 유도하는 데 성공했다고 밝혔다.
