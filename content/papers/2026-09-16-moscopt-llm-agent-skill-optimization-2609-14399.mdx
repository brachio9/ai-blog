LLM 기반 에이전트의 핵심은 자연어 프롬프트와 스킬이다. 최근 프롬프트 및 스킬 최적화 기술은 눈에 띄는 성과를 거두었지만, 기존 방법들은 모두 단일 텍스트 템플릿만 최적화한다는 공통된 한계를 지니고 있다. 이는 서로 보완적인 다중 전략 간 시너지를 놓치게 만든다. MOSCOPT는 이러한 문제를 해결하기 위해 제안된 텍스트 네이티브 알고리즘으로, 파라미터 없이도 N개의 스킬 풀과 각 단계에서 K개의 스킬을 동적으로 선택하는 게이트KEEPING 스킬 G를 함께 최적화한다.

MOSCOPT의 핵심은 EditAdam이라는 내부 이중 상태 유지 메커니즘을 통한 효율적인 스킬 최적화에 있다. 이 알고리즘은 세 단계의 교차 업데이트를 수행하며, 그라디언트나 파라미터 튜닝 없이도 시스템 성능이 단조롭게 개선되도록 설계되었다. 즉, 복잡한 모델 가중치 변경 없이 텍스트 기반의 전략 조합과 선택 과정 자체를 진화시켜 에이전트의 능력을 향상시킨다는 것이 저자들의 설명이다.

저자들은 5개의 벤치마크와 3가지 대상 LLM을 대상으로 한 광범위한 실험과 상세한 아블레이션 연구 결과를 제시한다. 저자들의 주장에 따르면 MOSCOPT는 모든 베이스라인보다 일관되게 우수한 성능을 보였으며, 선택적 활성화가 가능한 혼합 스킬 아키텍처와 세 단계 교차 진화가 이러한 우수 성과의 필수 요소임을 확인했다. 이는 단일 전략 최적화보다는 다중 전략의 집단적 진화가 더 효과적임을 시사한다.

이 연구는 에이전트 훈련 알고리즘으로서의 MOSCOPT 구현 코드를 공개하며, 향후 LLM 에이전트의 프롬프트 엔지니어링 및 스킬 관리 방식에 새로운 접근법을 제시한다. 파라미터 학습 없이 텍스트 수준의 최적화만으로 성능을 극대화할 수 있다는 점은 계산 효율성 측면에서도 주목할 만하다. 관련 코드와 더 자세한 내용은 GitHub 저장소에서 확인할 수 있다.
