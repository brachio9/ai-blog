웹 에이전트는 시각적으로 복잡하고 긴 과정을 거치는 인터페이스를 탐색해야 하지만, 기존 대다수의 에이전트는 각 작업을 독립적으로 학습하며 축적된 절차적 지식을 버리는 단점을 가진다. 최근 등장한 스킬 증강 프레임워크는 중요한 첫걸음이지만, 스킬 라이브러리를 평면적이거나 2단계 프롬프트 캐시로만 취급해 중복을 압축하거나 재귀적으로 구성하는 원칙적인 메커니즘을 제공하지 못한다.

SCAFFOLD는 시각적 웹 에이전트의 자기 개선 프레임워크로, 다중 인스턴스 추상화 제약 하에서 성공한 궤적으로부터 파라메트릭 실행 가능한 스킬을 유도한다. 이 시스템은 상위 레벨 스킬이 하위 레벨 스킬을 호출하는 재귀적 계층 구조를 유지하며, 최소 설명 길이(MDL) 기준과 행동 동등성 검사를 통해 라이브러리를 압축한다. 또한 주기적으로 스킬 증강 궤적을 모델 가중치로 정제해 추상화를 내부화한다.

저자들의 주장에 따르면 SCAFFOLD는 WebArena, VisualWebArena, Online-Mind2Web의 홀드아웃 분할에서 가장 강력한 스킬 증강 베이스라인 대비 성공률을 11.1~17.2 절대 포인트 향상시킨다. 또한 라이브러리 붕괴 없이 다섯 번의 자기 개선 반복에 걸쳐 단조로운 성능 향상을 보인다고 한다.

이 연구의 코드와 문서는 GitHub 저장소에서 공개되어 있어, 웹 에이전트의 지식 축적과 재사용 문제를 해결하는 새로운 접근법을 직접 확인할 수 있다.
