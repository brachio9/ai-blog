LLM 기반 에이전트가 사용자를 대신해 웹을 탐색하는 사례가 늘어나면서, 웹사이트가 에이전트의 기반 모델을 식별할 수 있는지에 대한 보안 문제가 제기되었다. 특정 모델의 취약점을 노린 표적 공격이 가능해지기 때문이다. 연구진은 에이전트의 행동과 상호작용 타이밍을 수동적인 자바스크립트 트래커로 수집하여 모델을 식별하는 실험을 진행했다.

저자들의 주장에 따르면, 특정 환경 내에서 에이전트의 행동 데이터만으로 최대 96%의 F1 점수로 기반 모델을 식별할 수 있었다. 다만 이러한 지문은 환경에 종속적이라 다른 환경으로 전이될 때는 성능이 낮아지지만, 여러 환경의 데이터를 통합하면 0.74에서 0.81 사이의 Macro-F1 점수로 모델을 식별할 수 있다고 주장한다.

연구진은 전체 데이터 중 약 3분의 1 정도의 트레이스만으로도 강력한 분류기를 학습시킬 수 있으며, 관찰되는 이벤트가 많아질수록 식별 성능이 지속적으로 향상된다고 밝혔다. 또한 행동 사이에 무작위 지연 시간을 삽입하는 방식이 분류 성능을 저하시키기는 하지만, 지연 데이터로 재학습된 분류기를 통해 성능이 다시 회복되므로 완벽한 방어책은 되지 못한다는 점을 확인했다.

연구진은 이 연구를 통해 확인된 에이전트 트레이스 데이터와 코드를 공개했다.
