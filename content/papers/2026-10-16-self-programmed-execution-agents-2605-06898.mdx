현재의 언어 모델 에이전트 시스템에서는 턴 간 상태 전이를 담당하는 오케스트레이터 프로그램이 외부 하네스에서 고정된 정책으로 구현되어 있다. 이 논문은 이러한 제한을 깨고 모델의 생성 결과(completion) 자체가 오케스트레이터 프로그램이 되는 자기 프로그래밍 실행(SPE) 방식을 제안한다. 이 접근법에서 하네스는 프로그램을 평가할 뿐, 어떤 고정된 오케스트레이션 정책도 강제하지 않는다. 즉, 에이전트 머신의 상태는 모델 생성물이 임의의 후속 상태를 로드할 수 있는 지점이며, 그 인스턴스는 해당 생성물을 프로그램으로 실행한다.

이 방식이 실제로 작동하려면 소스 코드가 모델의 컨텍스트 창 내용과 중복되는 특수한 언어가 필요하다. 저자는 이를 위해 Spell이라는 Lisp 방언을 소개하는데, 이 언어는 프로그램이 스스로를 수정하고 재평가할 수 있도록 설계되었다. 특히 모델 호출과 같은 부수 효과(side effect)가 있는 표현은 구조화되어 있어, 수정된 프로그램을 재평가하더라도 이전의 부수 효과가 다시 재생되지 않도록 한다. 이는 에이전트가 자신의 실행 흐름을 동적으로 제어하면서도 불필요한 중복 처리를 피할 수 있게 해준다.

저자들의 주장에 따르면, SPE나 Spell로 사전 훈련되지 않은 기존 프론티어 모델들도 컨텍스트 내에서 Spell을 학습하고 복잡한 에이전트 작업을 수행할 수 있다. 이는 고정된 오케스트레이션 정책 없이도 언어 모델이 에이전트로 작동할 수 있음을 보여준다. 또한 이 결과는 자기 프로그래밍 실행을 위해 특별히 훈련된 모델이 어떤 자기 오케스트레이션 전략을 학습할 수 있을지에 대한 새로운 질문을 던진다.

이 연구는 에이전트의 제어 구조를 외부에서 정의하는 것에서 모델 내부의 생성물로 전환하는 패러다임 변화를 시사한다. 코드와 관련 자료는 GitHub 저장소에서 확인할 수 있으며, 이를 통해 독자들도 해당 방식을 직접 실험해 볼 수 있다.
