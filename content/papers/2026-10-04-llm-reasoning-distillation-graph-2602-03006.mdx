대규모 언어 모델을 분류 작업에 적용할 때 추론 지연 시간과 계산 비용, API 사용료가 큰 장벽으로 작용한다. 기존 활성 증류 방식은 오라클 모델의 최종 라벨만 학습시키며 중간 추론 신호를 버리기 때문에, 어떤 추론이 부족하고 어디서 오류가 발생하는지 진단하기 어렵다. 이 연구는 이러한 한계를 극복하기 위해 교사의 추론 과정을 중간 개념들의 방향성 비순환 그래프로 유도하고 이를 학생 모델에 반영하는 '개념 예측자 그래프' 프레임워크를 제안한다.

이 프레임워크는 그래프 기반의 획득 전략을 통해 샘플 효율성을 높인다. 각 개념별 불확실성, 기울기 다양성, 노드 중심성을 고려해 가중치를 부여함으로써 학습 데이터 선택을 최적화한다. 또한 하류 손실을 특정 개념 예측자에게 귀속시켜 영향력이 큰 모듈만 재훈련하는 표적 부분 모듈 재훈련 방식을 도입해 훈련 안정성과 효율성을 개선한다.

저자들의 주장에 따르면 이 방법은 여덟 개의 자연어 처리 분류 벤치마크에서 제한된 주석 예산 하에서도 성능을 향상시킨다. 기존 방식과 달리 학습 동역학을 더 해석 가능하고 통제 가능한 형태로 만든다는 점이 특징이다. 코드와 관련 자료는 공개된 저장소에서 확인할 수 있다.
