LLM 기반 진화 알고리즘에서는 언어 모델이 제어 흐름 같은 구조적 요소와 연속적인 파라미터를 동시에 업데이트하는 단일 연산자로 작동한다. LLM은 구조 설계에는 강점이 있지만, 시행착오 루프 내에서 이산적인 점프를 통해 연속 파라미터를 조정하는 과정은 토큰 낭비가 심하고 비효율적이다.

이 문제를 해결하기 위해 하이브리드 중첩 탐색을 공식화했다. 외부 루프에서는 LLM이 숫자 공백이 있는 구조적 스케치를 제안하고, 내부 루프에서는 수치 최적화기가 해당 스케치를 튜닝한다. 이 프레임워크의 핵심은 플러그인 방식의 유연성이다. 텍스트 기반 최적화기로는 어떤 모델이든 사용 가능하며, 내부 솔버에는 CMA-ES 같은 제로차 최적화기나 그래디언트 기반 루틴, MCMC 샘플러 등을 자유롭게 결합할 수 있다.

저자들은 이 프레임워크를 세 가지 과학적 도메인에서 검증했다. 닫힌 형식 테스트 함수에 대한 메타 옵티마이저, 시스템 연구 및 사회적 딜레마를 위한 코드 기반 정책, 그리고 근사 베이지안 추론 작업이 해당된다. 저자들의 주장에 따르면, 이 하이브리드 최적화기는 순수한 LLM 기반 탐색이나 순수 수치 최적화 베이스라인 모두보다 모든 도메인에서 우수한 성능을 보였다.

이 연구는 LLM의 창의적인 구조 설계 능력과 수치 최적화기의 정밀한 파라미터 튜닝 능력을 분리하여 시너지를 내는 방법을 제시한다. 코드와 관련 자료는 GitHub 저장소에서 확인할 수 있으며, 이는 다양한 과학적 문제 해결에 적용 가능한 범용적인 프레임워크로 평가된다.
