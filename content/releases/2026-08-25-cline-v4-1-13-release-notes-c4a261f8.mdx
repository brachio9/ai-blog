이번 업데이트는 SDK 번들을 통해 배포되므로 해당 번들을 실행하는 모든 윈도우 환경에 적용된다. 가장 주목할 만한 변경점은 커스텀 OpenAI 호환 모델의 도구 호출 기능 복구다. 이전 버전에서는 supportsReasoning과 같은 편의 플래그에서 추론된 능력 목록이 절대적인 거부 기준으로 작용해 요청에서 모든 도구가 제거되는 문제가 발생했다. 이제 명시적으로 작성된 능력 목록이 우선권을 가지도록 수정되어 정상적인 도구 호출이 가능해졌다.

Hub 기반 세션의 안정성도 크게 개선되었다. Hub가 재시작되거나 업그레이드되는 동안에도 세션이 유지되며, 연결이 끊긴 사이에 발생한 이벤트를 클라이언트가 다시 재생할 수 있게 되었다. 특히 이벤트 재생 스트림과 실시간 스트림이 겹칠 때 동일한 이벤트가 두 번 전달되던 버그도 수정되어 데이터 일관성이 확보되었다.

또한 Langfuse 트레이싱 기능에도 세션 및 클라이언트 정체성 정보가 포함되도록 개선되었다. 기존에는 Hub 기반 실행이나 위임된 에이전트 실행 시 세션 그룹화나 클라이언트 버전 정보가 누락되어 추적하기 어려웠으나, 이제 이러한 메타데이터가 정확히 전달된다.

이 요약은 전체 변경 로그 중 주요한 사항만 추려낸 것이며, 상세한 커밋 목록이나 기여자 정보는 공식 저장소의 비교 페이지에서 확인할 수 있다.
