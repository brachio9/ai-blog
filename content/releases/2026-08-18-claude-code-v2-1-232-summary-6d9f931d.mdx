이번 업데이트의 가장 큰 변화는 서브에이전트 포킹(subagent forking)이 기본 활성화된 점이다. 이제 'fork' 타입의 서브에이전트는 대화 이력과 프롬프트 캐시를 그대로 상속받으며, 인터랙티브 세션에서 생성된 비팀메이트 에이전트는 백그라운드에서 실행된다. 또한 프롬프트 입력창에서 '@'를 치면 다른 Claude 세션을 이름으로 호출해 직접 메시지를 보낼 수 있게 되어 작업 흐름이 더 매끄러워졌다. 같은 기기에서 여러 세션을 운영할 때 이름 충돌을 자동으로 처리해 주며, 설정 메뉴에 대화 만료 시간과 타 세션 메시지 수신 정책 관련 옵션이 추가되었다.

GitLab과의 통합도 크게 강화되었다. GitLab 토큰 계열의 비공개 정보 적출(redaction) 기능이 확대되어 다양한 토큰 접두사와 라우팅 가능한 토큰이 자동으로 감춰지며, glab CLI 설정 저장소도 GitHub와 동일한 샌드박스 및 자격 증명 경로 보호를 받는다. 플러그인 마켓플레이스에서 gitlab.com 리포지토리 URL(중첩 서브그룹 포함)이 github.com처럼 쉽게 클론되며, 인증 실패 시 실제 깃 호스트 이름을 명시해 준다. 기업 정책에서는 특정 리포지토리 URL을 차단할 때 CLI가 이를 깃 클론으로 분류하더라도 차단이 유지되도록 개선되었다.

보안 측면에서 여러 중요한 패치가 적용되었다. PowerShell에서 변수 작성 매개변수가 $PSDefaultParameterValues를 침묵하게 덮어씌워 파일 접근을 리디렉션하는 취약점, Windows의 Git Bash가 Cygwin 스타일 심볼릭 링크를 일반 파일로 오인해 권한 우회를 가능하게 하던 문제, 그리고 중첩된 깃 리포지토리가 상위 디렉터리의 신뢰 설정을 물려받는 문제가 모두 해결되었다. 또한 MCP 연결이 서버 응답 실패나 오류 시 30초 전체 타임아웃 동안 멈춰 있던 문제가 개선되었고, 클라우드 세션 내부 브리지에서 시작된 원격 제어 세션이 해당 세션의 트랜스크립트나 자격 증명을 상속받는 결함도 수정되었다.

기타 설정 및 안정성 개선 사항으로는 Gateway의 데스크톱 오버레이가 이제 출시된 모든 데스크톱 설정을 받아들이며 부팅 시 스키마 검증으로 유효하지 않은 키를 차단한다. 관리 정책에서 빈 그룹 항목이나 형식이 잘못된 이메일 도메인 값이 침묵하게 무시되거나 관리자 권한을 부여하던 대신 부팅 실패로 처리되어 보안성을 높였다. Fable 5는 Fable 접근 권한이 있는 조직에서 /advisor 명령어를 통해 다시 어드바이저로 제공되며, /model fable 명령을 통해 사용 크레딧 동의가 설정된다. 이 요약은 주요 변경 사항 중 일부를 다루며 전체 릴리즈 노트의 전부는 아니다.
