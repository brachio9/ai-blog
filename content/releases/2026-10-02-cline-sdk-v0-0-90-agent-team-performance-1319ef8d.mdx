이전 버전에서는 에이전트 팀이 작동하는 동안 각 스트림 청크와 하트비트가 전체 팀 상태와 대화 기록을 다시 저장하며 성능이 급격히 떨어졌다. 단일 데이터베이스 파일이 1.6GB 이상으로 부풀어 오르고 한 행이 수십만 번 재기록되는 현상이 발생했다. 이번 업데이트는 이러한 과도한 쓰기 작업을 차단한다. 스트리밍 중인 데이터는 실시간 UI에만 전달되고 더 이상 저장되지 않으며, 변경된 엔티티만 300ms마다 일괄 처리하여 저장한다.

저장소 구조도 함께 개편되었다. 실행 기록은 전체 대화 대신 요약본을 유지하며, 팀 이벤트 로그는 팀당 2000행과 30일로 제한된다. SQLite 스키마가 v2로 업그레이드되며 기존 데이터는 자동으로 압축 정리된다. 명시적으로 진공 처리를 호출하면 해제된 공간을 회수할 수 있으며, 저장 실패 시에도 데이터가 유실되지 않도록 재시도 로직이 적용되었다.

세션 외부에서 수행되는 독립형 요청의 헤더 처리 방식도 개선되었다. 커밋 메시지 생성과 같은 작업에서 세션 ID가 선택 사항이 되었으며, 비어 있는 X-Task-ID 헤더 전송을 제거했다. 이는 외부 API 호출 시 불필요한 메타데이터 전송을 줄이고 오류 가능성을 낮추는 조치다.

모델 카탈로그도 갱신되었다. DigitalOcean, GMI Cloud, NanoGPT, Nvidia, Ofox 등 주요 제공자의 기본 모델이 최신 버전으로 변경되었다. 각 플랫폼의 기술적 변화에 맞춰 최적화된 모델을 기본값으로 설정하여 사용자의 초기 설정 부담을 줄였다. 전체 변경 내역은 공식 저장소의 비교 링크에서 확인할 수 있다.
