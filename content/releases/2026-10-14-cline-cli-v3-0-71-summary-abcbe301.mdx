이번 업데이트의 가장 큰 변화는 플러그인 실행 방식이다. 이제 플러그인은 별도의 노드나 번 프로세스가 아닌 허브 내부에서 로드된다. 이로 인해 CLI가 플러그인을 실행하기 위해 시스템 경로에 자바스크립트 런타임이 있을 필요가 없어졌다. 플러그인 로딩 실패 시 더 이상 도구 목록에서 조용히 사라지지 않고, 경고 메시지와 함께 에러 원인을 명시적으로 알려준다. 기존처럼 서브프로세스 방식으로 유지하려면 환경 변수를 설정하면 된다.

대화 효율성과 관련된 개선 사항도 포함되어 있다. 스크린샷 등 이미지 입력이 토큰 추정치를 불필요하게 부풀려 자동 압축을 너무 일찍 작동시키는 문제가 해결되었다. 또한 모델 카탈로그에 컨텍스트 윈도우 정보가 없을 때 선택된 모델의 실제 컨텍스트 윈도우를 기준으로 자동 압축을 수행하도록 조정했다. 이는 대화 한계에 가까워지기 전까지 불필요한 압축을 방지한다.

사용자 경험 측면에서도 여러 편의 기능이 추가되었다. ACP 모드에서 이제 추론(thinking) 기능을 사용할 수 있게 되었으며, 모든 제공업체에서 추론 기능의 켜고 끄기가 정상적으로 작동한다. 환경 변수로 설정된 API 키가 시작 시 구성 완료로 인식되므로 TUI에서 중복 설치를 요청하지 않는다. 또한 스케줄링 실행 시 대기열에 있는 작업이 정상적으로 시작되고, 모델 호출 실패 시 에러 상태로 명확히 표시된다.

기타 변경 사항으로는 심볼릭 링크 규칙 파일 지원, .claude/skills 디렉토리 내 스킬 자동 발견, 그리고 다양한 제공업체의 기본 모델 및 엔드포인트 업데이트 등이 있다. 이번 릴리스는 전체 커밋 목록 중 주요한 기능 개선과 버그 수정만을 추려낸 것이므로, 상세한 변경 내역은 공식 저장소의 풀 체인지로그를 참고해야 한다.
