로컬 모델(llama.cpp, Ollama 등) 사용 시 출력 토큰 한계에 도달하면 대화 중반에 응답이 끊기는 문제가 해결되었다. CLI는 이제 대화 내용을 압축한 후 한 번 재시도하며, 실패 시에도 부분적인 답변을 유지한다. 또한 허브 시작 실패 시 구체적인 원인을 표시하고 Windows 환경에서의 초기 시작 대기 시간을 8초에서 15초로 연장하여 안정성을 높였다.

세션 재개 시 이전에 발생한 에러 메시지가 대화 기록에 다시 나타나며, 이 과정에서 모델 전송이나 압축 카운트에 포함되지 않는다. 허브 관리 세션에서 제목과 프롬프트 수정이 영구적으로 저장되도록 개선되었고, 플러그인 로딩 실패 시 샌드박스 생성 비용이 매 요청마다 발생하지 않도록 변경되었다. 빈 응답 재시도 중 Esc 키를 누르면 백오프 지연 없이 즉시 취소된다.

Yolo 모드(-y)는 더 짧은 계획과 도구 호출 전 서론 제거, 코드 및 편집 내용을 텍스트 초안 없이 직접 도구 호출에 작성하도록 모델 프롬프트를 강화했다. 이를 통해 불필요한 설명과 토큰 소비가 줄어든다. 새로운 제공자 ai&가 추가되어 일본 기반 오픈웨이트 모델을 지원하며, 기본 모델은 GLM 5.3이다.

모델 카탈로그가 6,237개에서 6,386개로 확대되었고, 19개 제공자의 기본 모델이 변경되었다. Claude Opus 5.5를 기본으로 하는 제공자가 11곳 증가했으며, StepFun, Fireworks 등 주요 제공자들도 각각 새로운 버전의 모델을 기본값으로 채택했다. 특정 모델을 고정하지 않은 사용자는 업데이트 후 다른 기본 모델을 사용할 수 있음을 유의해야 한다.
