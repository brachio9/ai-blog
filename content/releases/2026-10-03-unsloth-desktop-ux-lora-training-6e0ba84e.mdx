Unsloth 데스크톱 앱의 최신 릴리즈는 사용자의 작업 흐름을 더 매끄럽게 만드는 데 초점을 맞췄다. Cmd/Ctrl+P 단축키로 명령어 팔레트를 열 수 있게 되어 모델 탐색이 빨라졌으며, GGUF 모델의 실행 설정을 링크로 공유하거나 저장할 수 있게 되었다. 또한 에러 메시지가 더 명확해져 로드나 생성 실패 원인을 쉽게 파악할 수 있고, 로그 확인 버튼도 제공된다. 이미지 갤러리 썸네일 우선 로딩과 확대/축소 기능 등 인터페이스 개선도 함께 적용되었다.

가장 주목할 만한 기술적 변화는 4비트 체크포인트 학습 방식의 개선이다. 기존에는 학습 시 모델 가중치를 풀어서 메모리를 많이 썼지만, 이번 업데이트는 Triton 커널을 사용해 레이어 단위로 실시간 역양자화(dequantize)하며 학습한다. 이로 인해 Qwen3.8-27B-NVFP4 모델의 경우 단일 RTX PRO 6000에서 피크 메모리 사용량이 72.9GB에서 40.2GB로 줄어드는 등 약 45% 절감 효과를 보였다. INT4와 MXFP4 체크포인트도 압축된 상태를 유지하므로 Kimi-K2.7-Code나 gpt-oss 같은 대형 모델도 적은 메모리로 학습할 수 있게 되었다.

결정(Decision) API 관련 성능도 크게 향상되었다. Laya 결정 모델의 응답 속도가 최대 4.1배 빨라졌으며, TypeSafe 등 외부 호스팅 제공자와의 연결이 지원된다. B200 GPU에서 3단계 가드레일 체크 시간이 11.6ms에서 2.8ms로 단축되는 등 짧은 요청 처리가 매우 효율적으로 변했다. 모델 로딩 시간도 약 절반으로 줄고 호스트 RAM 사용량도 반감되었다.

이 업데이트는 Unsloth 팀의 공식 릴리즈 노트에 기반한다. 수치와 성능 개선 효과는 해당 팀의 테스트 환경에서 측정된 결과이며, 모든 사용자의 환경에서 동일한 결과가 나오지 않을 수 있다. 특히 4비트 학습 시 메모리 절감 효과는 모델과 하드웨어에 따라 차이가 있을 수 있으므로 참고가 필요하다.
