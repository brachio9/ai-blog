이번 업데이트의 핵심은 비임(Vim) 모드에서의 작업 흐름 개선이다. 이제 `u` 키로 실행 취소하고 `Ctrl+R`로 재실행하는 기능이 지원되며, 붙여넣기 내용이나 첨부 파일까지 포함한 초안 전체를 보존할 수 있다. 또한 플러그인 CLI를 통해 원격 마켓플레이스에서 플러그인을 목록 확인, 설치, 제거하는 것이 가능해졌다.

사용자 인터페이스(TUI) 측면에서는 자동 요약 기능을 비활성화하면서도 수동 `/recap` 명령은 유지할 수 있도록 `tui.auto_recap = false` 설정이 추가되었다. 히스토리 기능도 강화되어 패치 전체 내용, 백그라운드 터미널에 전송된 입력, 개별 완료 명령 등을 더 명확하게 확인할 수 있게 되었다.

안정성과 신뢰성 측면에서도 개선점이 많다. 외부 앱 서버 연결이 끊겼을 때 TUI 세션이 재연결되며 초안과 대화 기록은 보존된다. 이때 불확실하거나 대기 중인 제출물은 검토를 위해 일시 정지 상태로 유지된다. 가디언(Guardian) 리뷰 히스토리는 컴팩션, 재시작, 포크 상황에서도 롤백 경계와 서브 에이전트 격리를 존중하며 안정적으로 유지된다.

기타 설정 및 API 변경 사항으로는 앱 서버 스레드 메타데이터에 `model`과 `reasoningEffort` 필드가 nullable로 추가되었고, 모델 카탈로그 활성화 시 비동기 사용자 입력 요청이 지원된다. 붙여넣기 버스트 제어 설정이 `tui.disable_paste_burst`로 이동했으며, 기존 설정은 하위 호환성으로 유지된다. 이 외에도 맥스(MCP) 도구 승인 범위 지정과 macOS 상대 경로 처리 개선 등 다양한 버그 수정이 포함되었으나, 이는 전체 변경 사항의 일부일 뿐이다.
