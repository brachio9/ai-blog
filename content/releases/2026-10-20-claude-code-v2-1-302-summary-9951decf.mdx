이번 업데이트의 가장 큰 변화는 자동 모드(auto mode)의 동작 방식을 세밀하게 제어할 수 있게 되었다는 점이다. 기존에는 서버 측과 클라이언트 측이 동일한 모델을 사용했으나, 이제 `CLAUDE_CODE_AUTO_MODE_MODEL` 환경 변수를 통해 클라이언트 측 분류기에만 특정 모델을 지정할 수 있다. 이는 비용 효율성이나 응답 속도를 고려해 분류 작업에 적합한 모델을 선택하는 데 유용하다. 또한 `/config` 명령어에서 'Idle compaction' 옵션을 토글할 수 있게 되어, 불필요한 컨텍스트 압축으로 인한 중단을 원치 않는 사용자는 이를 쉽게 끌 수 있다.

안정성 측면에서도 여러 중요한 수정이 이루어졌다. 대화 컴팩션 도중 턴(turn)을 중단하려 할 때 발생하던 '프롬프트가 너무 길다' 오류를 해결했으며, 세션 중간에 Vertex나 Bedrock 같은 다른 백엔드로 전환했을 때 발생하던 진단 오류도 고쳤다. 특히 Read 도구가 이미지 파일이나 파이프를 무조건 메모리에 로드하여 시스템 자원을 소모하던 문제가 수정되어, 128MB가 넘는 이미지 소스는 이제 거부된다. 이는 대용량 파일 처리 시 발생할 수 있는 메모리 누수 및 크래시를 방지하는 중요한 조치다.

플러그인 및 도구 관련 버그들도 광범위하게 해결되었다. PowerShell 도구가 플러그인의 bin 폴더에서 명령어를 찾지 못하거나, 검색 결과가 없을 때 에러를 내던 문제가 수정되었다. 또한 Git 기반 플러그인 설치 시 버전 정보가 'unknown'으로 표시되거나 매번 다시 클론되는 현상이 개선되었고, 설정 저장 중 프로세스가 종료되며 변경사항이 유실되거나 임시 파일이 남는 문제도 해결했다. MCP 서버의 프로토콜 버전 협상 과정에서 누락된 필드로 인해 도구가 표시되지 않거나 호출이 실패하던 이슈 역시 패치되었다.

마지막으로 사용자 경험(UX)과 모니터링 관련 개선 사항도 포함되었다. 데스크톱 앱에서 MCP 서버 연결 오류 시 잘못된 설정 페이지로 유도하던 문제가 수정되어 올바른 경로로 안내하도록 고쳤다. 또한 자동 모드 분류기 이벤트가 OpenTelemetry에 제대로 기록되지 않던 문제를 해결해 관측 가능성을 높였으며, 크레딧으로 결제되는 모델에서 프롬프트 제안이 불필요하게 크레딧을 소모하던 현상도 차단했다. 이 외에도 디자인 동기화 관련 공지사항 표시 및 아티팩트 발행 실패 문제 등 다양한 세부 사항들이 개선되었다.
