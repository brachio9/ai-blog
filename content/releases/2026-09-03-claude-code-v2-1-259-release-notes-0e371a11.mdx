이번 업데이트는 비대화형(headless) 호스트에서 Claude Code를 자동으로 실행할 때 필요한 기능을 보강했다. --permission-prompts none 플래그를 추가해 프롬프트가 발생할 경우 자동으로 거절하도록 처리하므로, 인간의 개입 없이도 스크립트나 CI 파이프라인 내에서 안전하게 코드를 실행할 수 있다. 또한 조직 관리자가 모든 사용자에게 HTTP/SSE 기반 MCP 서버를 일괄 제공하도록 하는 managedMcpServers 설정을 도입해 기업 환경에서의 통합 관리를 용이하게 했다.

GitLab 사용자들을 위한 개선 사항도 포함되었다. glab 명령어를 통해 생성되거나 수정된 머지 리퀘스트(MR)가 도구 요약과 푸터 배지에 정확히 반영되도록 인식 로직을 추가했다. 이는 GitLab 워크플로우를 사용하는 개발자들이 코드 변경 사항을 더 직관적으로 추적할 수 있게 해준다. 또한 플러그인 유효성 검사에 --json 옵션을 추가해 기계가 읽을 수 있는 리포트를 출력하도록 하여 자동화 테스트와의 연동을 강화했다.

안정성 측면에서는 다중 세션 실행 시 발생할 수 있던 설정 충돌 문제를 해결하는 데 중점을 뒀다. 이전에는 여러 세션이 동시에 작동할 때 ~/.claude.json 변경 사항이 서로 덮어씌워져 워크스페이스 신뢰 상태나 MCP 프로젝트 정보가 손실되는 문제가 있었으나, 이번 패치로 이러한 현상이 수정되었다. 또한 자동 모드에서 명령어나 스킬의 프론트매터에 명시된 모델과 세션 모델 간 충돌로 인한 오류, 그리고 긴 대화 중 풀스크린 모드에서 화면이 비어 보이는 문제 등 사용자 경험(UX)을 해치는 여러 버그들이 함께 해결되었다.

파일 접근 권한 및 보안 관련 수정 사항도 중요하다. Bash 명령어에서 옵션 값이나 복합 명령어를 통해 접근하는 파일에 대한 읽기 거부 규칙이 제대로 적용되지 않던 문제를 보완해, 민감한 파일에 대한 무단 접근 시도를 더 철저히 차단한다. 또한 OAuth 토큰 갱신 시 프롬프트 캐시가 무효화되던 문제와, 구버전에서 이어진 대화에서 아티팩트 발행이 실패하던 오류 등을 수정해 전반적인 실행 신뢰도를 높였다.
