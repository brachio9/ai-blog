이번 업데이트에서 가장 눈에 띄는 변화는 클라우드 세션과 원격 제어 기능의 강화다. 이제 엔터프라이즈 환경에서 맞춤형 역할을 통해 클라우드 세션 접근 권한을 세부적으로 제어할 수 있으며, 클라우드 환경 설정 스크립트를 파일에서 직접 불러오는 기능이 추가되었다. 또한 세션 시작 시 체크리스트에서 설정 스크립트의 출력 결과를 확인할 수 있도록 사용자 인터페이스가 개선되었다.

개발 환경의 편의성을 높이는 다양한 버그 수정과 성능 개선도 포함되었다. 대규모 트랜스크립트 파일 처리 시 메모리 사용량이 최적화되었으며, 프롬프트가 너무 길어 오류가 발생했을 때 대화 내용이 과도하게 압축되어 다음 요청이 실패하는 문제를 해결했다. 또한 특정 게이트웨이에서 발생하는 요청 실패 문제를 해결하기 위해 불필요한 베타 값이나 시스템 메시지를 제외하고 재시도하는 로직이 추가되었다.

사용자 경험을 세밀하게 다듬은 부분도 많다. VSCode 환경에서 계획 검토 버튼의 동작 오류가 수정되었고, 리눅스 환경에서 샌드박스 실행 시 발생하는 AppArmor 제한에 대한 안내가 구체화되었다. 터미널 환경에서 이미지 렌더링이 개선되었으며, 파일 읽기 권한 요청 시 심볼릭 링크의 경로를 정확히 표시하도록 수정되었다.

이번 릴리즈는 전체 업데이트 내용 중 핵심적인 기능 개선과 버그 수정 사항만을 요약한 것이다. 상세한 기술적 변경 사항이나 세부적인 버그 수정 목록은 공식 릴리즈 노트를 참조해야 한다.
