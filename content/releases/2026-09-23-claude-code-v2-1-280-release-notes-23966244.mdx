이번 업데이트의 가장 큰 변화는 Claude Opus 5.5 모델이 추가되어 기본 오퍼스 모델로 지정된 것이다. 이 모델은 100만 토큰의 컨텍스트 윈도우를 지원하며, 캐시 읽기 시 $0.20/Mtok의 비용으로 효율성을 높였다. 풀스크린 모드에서도 사용 편의성이 개선되어, `/skills` 목록 스크롤과 `/plugin` 상태 옵션 클릭 등 마우스 조작이 더 자연스럽게 지원된다. 또한 MCP 도구 설명 및 서버 지침의 길이 제한을 환경변수로 조정할 수 있게 되어 긴 지시사항 처리가 유연해졌다.

자동 모드(auto mode)의 안정성이 크게 향상되었다. 이전에는 안전성 검사에서 거절당하거나 응답이 없을 때 액션을 무한정 반복 시도하는 문제가 있었으나, 이제 한 번 거절되면 재시도를 중단하고 연속 실패 시 턴을 종료하는 로직으로 변경되었다. 이는 불필요한 리소스 소모를 막고 사용자의 의도를 더 명확히 반영한다. 또한 심볼릭 링크 경로에서의 파일 쓰기 권한 판단 오류가 수정되어, 트리 외부로의 쓰기가 잘못 승인되는 문제가 해결되었다.

인터페이스 및 입력 처리 관련 버그들도 광범위하게 수정되었다. 대화 상자에서 Ctrl+C나 Ctrl+D를 두 번 눌러도 프로그램이 종료되지 않고 대화상자만 닫히며, 우연히 누른 'n'이나 'y' 키가 대화상자를 닫거나 확인하는 오류가 제거되었다. 텍스트 입력 시 특정 키바인딩으로 인해 글자가 삭제되거나, 윈도우 터미널에서 보이지 않는 문자 제거 후 프롬프트 라인이 깨지는 현상도 해결되어 정확한 텍스트 전송이 보장된다.

다국어 지원 및 음성 인식 기능에서도 개선점이 있다. 페르시아어와 아랍어에서 접미사를 붙일 때 사용하는 영점 너비 논조이너(zero-width non-joiner)가 잘못 제거되는 문제가 수정되었다. 또한 음성 독트레이션 중 Ctrl+C로 마이크 녹음이 멈추지 않거나, Esc 키로 처리 중인 전사본을 취소하지 못하는 문제 등이 해결되어 더 매끄러운 음성 입력 경험을 제공한다. 호스트 앱에서 모델 변경 시 프롬프트 캐시 미스 현상도 개선되었다.
