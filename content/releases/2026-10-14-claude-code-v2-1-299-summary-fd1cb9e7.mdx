이번 업데이트의 가장 큰 변화는 대화 컨텍스트 관리 방식이다. 터미널에서 약 54분간 활동이 없으면 20만 토큰 이상의 대화 기록이 자동으로 압축되어, 다음 메시지 입력 시 전체 내용을 다시 처리하는 부담을 줄인다. 이는 1시간짜리 프롬프트 캐시 만료 전에 작동하며, 설정 파일을 통해 최소 토큰 수를 조정하거나 기능을 완전히 비활성화할 수 있다. 또한 파일 언급(@) 시 파일 내용 대신 경로만 전달하도록 변경되어, 파일 도구 사용 시의 효율성을 높였다.

모딩(Modding) 환경에서의 제어력이 강화되었다. 관리형 설정으로 설치된 모드는 이제 첨부된 이미지나 문서의 바이트 데이터를 직접 읽을 수 있게 되었으며, 세션의 로그인 상태와 조직 정보를 식별할 수 있는 함수가 추가되었다. 텍스트 및 박스 컴포넌트에 글꼴 크기, 가중치, 등폭 여부 등 더 세밀한 스타일링 옵션이 지원되고, 기존 bold 속성은 weight로 대체되었다. 또한 모드의 skill.prompt 훅에서 프론트매터와 소스 정보 등을 확인할 수 있어 디버깅과 로깅이 용이해졌다.

에이전트 뷰와 운영 측면에서도 개선점이 있다. 에이전트 뷰에서 /effort와 /fast 명령을 통해 새 세션의 기본 설정을 빠르게 변경할 수 있으며, 백그라운드 세션의 안전 모드 여부를 패널에서 확인할 수 있다. 자체 호스팅 러너 오케스트레이터에는 graceful shutdown을 위한 대기 시간 옵션이 추가되어, 종료 신호 수신 시 진행 중인 작업이 완수될 시간을 보장한다. 플러그인 평가 시 특정 빌트인 도구를 제외하는 기능도 도입되어 테스트 환경의 격리 수준이 높아졌다.

기존 버그 수정과 안정성 개선도 포함되었다. 클라우드 세션 거부 오류 시 잘못된 조직을 가리키는 문제가 해결되었으며, 커스텀 엔드포인트 사용 시 20만 토큰 근처에서 발생하는 자동 압축 실패 오류가 수정되었다. 또한 헤드리스 모드에서 모드가 프롬프트를 계속 제출하는 경우의 메모리 누수 문제도 패치되었다. 이번 릴리즈는 전체 변경 사항 중 주요 기능 위주로 추려낸 것이며, 상세한 커밋 목록이나 기여자 명단은 공식 릴리즈 노트를 참고해야 한다.
