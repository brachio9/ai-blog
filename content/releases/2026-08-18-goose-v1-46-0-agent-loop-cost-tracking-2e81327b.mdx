이번 릴리즈의 핵심은 에이전트 실행 루프의 구조적 개선이다. 기존 방식에서 벗어난 새로운 에이전트 루프 구현으로 시스템의 안정성과 예측 가능성이 높아졌다. 특히 캐시 사용 시에도 컨텍스트가 안전하게 유지되도록 요청 조립 방식을 변경해, 반복 작업 시 불필요한 토큰 소모를 줄이고 비용 정산의 정확도를 높였다.

비용과 사용량 추적 기능이 대폭 강화되었다. 이제 각 메시지별로 소비된 토큰 수, 비용, 첫 토큰 응답 시간(TTFT), 초당 토큰 처리 속도 등을 실시간으로 확인할 수 있다. 캐시된 토큰까지 포함해 세션 전체의 누적 비용을 정확히 산출하므로, 개발자가 모델 호출에 드는 실제 비용을 투명하게 파악할 수 있게 되었다.

사용자 인터페이스와 작업 흐름도 개선되었다. 명령어 실행 중 셸 출력을 스트리밍 방식으로 바로 볼 수 있어 대기 시간이 줄었다. 사이드바 너비를 자유롭게 조절하고 세션 정보를 마우스 오버로 빠르게 확인할 수 있으며, 단일 선택형 입력 시 대화식 메뉴를 통해 더 직관적으로 상호작용할 수 있다. 또한 로컬 음성 인식의 다국어 지원과 내장 스킬 비활성화 옵션 등 환경 설정의 유연함도 늘었다.

이 외에도 에이전트의 목표 달성 여부를 스스로 평가하는 '/goal' 명령어와 상태 확인용 '/status' 명령어가 추가되어 작업 흐름을 더 잘 통제할 수 있게 되었다. OpenTelemetry와의 통합이 강화되어 GenAI 관련 속성을 더 풍부하게 기록하며, Termux 환경에서의 설치 안정성도 개선되었다. 이 요약은 주요 변경 사항 중 일부를 다루며, 전체 커밋 목록이나 기여자 명단은 포함하지 않는다.
