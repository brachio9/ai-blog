Unsloth는 최신 릴리즈를 통해 Qwen3.8-Flash와 GLM-5.3-Flash 모델에서 MTP(Multi-Token Prediction) 기능을 기본 활성화했다. 이로 인해 해당 모델들의 추론 속도가 최대 2배까지 빨라졌으며, 사용자는 필요시 이를 비활성화할 수 있다. Unsloth 측은 이번 업데이트가 단순한 속도 개선을 넘어 로컬 서버 및 연결된 제공자 간 모델 로딩의 안정성을 높이고, 대화 수정 시 도구 카드나 응답 세부사항이 유지되도록 하는 등 사용자 경험을 전반적으로 개선했다고 밝혔다.

Apple Silicon 환경에서의 MLX 추론 성능도 크게 강화되었다. 대규모 MoE 모델을 텍스트 또는 이미지로 파인튜닝하는 과정이 지원되며, Qwen 모델의 긴 대화 후속 턴 처리 속도가 최대 30배까지 빨라졌다. 또한 MLX 모델이 전체 컨텍스트 크기를 활용하고 더 긴 배치 생성을 지원하며, 생성 간 GPU 메모리 해제가 더 깔끔하게 이루어지도록 최적화되었다. 이를 통해 Unsloth의 OpenAI 호환 API를 통한 MLX 모델 서빙도 원활해졌다.

오디오 및 멀티모달 기능에서도 주목할 만한 변화가 있었다. MiniMax-Music3, Higgs, MOSS 등 새로운 오디오 모델이 지원되며 오디오 생성 중 실시간 진행 상황 확인과 클립 관리 기능이 추가되었다. 대화 도구 사용 측면에서는 여러 도구 호출의 인자 혼동을 방지하고, 이미지 대화 중에도 도구 접근성을 유지하며, 각 대화별 MCP 연결을 통해 도구 호출 속도를 높였다. 또한 로컬 모델이 Codex의 apply_patch 도구를 이용해 코드를 수정할 수 있게 되었고, Deep Research 실행 전 계획 검토 및 승인 기능이 강화되었다.

하드웨어 및 학습 환경 개선도 병행되었다. 여러 GPU에 걸친 대형 모델 학습 시 자동 배치 기능이 개선되었고, AMD/ROCm 환경에서의 설치 및 호환성 검출이 강화되어 더 많은 GPU에서 BF16 지원을 가능하게 했다. GLM-5.3의 MLX 파인튜닝 결과를 GGUF로 내보내는 기능과 사용자 정의 샤드 크기 설정도 추가되었다. Unsloth는 이번 릴리즈가 170여 가지에 달하는 훈련, 채팅, 하드웨어, 성능 관련 개선 사항을 포함하고 있으며, 이는 전체 변경 사항 중 주요 부분만 추린 것이라고 명시했다.
