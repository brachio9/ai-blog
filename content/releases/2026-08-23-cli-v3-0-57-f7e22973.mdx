이번 업데이트는 클라인 허브의 운영 안정성에 집중했다. 새로운 `cline hub drain` 명령어로 진행 중인 작업이 완료될 때까지 신규 작업을 일시 중단할 수 있게 되었다. 특히 `cline hub upgrade` 명령어는 이 드레인 기능을 자동으로 활용하여, 현재 실행 중인 작업이 모두 끝날 때까지 기다린 후 새 버전으로 재시작한다. 업그레이드 중 중단이 발생하더라도 드레인 상태가 해제되어 허브가 작업을 거부하는 상황이 발생하지 않도록 설계되었다.

세션의 지속성도 크게 개선되었다. 이제 허브가 재시동되더라도 기존 세션이 유지된다. 연결이 끊겼던 클라이언트가 다시 접속하면 누락된 이벤트를 이벤트 ID를 기준으로 중복 제거하여 재생한다. 이를 통해 사용자는 작업 흐름을 끊기지 않고 이어갈 수 있으며, 데이터의 일관성도 보장받는다.

또한 커스텀 오픈AI 호환 모델에서 도구 호출이 조용히 비활성화되던 버그를 수정했다. 이전에는 `supportsReasoning` 같은 편의 플래그에서 추론된 기능 목록이 절대적 거부로 인식되어 요청에서 모든 도구가 제거되는 문제가 발생했는데, 이제 정상적으로 작동한다. 또한 랭퓨즈 추적에 세션 및 클라이언트 식별 정보를 포함하여 허브 기반 실행 시에도 정확한 그룹화와 버전 확인이 가능해졌다.

마지막으로 모델 카탈로그가 새로고침되어 여러 제공자의 모델 목록과 가격이 업데이트되었다. 딥시크, 크로프, 크로스모델, 에덴 AI, 킬로, 나노GPT 등 일부 제공자의 기본 모델도 변경되었으므로 최신 설정을 확인하는 것이 좋다. 이번 릴리스에는 언급되지 않은 다른 세부 수정 사항들도 포함되어 있을 수 있다.
