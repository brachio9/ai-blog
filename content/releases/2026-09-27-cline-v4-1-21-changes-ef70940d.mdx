이번 업데이트의 가장 큰 변화는 로컬 모델(llama.cpp, Ollama 등) 사용 시 긴 응답으로 인한 작업 중단 문제를 해결한 것이다. 기존에는 출력 토큰 한계에 도달하면 작업이 종료되었지만, 이제 대화 내용을 압축하고 한 번 재시도하여 작업을 계속할 수 있게 되었다. 이는 로컬 서버가 남은 컨텍스트만큼만 생성하는 특성을 고려한 조치로, 부분적인 답변이라도 유지하면서 오류 회피 능력을 높였다.

모델 카탈로그가 대대적으로 갱신되면서 209개 제공자에 걸쳐 6,386개의 모델이 등록되었다. 특히 GitHub Copilot과 Vertex AI 등 19개 제공자 중 11곳의 기본 모델이 Claude Opus 5.5로 변경될 수 있으므로, 특정 모델을 고정하지 않고 사용하는 사용자는 예상치 못한 모델 변경에 주의해야 한다. 이는 사용자가 명시적으로 모델을 선택하지 않았을 때 적용되는 기본값의 변화다.

사용성 측면에서도 여러 개선점이 있다. 실패한 작업을 다시 열면 완료된 것처럼 보이기보다 오류와 재시도 옵션을 명확히 보여주며, 빈 결과를 반환하는 명령어의 경우 불필요한 JSON 데이터를 출력하지 않는다. 또한 윈도우 환경에서 @멘션 검색 시 중첩된 파일 경로가 잘못 표시되거나 중복되는 문제가 수정되어 정확한 파일 이름을 확인할 수 있게 되었다.

보안 측면에서는 룰과 스킬 프론트매터를 파싱하는 데 사용되는 js-yaml 라이브러리의 최소 버전을 4.3.2로 상향 조정하여 보안 취약점을 패치했다. 요청 취소 기능도 개선되어 백오프 대기 중에도 즉시 취사가 적용되도록 했다. 이번 릴리스는 전체 변경 사항의 일부만 다루었으며, 더 많은 세부 사항은 공식 저장소의 변경 로그를 참고할 수 있다.
