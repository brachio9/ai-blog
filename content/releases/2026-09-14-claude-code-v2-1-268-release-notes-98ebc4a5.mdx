기업 환경에서 Claude Code를 사용하는 사용자에게 가장 큰 변화는 게이트웨이 관련 기능이다. 이제 gateway.yaml에 pricing 설정을 추가하면 로그인한 클라이언트도 관리된 설정과 동일한 요금제를 적용받게 되며, 이는 /cost 명령어와 텔레메트리 데이터가 실제 사용량 미터링과 정확히 일치하도록 보장한다. 또한 접근 제어 목록이 비어 있거나 공개 IP에서 요청이 들어올 때 시작 경고와 일회성 경고를 표시하여 관리자가 보안 설정을 확인하기 쉽게 했다. 조직의 자체 IPv4 블록에 대한 게이트웨이 로그인 허용도 새로운 관리 설정으로 추가되었다.

안정성과 성능 측면에서도 중요한 수정 사항이 많다. 최근 버전에서 발생하던 제3자 Anthropic 호환 엔드포인트에서의 HTTP 400 오류를 입력 스키마 정규식 문제로 인해 해결했으며, 응답이 완료되지 않는 서버에 대해 WebFetch가 무한 대기하는 문제를 300초 타임아웃으로 제한했다. 또한 장시간 실행 중인 세션에서 CPU 코어를 점유하던 버그와 터미널 포커스 리포트로 인한 고부하 현상이 수정되어 시스템 자원을 더 효율적으로 사용하게 되었다.

보안과 권한 관리의 신뢰성도 크게 향상되었다. macOS와 Linux의 심볼릭 링크된 디렉토리(예: /etc, /tmp)에 대한 읽기 및 편집 금지 규칙이 실제 경로로 접근할 때 우회되는 문제가 수정되었으며, env나 eval 같은 명령어가 포함된 라인에서 권한 체크가 제대로 작동하지 않던 케이스도 해결했다. 또한 플러그인 설치 및 관리 명령어에 JSON 출력 옵션을 추가하고, 인증 상태 확인 시 설정 디렉토리 정보를 제공하여 스크립트 자동화가 더 수월해졌다.

마지막으로 사용성 개선 사항으로는 브라우저 탭 아이콘이 생성된 아티팩트 페이지에 맞게 자동으로 선택되도록 변경되었다. SDK 세션에서 프롬프트 캐싱과 확장 사고 기능이 중단되는 문제, 모델 접근 권한 캐시 오류로 인한 잘못된 제한 메시지 표시 문제 등도 수정되어 더 매끄러운 개발 경험을 제공한다. 이 요약은 주요 변경 사항 중 일부를 추린 것이므로 전체 릴리즈 노트는 공식 출처를 참고해야 한다.
