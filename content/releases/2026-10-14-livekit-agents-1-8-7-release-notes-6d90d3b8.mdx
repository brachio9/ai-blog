이 릴리즈에서 가장 주목할 만한 기능은 실시간 종단간 지연 측정이다. 로컬 VAD를 구성하면 마지막 사용자 발화 감지부터 어시스턴트 재생 시작까지의 시간을 정확히 잴 수 있다. 개발자는 어시스턴트 메시지 메트릭에서 e2e_latency 값을 읽어 이 지표를 확인할 수 있으며, 대화 품질 개선에 유용한 데이터가 된다.

모델 지원 측면에서는 Anthropic SDK 업그레이드를 통해 Claude Opus 5, Opus 5.5, Sonnet 5.5 모델을 사용할 수 있게 되었다. 이는 최신 언어 모델의 성능을 실시간 에이전트 환경에서 바로 활용 가능함을 의미한다. 또한 Google의 불변 컨텍스트 모델에 대한 지시문 없는 실시간 응답이 허용되며, ElevenLabs STT 클라이언트 오류 처리가 개선되어 재시도 없이 실패 상태로 유지되도록 변경되었다.

주요 변경 사항 중에는 텔레메트리 구조의 평탄화가 포함되어 있다. 폴백 속성이 어댑터 요청 스패인으로 이동했으므로 기존 추적 쿼리를 수정해야 할 수 있다. Anthropic 커스텀 HTTP 클라이언트는 httpx2를 사용해야 하며, OpenTelemetry는 제거된 Events API 대신 LogRecord를 사용하도록 변경되었다. 이러한 브레이킹 체인지는 모니터링 및 로깅 시스템의 안정성을 높이는 방향으로 진행되었다.

기타 개선 사항으로는 TLS 컨텍스트 캐싱 최적화, 인터럽션 타임아웃 시 도구 실행의 비동기 처리 지속, 그리고 녹음 종료와 VAD 리사이징 등의 신뢰성 향상이 있다. 의존성 버전도 OpenAI, MCP, websockets 등 주요 라이브러리에 대해 특정 범위 내에서 업데이트되었다. 전체 변경 목록은 공식 릴리즈 노트를 참고하되, 위 사항들이 이번 버전의 핵심이다.
