vibe 코딩을 하다 보면 가장 짜증나는 순간 중 하나가 갑자기 끊겨버리는 대화 흐름이다. 이번 업데이트는 특히 PDF나 이미지 같은 대용량 도출 결과를 다룰 때 발생하던 'Autocompact is thrashing' 오류를 수정했다. 클라우드 세션에서 `/autocompact` 명령 후 기본 창으로 돌아가거나, `/clear`로 지운 대화 기록이 세션 재시작 시 다시 나타나는 버그도 해결되어 맥락 관리가 훨씬 안정적으로 작동한다.

MCP(Model Context Protocol) 서버와의 연결 문제도 집중적으로 개선되었다. macOS 키체인이 잠겨 있거나 컴퓨터가 절전 모드에 진입하는 상황에서 MCP 서버가 타임아웃되거나 인증 오류를 내보내던 문제가 해결됐다. 이제 연결 중 끊긴 HTTP 도구 호출은 읽기 전용 또는 멱등성(idempotent) 도구만 재시도하도록 제한되어 불필요한 중복 요청을 방지한다. 또한 Agent SDK를 통한 모델 변경 시 API 응답 대기 시간을 5초에서 15초로 연장하여 모델 전환이 거절되는 현상을 줄였다.

클라우드 환경과 게이트웨이 사용자를 위한 수정 사항도 포함됐다. Foundry나 커스텀 앤스로픽 베이스 URL을 사용할 때 무의미하게 전송되던 베타 헤더 전송을 중단했고, 클라우드 세션에서 WebFetch 도구가 4xx 상태 코드나 robots.txt 거부를 도구 오류로 잘못 보고하던 문제를 정상 결과로 처리하도록 고쳤다. 또한 `/permissions` 명령에서 최근 거부된 셸 명령어를 명확히 표시하고 승인 로직이 이를 올바르게 인식하도록 하여 자동 모드에서의 권한 관리 신뢰성을 높였다.

이 외에도 OpenTelemetry 이벤트 추적 정밀도 향상, 서브에이전트 트랜스크립트의 토큰 사용량 기록 오류 수정, 데스크톱 앱의 코드 탭에서 GitHub MCP 쓰기 도구 폼이 비정상적으로 닫히던 문제 등 다양한 버그 픽스가 적용되었다. 전체 커밋 목록은 공식 릴리즈 노트를 참고하되, 이번 업데이트는 주로 개발자의 집중력을 해치던 연결 끊김과 맥락 손실 문제를 해결하는 데 초점을 맞췄다.
