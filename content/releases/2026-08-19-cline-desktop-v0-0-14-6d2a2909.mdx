이제 Cline은 백그라운드에서 작업을 수행하는 동안 완료나 입력 요청 시 macOS 네이티브 알림을 보낸다. 설정의 알림 메뉴에서 이를 구성할 수 있으며, 덕분에 사용자는 앱을 최소화한 채도 에이전트의 진행 상황을 파악하고 필요한 순간에만 개입하면 된다.

음성 입력 기능이 도입되어 마이크 버튼을 통해 말한 내용을 실시간으로 텍스트로 변환한다. 이는 사용자가 별도로 설정해 둔 제공자와 모델을 그대로 사용하므로 기존 워크플로우에 자연스럽게 녹아든다. 또한 이미지 생성이 가능한 모델은 작업 중 이미지를 생성하고 이를 트랜스크립트 내에 인라인으로 렌더링하여 결과를 즉시 확인할 수 있게 되었다.

명령어 실행 시 출력이 종료 후 한 번에 뜨는 것이 아니라 스트리밍 방식으로 실시간으로 표시되며, 터미널 색상 유지와 스크롤 기능이 개선되었다. 장시간 걸리는 명령어는 'Proceed while running' 옵션을 통해 백그라운드로 보내 에이전트가 다른 작업을 계속 진행하도록 할 수 있다. 완료된 에이전트 실행 기록은 시간과 도구 호출 횟수를 요약한 단일 항목으로 접히므로 최종 답변이 묻히지 않고 상단에 유지된다.

UI 측면에서는 질문 카드가 다중 선택과 키보드 단축키를 지원하며 불필요한 내부 ID 표시를 제거해 더 깔끔해졌다. 웹 검색 토글은 현재 연결된 제공자 중 어떤 것이 해당 기능을 지원하는지 명확히 안내한다. 또한 베타 버전인 'Cline Code Beta' 앱이 별도로 설치되어 실험적 기능을 테스트할 수 있으며, 스트리밍 오류와 자동 승인 모드 관련 버그도 수정되었다.
