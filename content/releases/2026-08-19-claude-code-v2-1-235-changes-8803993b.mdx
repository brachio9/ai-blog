프롬프트 입력창에서 오타를 실시간으로 확인하는 기능이 생겼다. 시스템에 설치된 aspell이나 hunspell 같은 도구를 활용하여 틀린 단자를 밑줄로 표시해 준다. 이는 복잡한 지시를 작성할 때 실수를 줄이고 의도를 정확히 전달하는 데 도움이 된다.

백그라운드에서 클라우드 세션이 실행될 때 메모리와 CPU 사용량이 개선되었다. 특히 /ultrareview나 /autofix-pr 같은 명령어를 사용할 때 이벤트 스트림을 매번 다시 스캔하고 렌더링하지 않아 리소스 낭비를 막는다. 이는 장시간 코드 리뷰나 자동 수정 작업을 수행할 때 시스템 부하를 낮추는 데 중요하다.

터미널 UI와 대화상자의 안정성도 높아졌다. 중첩된 마크다운 목록의 정렬 오류, 멀티라인 프롬프트에서의 하이라이트 위치ずれ, 그리고 권한 승인 대화상자에서 Shift+Tab 키가 의도치 않게 전체 편집 권한을 부여하던 버그들이 수정되었다. 또한 맥북이나 리눅스 환경 내장 grep 명령어의 메모리 과다 사용 문제도 해결되어 패턴 매칭이 더 안정적으로 작동한다.

기타 여러 작은 개선 사항들도 포함되었다. 비메모리 모드에서 커서 위치가 유지되고, 대화상자 키보드 네비게이션 반응 속도가 빨라졌다. 원격 제어 시 엔터프라이즈 게이트웨이 확인 절차가 일관되게 적용되며, VSCode 확장 프로그램의 탭 포커스 이동 문제도 해결되었다. 전체 변경 사항 중 주요 기능과 안정성 개선만 선별하여 정리한 것이다.
