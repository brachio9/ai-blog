이번 릴리즈는 주로 버그 수정과 안정성 강화에 집중했다. 풀스크린 렌더러가 한 번 실패하면 영구적으로 작동하지 않던 문제가 해결되어, 이제 고전 렌더러로 폴백 처리된다. 또한 터미널 리사이즈 후 메시지가 늦게 표시되거나 프롬프트 위에 빈 공간이 남는 등의 시각적 결함들이 수정되었다. tmux 환경에서 탭 제목이 불필요하게 깜빡이는 현상도 텍스트 변경 시에만 업데이트되도록 개선되어 사용자의 집중을 방해하지 않는다.

보안과 설정 관련 개선 사항도 포함되었다. macOS 샌드박스 환경에서 와일드카드 기반의 읽기 금지 규칙(예: `**/.env`)이 허용된 영역 내에서도 우선 적용되며, 파일 이름 변경으로 우회하는 것을 막았다. 새로운 환경 변수 `ANTHROPIC_DEFAULT_MODEL`이 추가되어 새 세션의 기본 모델을 설정할 수 있게 되었으며, 이는 `/model` 명령으로 선택한 모델보다 낮은 우선순위를 가진다. 또한 같은 머신에서 실행 중인 다른 Claude Code 세션이 유휴 상태가 될 때 한 번만 알림을 보내주는 `notify_when_idle` 기능이 도입되어 멀티 세션 작업 시 효율성을 높였다.

기존 버그들도 광범위하게 수정되었다. 세션이 전환된 디렉토리가 삭제되었을 때 클립보드 복사나 로컬 MCP 로그 작성이 중단되던 문제가 해결되었으며, WSL 환경에서 서브프로세스 시작 실패로 인한Unhandled Promise Rejection 오류도 잡았다. `/model` 선택기가 터미널 높이보다 커지는 문제와 요약 필드에 메시지 텍스트가 잘못 들어가는 버그도 수정되었다. 또한 자동 모드에서의 모니터 할당 로직이 개선되어 더 원활한 경험을 제공한다.

성능 측면에서는 세션 카운터 기록을 백그라운드에서 처리하여 시작 속도를 높였다. Fable 5의 크레딧 프롬프트가 원격 제어 사용 시 자동으로 폴백 모델을 선택하던 문제와, 캐시된 게스트 패스 리워드 데이터가 손상되었을 때 스피너 팁이 표시되지 않던 오류도 해결되었다. 이 외에도 셀프 호스팅 러너 세션 종료 후 훅 실행 완료 전에 다른 러너에서 재개되던 간헐적 문제와 클라우드 환경 목록이 비어 있을 때 발생하는 모호한 오류 메시지 개선 등 다양한 세부 사항들이 다듬어졌다.
