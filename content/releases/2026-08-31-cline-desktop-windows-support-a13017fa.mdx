클라인 데스크톱이 드디어 윈도우 플랫폼을 공식 지원하기 시작했다. 코드 서명이 적용된 인스톨러를 통해 설치하면 맥OS와 동일한 피드를 통해 자동으로 업데이트된다. 윈도우 환경에서 흔히 발생하던 백그라운드 프로세스의 콘솔 창 팝업 문제도 해결되어, 사이드카나 깃 작업 시 더 깔끔한 경험을 제공한다. 또한 홈 디렉터리 설정이 없을 때 사용자 프로필 경로로 대체되는 등 윈도우 특유의 환경 변수 처리가 개선되었다.

작업 결과물의 가독성이 크게 향상되었다. 브라우저나 MCP 도구를 통해 얻은 스크린샷 같은 이미지 결과물이 더 이상 원시적인 base64 텍스트로 표시되지 않고, 대화창 내에 인라인 이미지로 렌더링된다. 여러 장의 이미지가 있을 경우 캐러셀 형태로 넘겨볼 수 있으며 클릭하면 확대되어 확인 가능하다. 이는 비주얼 피드백이 중요한 에이전트 작업에서 사용자의 인지 부하를 줄이는 중요한 개선 사항이다.

스케줄링 기능의 안정성과 관리 편의성이 크게 높아졌다. 이전에는 앱 업데이트 시 사라지던 예약 작업들이 이제 사용자 홈 디렉터리에 중앙 집중식으로 저장되어 영구적으로 유지된다. 완료된 스케줄 세션은 최종 답변을 마크다운 형식으로 요약해 보여주며, 실패 시에도 명확한 오류 메시지를 표시한다. 또한 오프라인 상태의 원격 MCP 서버가 세션 시작을 막는 버그도 수정되어 작업 흐름이 더 매끄러워졌다.

검색과 설정 관리 기능도 실질적으로 개선되었다. 사이드바 검색 아이콘을 누르면 전체 인덱싱된 히스토리를 서버 측에서 랭킹하여 보여주며, 과거처럼 메모리에 모든 세션을 로드하지 않아 성능이 향상되었다. GitHub 연동 온보딩 단계가 추가되었고, OpenAI Codex 로그인 시 포트 충돌이나 네트워크 오류로 인한 끊김 현상이 해결되어 인증 과정이 더 안정적이다. 전역 규칙 파일 경로 인식 문제도 수정되어 WSL 등 다양한 환경에서 규칙이 제대로 적용되도록 했다.
