이번 업데이트의 가장 큰 변화는 모델 관리 인터페이스에 HuggingFace Hub와의 연동 기능이 도입된 점이다. 이제 사용자는 별도의 도구 없이 애플리케이션 내에서 모델을 검색하고, 메타데이터를 확인하며, GGUF 형식의 모델을 직접 다운로드할 수 있다. 이 기능은 설정에서 활성화해야 사용 가능하며, 탐색 화면과 기존 모델 목록을 자연스럽게 전환할 수 있도록 설계되었다.

다운로드 프로세스의 안정성이 크게 개선되었다. 이전에는 다운로드가 중단되면 파일이 삭제되거나 재시작해야 했으나, 이제는 중단 지점에서 이어서 받을 수 있다. 부분적으로 다운로드된 파일은 콘텐츠 해시로 관리되어 재개 시 정확한 위치에서 이어지며, 다운로드 진행 상황도 더 명확하게 표시된다. 또한 사이드카 파일과 같은 보조 리소스도 독립적으로 캐싱되고 관리되므로 모델 로딩의 신뢰성이 높아졌다.

UI 측면에서는 마크다운 렌더링에 대한 유연성을 높였다. 기본적으로는 안전을 위해 HTML 태그를 이스케이프 처리하지만, 필요시 allowHtml 속성을 통해 DOMPurify로 정제된 원본 HTML을 렌더링할 수 있게 되었다. 이는 모델 설명이나 문서에서 복잡한 포맷이 필요한 경우 유용하게 활용될 수 있다. 이러한 변경 사항들은 모델 탐색과 다운로드 경험을 한층 더 매끄럽고 직관적으로 만드는 데 초점을 맞추고 있으며, 전체 커밋 목록 중 주요한 개선 사항만 다룬 것이다.
