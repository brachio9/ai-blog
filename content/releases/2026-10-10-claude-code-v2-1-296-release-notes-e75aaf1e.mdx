이번 업데이트는 Claude Desktop과 CLI 간의 정책 일관성을 높이는 데 중점을 두었다. `managed.policies`에 `code` 키를 추가하여 데스크톱 앱의 코드 탭에서도 CLI와 동일한 설정을 적용할 수 있게 되었으며, 이를 통해 게이트웨이 모드를 활성화할 수 있다. 이는 조직 내 보안 정책이나 프록시 설정을 일관되게 관리하려는 사용자에게 유용하다.

서브에이전트의 동작 제어 기능이 세분화되었다. 서브에이전트 프론트매터와 에이전트 정의에 `autoCompactWindow` 옵션이 추가되어 메인 대화창보다 먼저 컨텍스트를 압축할 수 있게 되었다. 또한 `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` 환경 변수를 통해 워크플로우 에이전트만 특정 모델로 실행하도록 지정하는 것이 가능해졌다. 이는 비용 최적화나 성능 테스트 시 유용한 기능이다.

파일 처리와 오류 대응 측면에서도 개선이 있었다. Read 도구에 `allow_large` 옵션을 도입하여 컨텍스트 여유가 있을 경우 크기 제한을 초과하는 텍스트 파일을 한 번에 읽을 수 있게 되었다. 네트워크 오버로드(529 에러) 발생 시 백오프 최대 지연 시간을 설정할 수 있는 환경 변수도 추가되어 안정적인 재시도를 지원한다.

이번 릴리즈는 수많은 버그 수정을 포함하고 있다. 주요한 것만 꼽아보면, 헤들리스 세션에서 비활성화된 MCP 서버가 다시 시작되는 문제, 게이트웨이 로그인 관련 회귀 버그, 그리고 특정 터미널에서의 이스케이프 시퀀스 오류 등이 해결되었다. 또한 토큰 카운팅 오류와 훅(hook) 처리 관련 결함들도 수정되어 전체적인 안정성이 향상되었다. 이는 전부가 아니며 상세한 변경사항은 공식 릴리즈 노트를 참고해야 한다.
