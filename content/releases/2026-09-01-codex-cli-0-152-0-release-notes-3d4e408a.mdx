이번 업데이트는 특히 Vim 모드를 사용하는 개발자의 편의를 높이는 데 집중했다. 이제 초안 작성 중 `/`와 `?` 키로 텍스트 검색이 가능해졌으며, 일치하는 항목이 하이라이트되고 `n`, `N` 키로 반복 탐색할 수 있다. 또한 메시지 전송이나 슬래시 명령어 실행 후에도 새 초안이 인서트 모드로 시작되므로 작업 흐름이 끊기지 않는다.

자동 승인(Automatic Approval) 기능의 신뢰성도 크게 향상되었다. 대화 기록 압축 시에도 사용자의 지시사항과 승인 권한이 유지되며, 더 긴 메시지와 대화 전사본을 보존할 수 있게 되었다. 이는 장기적인 세션에서도 컨텍스트가 유실되는 문제를 해결하여 자동화 파이프라인의 안정성을 높이는 데 기여한다.

MCP(Model Context Protocol) 관련 개선 사항도 눈에 띈다. 서버 이름에 콜론, 아틀릿, 슬래시 등 더 다양한 특수 문자를 사용할 수 있어 패키지 스타일 네이밍을 지원하며, 개별 도구별 출력 토큰 제한 설정이 세션 재개 시에도 일관되게 적용된다. 또한 인증 갱신 과정의 진행 상황을 터미널 UI와 `codex exec` 명령어에서 실시간으로 확인할 수 있게 되었다.

성능과 안정성 측면에서는 플러그인 추천 목록이 시작 단계부터 미리 로드되어 첫 턴(Turn) 지연을 줄였다. 계획 도구(Planning Tool)는 기본 비활성화 상태로 변경되어 명시적 활성화가 필요하며, Windows 샌드박스 실행 및 모델 선택기 리프레시 시 발생하는 버그들도 수정되었다. 전체 변경 내역은 공식 저장소의 비교 링크를 통해 확인할 수 있다.
