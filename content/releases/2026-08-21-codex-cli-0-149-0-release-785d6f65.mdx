이번 업데이트의 가장 큰 변화는 `codex agents` 대시보드의 등장이다. 이제 사용자는 복잡한 명령어 대신 인터페이스를 통해 에이전트 작업을 검색하고 시작하며 이름도 변경할 수 있다. 중단된 작업 재개나 정지 역시 설정 가능한 단축키로 간편하게 처리할 수 있어, 다중 에이전트 환경에서의 관리 부담이 크게 줄었다.

터미널 사용자 인터페이스(TUI)의 편의성도 한층 높아졌다. `/cd`, `/pwd`, `/cwd` 명령어를 통해 세션 내에서 작업 디렉토리를 직접 제어할 수 있게 되었으며, Vim 편집 기능이 문자 교체와 다양한 변경 동작을 지원하도록 확장되었다. 또한 `codex queue` 명령어를 통해 기존 로컬 또는 원격 세션에 메시지를 보내는 것이 가능해져, 비동기적 협업이나 백그라운드 작업 지시가 더 자연스럽다.

안정성과 디버깅 기능도 강화되었다. `codex doctor`가 엔드포인트 보호 설정, 네트워크 및 프록시 오류, 데스크톱 앱 상태 등을 종합적으로 진단하도록 개선되어 문제 해결이 용이해졌다. 대기열 메시지가 유휴 세션을 안정적으로 깨우는 방식과 서브 에이전트 활동의 중복 실행 방지 등 핵심 버그들이 수정되며 전체적인 실행 신뢰도가 향상되었다.

SDK 사용자들을 위한 기능도 업데이트 되었다. 타입스크립트 SDK를 통해 CLI 구성 설정을 정확히 오버라이드하거나 추론 노력을 'max' 또는 'ultra'로 선택할 수 있는 옵션이 추가되었다. 이는 개발자가 코덱스 에이전트의 동작을 더 세밀하게 제어하고 통합하는 데 도움이 될 것이다. 이번 릴리스는 이러한 주요 기능 개선과 버그 수정에 초점을 맞추었으며, 전체 변경 내역은 공식 저장소에서 확인할 수 있다.
