이번 업데이트는 개발자가 Claude Code의 자동 모드를 자신의 프로젝트에 맞게 빠르게 적응시킬 수 있도록 돕는다. 새로 추가된 '/auto-mode-setup' 명령은 현재 프로젝트 구조와 최근 세션 기록을 분석해 환경 정보를 학습시킨다. 이 기능은 이제 Bedrock, Vertex, Foundry 등 다양한 플랫폼과 원격 측정 비활성화 세션에서도 사용할 수 있게 됐다. 또한 '/claude-api managed-agents-secure' 명령을 통해 Managed Agents 에이전트의 설정이 Anthropic의 공식 보안 가이드와 일치하는지 확인할 수 있으며, 이 과정에서 실제 설정 변경은 발생하지 않는다.

플러그인 및 모드 관련 동작도 더 투명해졌다. 특정 플러그인이 먼저 실행되어 모드의 훅(hook)을 건너뛸 경우, 트랜스크립트에 해당 이벤트명과 플러그인 이름이 명시되므로 어떤 단계가 생략되었는지 쉽게 파악할 수 있다. 도구 사용 권한 확인 시 'decider: person' 옵션을 추가해 승인 요청이 반드시 사람이나 호스트 콜백에 의해서만 처리되도록 강제하며, 승인자가 없을 경우 모드의 이유를 들어 거절한다. 또한 읽기 전용 도구 호출 여부를 식별하는 'e.isReadOnly' 속성도 지원한다.

안정성 측면에서 여러 버그가 수정됐다. 리눅스 환경에서 샌드박스 파일 시스템 접근 제한 패턴에 대괄호가 포함된 경로 폴더가 있을 때 명령 실행이 실패하던 문제가 해결되었다. 마운트된 드라이브나 최상위 폴더 삭제 시 안전 경고가 표시되지 않던 오류도 수정되어 'rm -rf /Applications'와 동일한 수준의 보호를 받는다. 또한 디스크 공간 부족으로 트랜스크립트 파일 정리 중 메시지가 유실되던 현상과, 플러그인 재로드 실패 시 기존 도구가 사라지거나 상태 메시지가 잘못 표시되던 문제들이 개선되었다.

사용자 경험 측면에서도 편의성이 높아졌다. Pro 및 Max 요금제 사용자는 비활성화된 대화 재개가 5시간 사용 한도의 상당 부분을 차지할 경우 경고 메시지를 받게 되며, 새 대화를 시작하더라도 이전 내용을 참조할 수 있도록 안내된다. 파일 경로 표시가 작업 디렉토리 외부 파일을 '..'로 혼란스럽게 보여줬던 문제가 '~' 또는 전체 경로로 명확히 표시되도록 수정되었다. 원격 제어 세션에서 다른 계정으로 로그인 시 대화 기록이 영구적으로 차단되거나, 클라우드 세션에서 특정 메뉴 선택 시 스킬이 실행되지 않던 문제들도 해결되어 더 원활한 협업 환경을 제공한다.
