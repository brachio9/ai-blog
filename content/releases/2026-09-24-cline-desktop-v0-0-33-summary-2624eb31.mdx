이제 새로운 태스크는 별도의 git worktree에서 실행되어 현재 작업 중인 트리를 건드리지 않는다. 웰컴 화면에서 'Worktree' 옵션을 선택하면 에이전트는 독립된 브랜치와 디렉토리를 생성해 작업을 수행하며, 태스크 삭제 시 해당 환경도 함께 정리된다. 이는 기존 세션이나 팔로우업 대화에는 적용되지 않으며, 오직 새로 시작하는 스레드에서만 작동한다.

긴 대화 세션이 자동으로 압축되도록 개선되어 더 이상 공간 부족으로 중단되지 않는다. 이전 버전에서는 사이드카가 체크포인트는 설정했지만 압축 기능은 활성화하지 않아 90% 트리거가 작동하지 않는 문제가 있었다. 이번 업데이트로 이 간극이 메워져 데스크톱 앱에서도 장시간 사용 시 자동으로 세션이 정리된다.

윈도우 환경에서 이미 실행 중인 앱을 다시 열면 새 인스턴스가 생성되지 않고 기존 창이 앞으로 나오도록 수정했다. 또한 앱을 닫을 때 트레이 아이콘으로 최소화되며, 시작 메뉴나 단축키를 통한 재실행 시 중복 프로세스가 생성되는 문제도 해결되었다. Cline 베타 버전은 안정화 버전과 병행하여 실행할 수 있다.

기타 버그 수정 사항으로는 앱 초기화 중 로그인 시도 시 발생하는 오류를 해결하고, SSH 원격 호스트에서 새 채팅 시작 시 'Unknown session' 에러가 나는 문제를 고쳤다. 맥OS의 경우 앱 메뉴와 트레이 메뉴에 업데이트 확인 기능을 추가했으며, 현재 보고 있는 세션을 삭제하면 새 태스크 화면으로 이동하도록 개선되었다.
