이번 업데이트에서 가장 눈에 띄는 변화는 Claude Opus 및 Sonnet 모델을 사용할 때 지원되는 플랫폼의 확대다. 이제 Amazon Bedrock, Google Cloud Agent Platform, Microsoft Foundry 및 Claude 앱 게이트웨이에서 자동 모드를 사용할 수 있으며, 권한 승인 모드가 없는 상호작용 세션이 이 모드로 시작된다.

개발 환경의 안정성을 높이기 위한 기능도 추가되었다. MCP 도구 훅(hook) 호출 실패 시 동작을 차단하는 설정이 도입되었고, 클라우드 세션에서 메시지가 유실될 수 있는 상황에 대한 경고 기능이 강화되었다. 또한 특정 환경에서 발생하던 Bash 명령어 인식 오류나 마크다운 렌더링 프리징 현상 등 사용자 경험을 저해하는 여러 버그가 수정되었다.

자가 호스팅 러너(Self-hosted runner)를 사용하는 사용자들을 위한 세부적인 개선 사항도 포함되었다. 저장소 폴더 지정 방식이 개선되었고, 세션 관리 및 메트릭 수집을 위한 새로운 파라미터와 지표들이 추가되어 운영 효율성을 높였다. 이번 릴리스는 전체 업데이트 내용 중 주요 기능과 버그 수정 사항을 중심으로 요약한 것이며, 세부적인 변경 사항은 공식 릴리즈 노트를 참조해야 한다.
