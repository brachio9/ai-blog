Claude Code v2.1.327 버전에서는 사용자 작업의 안전성을 확보하기 위한 장치들이 대폭 강화되었다. 이제 GitHub 앱 설치 시 저장소가 변경되는 것을 미리 확인하는 단계가 추가되었으며, 파일 내보내기 시 기존 파일이 덮어씌워지는 것을 방지하기 위해 사용자 확인 절차를 거치도록 개선되었다. 또한 `/status` 명령어를 통해 깨진 에이전트나 설정 오류를 한눈에 파악할 수 있는 기능이 도입되었다.

개발 편의성을 위한 세부적인 수정 사항도 포함되었다. MCP 서버 설정을 추가할 때 토큰이 명령줄에 노출되지 않도록 표준 입력을 지원하며, 터미널 환경에서 비전체 화면 렌더링을 선호하는 사용자를 위해 `/tui classic` 명령어가 추가되었다. 또한 원격 제어 모드나 자체 호스팅 러너 환경에서 발생하던 파일 삭제 오류 및 권한 관련 버그들이 수정되어 더욱 매끄러운 실행이 가능해졌다.

세션 관리와 인증 시스템의 안정성도 개선되었다. 세션 재개 시 메시지 로딩 오류를 알리는 문구가 추가되었고, 헤드리스 세션에서 메시지가 유실되던 사례나 계정 변경 시 세션 처리 방식이 개선되었다. 이번 업데이트는 전체적인 버그 수정과 안정성 확보에 초점을 맞추고 있으며, 원문에는 더 많은 세부 수정 사항이 포함되어 있으나 주요 변경 사항은 위와 같다.
