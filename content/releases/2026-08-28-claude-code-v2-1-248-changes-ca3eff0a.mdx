이번 업데이트는 개발 환경의 안전성과 신뢰성을 크게 강화했다. 새로 추가된 '--restricted' 플래그는 명령어 실행이나 코드 실행 도구, WebFetch 등을 제거하고 작업 디렉토리 내 파일 도구만 허용하며 설정 파일 무시 등 엄격한 제약을 적용한다. 이는 민감한 환경에서 에이전트를 안전하게 구동하려는 사용자에게 중요한 선택지가 된다. 또한 에이전트 프론트매터에 'experimental.cacheTtl'이 추가되어 서브에이전트 TTL 설정이 없을 때 개별 캐시 유효 기간을 지정할 수 있게 되었다.

장시간 세션에서 발생하던 프롬프트 캐시 미스 문제를 해결하여 확장된 사고 컨텍스트 손실을 방지했다. OAuth 토큰 갱신 후 도구 정의가 재렌더링되며 매 시간마다 발생하는 오류와, 사용량 초과 시 'ScheduleWakeup' 도구 정의 변경으로 인한 리서마 세션 첫 턴의 캐시 미스 문제가 수정되었다. 이로써 긴 코딩 세션 중 컨텍스트 유지가 더 안정적으로 이루어질 것이다.

엔터프라이즈 및 조직 단위 사용자를 위한 기능도 개선되었다. AWS 마켓플레이스나 셀프 서비스 엔터프라이즈, 트라이얼 조직의 구성원이 '/usage-credits'를 통해 관리자에게 사용량 한도 증대를 요청할 수 있게 되었다. 또한 서버 관리 설정 진단 기능이 추가되어 설정 로드 실패 시 시작 경고와 '/doctor', '/status' 명령을 통한 원인 설명(Bedrock/Vertex/서드파티 제공자, 커스텀 ANTHROPIC_BASE_URL 등)이 제공된다.

기존 세션 유지 및 로그인 관련 버그들도 해결되었다. Claude Desktop과 Cowork 세션이 30일 후 사라지는 문제가 수정되어 앱 내에서 작성된 세션은 조직 정책이 관리하지 않는 한 유지되며, 'desktopSessionCleanupPeriodDays' 설정으로 예외 기간을 제한할 수 있다. 토큰 갱신 잠금 충돌로 인한 로그인 화면 이동 문제와 Windows 환경에서의 키보드 응답 오류, CI 환경에서의 워크스페이스 신뢰 프롬프트 생략 문제 등도 정상적으로 작동하도록 수정되었다.
