이번 업데이트는 개발자의 작업 흐름을 더 매끄럽게 만드는 데 중점을 뒀다. 가장 눈에 띄는 변화는 '지금 보내기' 단축키 추가다. Ctrl+Enter나 Ctrl+X, Ctrl+S를 누르면 현재 진행 중인 턴을 중단하고 대기 중인 모든 메시지를 한 번에 전송할 수 있다. 전송된 메시지와 대기 중인 메시지는 회색으로 표시되어 모델이 응답하기 전까지 상태를 직관적으로 파악할 수 있게 했다.

계정 연동 기능도 확장되었다. claude.ai 계정으로 로그인한 터미널 세션에서 활성화된 스킬과 플러그인이 자동으로 동기화된다. 원치 않을 경우 설정을 통해 동기화를 비활성화할 수 있다. 또한 게이트웨이 로그인 시 계정 확인 절차를 강화하고, 오토메이션 헤더 설정 실패 시 시작 경고 메시지를 띄워 텔레메트리 전송 실패를 사전에 인지하도록 했다.

안정성 측면에서도 많은 버그가 해결되었다. 메모리 파일의 나이 정보가 변경되어 프롬프트 캐시 미스가 발생하는 문제, 포크된 서브에이전트 메시지 누락, @멘션 파일 제안 순서 오류 등이 수정되었다. 특히 리눅스 환경에서 zsh 셸 사용 시 실패한 명령어도 성공 코드를 반환하던 치명적인 버그와, 대용량 파일 디코딩 실패 시 읽기 도구가 멈추는 현상이 개선되어 샌드박스 내 작업의 신뢰도가 높아졌다.

전체적인 사용자 경험도 다듬어졌다. 전체 화면 모드에서 스크롤 시 프리징되거나 백그라운드 작업 알림 위치가 어긋나는 문제가 해결되었다. 또한 플러그인 설치 시 마켓플레이스 추가를 제안하는 기능이 생겼고, Git 주소나 토큰이 로그에 노출되는 보안 관련 버그도 수정되었다. 세션 복원 시 발생할 수 있는 크래시와 오류들도 광범위하게 패치되어 중단 없는 개발 환경을 제공한다.
