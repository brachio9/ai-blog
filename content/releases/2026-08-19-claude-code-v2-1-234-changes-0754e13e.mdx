이번 업데이트에서 가장 주목할 만한 변화는 보안 강화다. 원격 파일 읽기, 세션 복원, 워크플로우 스크립트 실행 등 사전 승인 파일 접근 시 Windows NT 네임스페이스 경로를 차단하여 NTLM 자격 증명 유출 위험을 줄였다. 또한 Claude가 사용자의 계정 이메일을 식별 목적으로만 사용하고, 별도의 요청이 없는 한 외부 서비스에 전송하지 않도록 정책이 명확해졌다. 이는 프라이버시 보호에 대한 개발자들의 우려를 해소하는 중요한 조치다.

사용성 측면에서는 자동 세션 지속 기능이 도입되었다. claude.ai의 사용량 제한이 해제되면 자동으로 세션을 이어갈 수 있으며, 설정에서 이 기능을 끌 수도 있다. GitLab 사용자들을 위해 푸터와 상태줄에 머지 요청 배지가 추가되어, 인증된 glab CLI 환경에서 MR의 상태를 한눈에 확인할 수 있게 되었다. 또한 텍스트 선택을 지우는 키바인드 액션이 추가되어 에이전트 뷰에서도 편리하게 작업할 수 있다.

안정성 개선도 두드러진다. 긴 대화 세션 중 샌드박스 명령어의 네트워크 접근 권한 재확인 문제를 해결하고, 백그라운드 서브에이전트의 권한 응답이 유실되는 버그를 수정했다. 스트리밍이 아닌 API 응답 경로에서 발생할 수 있는 크래시 원인을 제거했으며, 특수 유니코드 시퀀스가 포함된 마크다운 렌더링 속도 저하 문제도 개선되었다. 이는 장시간 코드 작성 작업 중 끊김 없이 집중할 수 있도록 돕는다.

기타 버그 수정 사항으로는 Git 원격 호스트 인식 오류, MCP 진단 시 비밀 정보 노출 방지, 모달 텍스트 복사 시 문자 누락 문제 등이 해결되었다. 셸 명령어 실행 중 대화상자가 닫히거나 큐에 있는 메시지가 잘못 처리되는 현상도 교정되어 인터랙션의 일관성이 높아졌다. 전체적인 변경 사항 중 핵심적인 부분만 선별하여 정리했으므로, 더 세부적인 커밋 내역은 공식 릴리즈 노트를 참고해야 한다.
