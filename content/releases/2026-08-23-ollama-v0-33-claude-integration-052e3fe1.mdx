이번 업데이트의 가장 큰 변화는 올라마가 클로드 데스크톱과 공식적으로 연동된다는 점이다. 이제 사용자는 메뉴 바에서 개별 올라마 모델의 활성화를 직접 제어할 수 있다. 클로드 내부에서도 사용 가능한 올라마 모델을 선택해 사용할 수 있으며, 클라우드 모델은 로그인 상태일 때만 나타난다. 새로운 앱 뷰를 통해 통합된 애플리케이션을 관리하고 실행 명령어를 복사하는 기능도 추가되었다.

캐시 성능과 안정성 측면에서도 중요한 개선이 있었다. 에이전트 클라이언트가 긴 프리필(pre-fill) 작업을 취소했을 때 발생하던 멈춤 현상이 해결되었다. 이제 취소된 프리필 작업이 지나간 복원 지점을 모두 유지하므로, 재시도 시 처음부터 다시 시작하는 대신 중단된 지점부터 이어진다. 이는 특히 순환 계층을 가진 모델에서 토큰 재처리로 인한 성능 저하를 막는 데 도움이 된다.

또한 클로드 코드의 토큰 카운트다운 시스템 메시지가 프롬프트 맨 앞에 배치되어 KV 캐시를 매 요청마다 깨뜨리던 문제가 해결되었다. 이제 중단된 프리필 작업이 주장하는 범위를 덮지 못하는 복원 지점을 기록하지 않아 불필요한 재처리를 방지한다.

기타 개선 사항으로는 딥시크 하네스 런처가 전역 npm 설치가 실패할 경우 npx로 폴백하며 Windows 명령어 shim을 지원하도록 변경되었다. 온보딩 흐름의 설명이 명확해졌고 macOS 헤더 정렬 및 확대/축소 단축키 제한 등 사용자 경험 개선도 이루어졌다. MLX 종속성 업데이트와 리눅스·윈도우 빌드 시 발생하는 패키징 오류 수정, 사이드바 전환 시 헤더 겹침 문제 해결 등의 버그 픽스도 포함되었다.
