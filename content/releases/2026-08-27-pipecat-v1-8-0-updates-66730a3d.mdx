이번 업데이트의 가장 큰 변화는 MCP(Model Context Protocol) 클라이언트의 사용 편의성 개선이다. 이제 `MCPClient`를 통해 도구를 호출할 때마다 모델이 선택하지 않아야 하는 고정 인자(예: 계정 ID, 검색 모드 등)를 주입할 수 있게 되었다. 이는 모델이 보지 못하는 스키마에 숨겨져 서버로 전달되며, 개발자가 특정 파라미터를 강제로 고정해야 할 때 유용하다. 또한 `MCPClient.tools()` 메서드 추가 덕분에 연결 설정부터 파이프라인 종료 시 연결 해제까지 모든 과정이 자동으로 처리되어, `LLMContext`에 도구를 등록하는 작업이 한 줄 코드로 단순화되었다.

실시간 정보 접근성을 높이기 위해 Keenable AI 기반의 웹 검색 서비스(`KeenableWebSearch`)가 선택적으로 추가되었다. 이 서비스를 통해 음성 에이전트는 호스팅된 MCP 서버를 매개로 실시간 웹 페이지 검색과 콘텐츠 읽기가 가능해졌다. API 키 없이도 기본 모드에서 사용 가능하며, 더 높은 속도 제한과 낮은 지연시간을 원할 경우 `realtime` 모드를 활성화하면 된다. 설치 시 `keenable` 엑스트라를 포함하면 해당 도구가 자동으로 등록되어 파이프라인 종료 시 연결이 정리된다.

기존 서비스들의 기능도 확장되었다. Gemini 어댑터는 이제 `Part.from_uri()`를 통해 외부 이미지 URL을 직접 지원하게 되었으며, Google Speech-to-Text v2 서비스는 도메인 전문 용어에 대한 인식 정확도를 높일 수 있는 `adaptation` 기능을 도입했다. 이 기능은 빌드 시 구성하거나 런타임 중에도 업데이트할 수 있어, 특정 분야 용어가 포함된 대화에서 음성 인식의 신뢰도를 높이는 데 기여한다.

개발 환경 설정 측면에서는 CLI 패키지에 Context Hub가 통합되었다. 이제 별도의 설치 없이 `pipecat init` 명령어를 실행하면 코딩 에이전트(Cursor, VS Code, Zed 등)에 Context Hub MCP 서버가 자동으로 등록되도록 가이드된다. 이는 개발자가 에이전트에게 컨텍스트를 조회하도록 지시하는 과정을 표준화하며, 봇 런타임 이미지 크기는 영향을 받지 않도록 CLI만 선택적으로 설치되는 구조로 유지되었다. 이번 요약은 주요 기능 변경 사항 중 일부를 다루었으며, 전체 변경 내역은 공식 릴리즈 노트를 참고해야 한다.
