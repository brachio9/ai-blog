이번 버전에서는 설정 메뉴에 앱 글꼴 크기 슬라이더가 생겼다. 이 기능을 통해 인터페이스 전체 크기를 조정할 수 있으며, 창이 그려지기 전에 적용되므로 실행 시 이전 크기로 깜빡이는 현상이 사라졌다. 또한 웹 검색 기능이 도입되어 지원 모델은 작업 중 인터넷을 검색할 수 있게 되었다. 설정에서 토글을 켜면 검색 결과물이 대화 기록에 남고 세션을 다시 열어도 유지된다.

Cline Pass 사용자를 위한 확장된 사고 예산이 게이트웨이 변경으로 인해 적용되지 않던 문제가 해결되었다. 이제 제공업체로 정상적으로 전달되어 예산 제한이 올바르게 작동한다. 모델 목록도 새로 고쳐져 Crusoe가 새로운 제공업체로 추가되었고, 각 제공업체별 기본 모델 설정이 업데이트되었다.

백그라운드 서비스인 Hub의 안정성도 크게 개선되었다. 서로 다른 빌드의 Cline 인스턴스가 동시에 실행될 때 Hub를 반복적으로 종료시키며 라이브 세션을 끊는 문제가 해결되었다. 이제 앱은 이미 작동 중인 Hub를 교체하지 않고 연결하며, Hub가 유휴 상태가 될 때만 교체가 일어난다. 또한 Hub가 자체 업데이트를 완료하는 과정에서 불필요한 '업데이트 필요' 대화창이 뜨지 않도록 조정했다.

세션 종료 후 남아 있던 플러그인 샌드박스 프로세스가 자동으로 회수되도록 개선하여 자원 낭비를 줄였다. 이 외에도 여러 버그 수정과 성능 최적화가 포함되었으나, 여기서는 주요 변경 사항만 다뤘다. 전체 변경 내역은 공식 저장소의 비교 페이지에서 확인할 수 있다.
