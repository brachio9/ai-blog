이번 업데이트는 외부 도구와의 연결을 더 유연하게 만든다. 선택적 MCP 서버에서 도구를 발견하는 데 걸리는 시간을 사용자가 직접 설정할 수 있게 되었다. 또한 확장 프로그램이 모델에게 전달되기 전에 MCP 도구 결과를 검사하거나 대체할 수 있는 기능이 추가되어 워크플로우의 제어가 세분화되었다. 플러그인 카탈로그도 저장소별 설정을 더 잘 반영하며 유효하지 않은 마켓플레이스만 숨기고 정상적인 플러그인은 계속 보여주도록 개선되었다.

보안과 권한 관리 측면에서도 중요한 수정이 이루어졌다. TUI 세션 간에 복원된 권한 프로파일이 유지되도록 하고, 디렉토리 이동 명령어가 샌드박스 제한을 우회하는 것을 막았다. 원격 샌드박스 실행 시 실제 홈 디렉터리와 운영체제 경로를 정확히 반영하여 격리 환경을 더 견고하게 했다. 또한 권한 상태가 변경된 후에도 이전의 승인 상태를 잘못 적용하는 문제를 해결해 보안 리스크를 줄였다.

모델 전환 및 토큰 관리의 정확성도 높였다. 모델을 바꾸거나 폴백할 때 도구 사용 가능 여부와 추론 노력 수준이 올바르게 유지되도록 수정했다. 중첩된 서브 에이전트가 사용한 토큰을 루트 목표 예산에 포함시켜 전체 사용량을 더 정확하게 추적할 수 있게 되었다. 이는 비용 관리와 리소스 할당에 있어 예측 가능성을 높이는 변화다.

기타 내부 테스트 안정화와 원격 실행자 관련 텔레메트리 수집 기능이 추가되었다. 이 릴리스는 주로 기존 기능의 신뢰성을 높이고 확장성 있는 도구 연동을 지원하는데 초점을 맞추었다. 전체 변경 내역은 공식 저장소의 비교 링크에서 확인할 수 있으며, 여기서는 주요한 기능 개선과 버그 수정만 다뤘다.
