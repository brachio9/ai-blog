이번 업데이트는 리소스 관리의 투명성을 높이는 데 중점을 두었다. 메모리 사용량이 임계치에 도달하면 눈에 띄는 경고 메시지가 표시되며, 메모리를 확보하거나 안전하게 재시작하는 구체적인 단계를 안내받는다. 또한 MCP 서버 연결 대기 시간을 환경 변수로 제어할 수 있게 되어, 첫 번째 비대화 턴에서 서버 응답을 기다리는 시간이 무한정 길어지는 문제를 방지한다.

MCP(MCP Protocol) 관련 안정성 개선이 두드러진다. HTTP 기반의 레거시 MCP 서버가 초기 요청에 에러 코드를 반환하더라도 연결이 끊기지 않도록 수정했으며, 스트림 가능한 HTTP 도구 호출의 타임아웃 문제도 해결했다. 또한 권한 부족(403) 오류가 로그인 만료로 잘못 인식되던 버그를 고쳐, 누락된 권한과 재인증 방법을 정확히 안내한다.

세션 관리와 에이전트 동작의 신뢰성도 강화되었다. '예상치 못한 도구 사용 ID' 오류로 인해 세션이 무한 루프에 갇히는 현상을 자정(self-healing) 기능으로 해결했으며, 컨텍스트 오버플로우 시 컴팩션이 제대로 작동하지 않아 목표(goal)가 손실되거나 세션이 종료되는 문제를 수정했다. 자동 업데이트 후 모델 및 권한 설정이 초기화되던 버그도 함께 고쳐졌다.

모니터링과 디버깅을 위한 추적 기능도 추가되었다. OpenTelemetry 트레이스에 effort 속성을 포함하고, 관리 설정 해결 상태를 이벤트로 기록하도록 했다. 데이터베이스 연결 타임아웃 설정을 명시적으로 조정할 수 있게 되었으며, 연결 실패 시 오류 메시지가 구체적인 설정 값을 안내한다. 이 외에도 수천 개의 파일 진단으로 인한 턴 지연 문제와 자체 호스팅 러너의 토큰 갱신 실패 문제 등 다양한 기술적 이슈가 해결되었다.
