Claude Code v2.1.289 릴리스는 주로 시스템 안정성과 플러그인 생태계의 신뢰성 향상에 집중했다. 이전 버전에서 발생하던 터미널 정지 현상이 크게 개선되었다. 짧은 코드 블록 내에 닫히지 않은 스크립트 태그가 많거나 중첩된 변수 치환이 있을 때 터미널이 멈췄던 문제가 해결되었으며, 특정 경계 스타일을 가진 박스 그리기 실패로 인한 앱 강제 종료 문제도 수정했다. 이는 개발자가 코드 생성 및 실행 과정에서 겪을 수 있는 갑작스러운 인터럽트를 줄이는 데 기여한다.

플러그인과 사용자 설치 모드(mod)의 동작 안정성이 크게 향상되었다. 업그레이드 후 첫 세션에서 모드가 로딩되지 않던 문제와, 로컬 폴더 마켓플레이스에서 설치한 플러그인의 상태가 제대로 반영되지 않던 버그를 수정했다. 또한 배경 작업 대화상자가 전체 화면으로 열려 있을 때 프롬프트 위의 행이 오래된 상태로 표시되던 현상이 해결되었으며, 플러그인 컴포넌트 렌더링 실패 시 주변 요소까지 함께 무너지지 않고 독립적으로 에러를 처리하도록 개선되었다. 이로써 확장 기능 사용 시 발생할 수 있는 인터페이스 오류가 감소했다.

보안 및 권한 관리 측면에서도 중요한 수정이 이루어졌다. 심볼릭 링크를 통해 IDE에서 참조된 파일에 대한 읽기 거부 규칙 적용 문제와, 복합 셸 명령어의 중첩 부분에서 승인 규칙이 유지되지 않던 버그를 해결했다. 특히 샌드박스 자동 허용 모드에서 환경 변수 접두사나 변수 할당이 포함된 Bash 명령어에 대해 거부 또는 질문 규칙이 건너뛰는 문제가 수정되어, 의도치 않은 명령어 실행 위험을 줄였다. 또한 사용자 설치 플러그인이 조직 관리 MCP 서버의 로그인 도구 설명을 재작성하는 것을 방지하는 보안 패치도 포함되었다.

마지막으로 VSCode 확장 및 인증 관련 개선 사항이 있다. 2.1.288 버전에서 도입된 변경으로 인해 로그아웃이 빈번하게 발생하던 문제가 되돌려졌다. 대형 파일의 코드 패널 열기 속도가 향상되었고, 플러그인 유효성 검사 도구가 마켓플레이스 매니페스트와 함께 있는 폴더를 올바르게 처리하도록 수정되었다. 이러한 세부적인 수정들은 개발자가 Claude Code를 더 신뢰할 수 있는 도구로 사용할 수 있도록 기반을 다진다.
