이번 업데이트에서 가장 눈에 띄는 변화는 모델의 추론(Reasoning) 성능 최적화다. 이제 지원되는 모델에 따라 최대 수준의 추론 노력을 제공하며, 특히 OpenAI의 o-시리즈나 GPT-5.x 모델에서 발생하던 오류를 해결했다. 또한 사용자 설정에 따라 추론 기능을 끄는 기능이 커스텀 모델까지 확장되어 유연한 사용이 가능해졌다.

데이터 처리 능력도 대폭 강화되었다. 기존에는 파일 읽기 결과가 8,000자 수준으로 제한되었으나, 이제는 도구 자체의 한도인 2,000라인(약 48,000자)까지 전체 내용을 모델에 전달할 수 있다. 이는 복잡한 코드나 긴 문서를 처리할 때 훨씬 더 정확한 컨텍스트를 제공하는 데 도움을 준다.

사용자 편의성 및 안정성 개선도 포함되었다. 요약 과정에서 멈춰버렸던 프로세스를 수동으로 중단할 수 있는 기능이 추가되었으며, macOS 환경에서의 업데이트 확인 방식이 개선되었다. 또한 앱 전반의 색상과 타이포그래피가 새롭게 단장되어 시각적인 사용자 경험이 개선되었다.

이번 업데이트에는 모델 카탈로그의 대대적인 조정과 수많은 프로바이더의 기본 모델 변경이 포함되어 있다. 다만 이번 요약에서는 핵심적인 기능 개선인 추론 최적화와 데이터 처리량 증대 위주로 설명했으며, 전체 변경 사항은 공식 릴리즈 노트를 참조해야 한다.
