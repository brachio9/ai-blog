이번 릴리즈는 GPT-6 Astra, Claude Opus 5.5 등 최신 모델에서 reason off 상태나 커밋 메시지 생성 시 발생하던 400 오류를 해결했다. 또한 MCP 서버나 훅이 종료될 때 입력을 다 읽지 않고 프로그램이 비정상적으로 종료되는 문제도 개선되어 작업의 안정성이 높아졌다. VS Code 확장판에서 설정을 마이그레이션할 때 빈 SAP AI Core 제공자가 추가되던 버그 역시 수정되었다.

명령어 구조가 일부 조정되었다. 기존 cline dashboard 명령은 cline hub dashboard로 변경되었으며, 구 버전 명령어도 숨겨진 별칭으로 계속 작동한다. 단순한 cline hub 입력 시 하위 명령어 목록을 확인할 수 있게 되었으며, 로그 파일 경로를 환경 변수로 설정했을 때 이를 정확히 열어주는 기능도 추가되었다. 또한 --retries 옵션의 기본값 설명이 실제 값인 3으로 정정되었고, thinking 옵션이 /model에서 선택한 레벨로 폴백됨이 명시되었다.

사용자 경험과 안정성을 위해 몇 가지 명령어 동작이 변경되었다. cline mcp add 명령 실행 시 헤더 값이 유지되도록 개선되어 인증 정보 유출을 방지하고, 유효하지 않은 스케줄링 설정(예: 전달 어댑터 없이 스레드 지정)은 저장 전에 에러로 차단한다. 기존에 존재했으나 아무런 효과가 없었던 옵션들은 제거되어 스크립트에서 해당 옵션 사용 시 명확한 에러를 반환하도록 했다.

모델 카탈로그가 새로고침되어 Claude Haiku 5.5가 추가되었다. Google Vertex AI, GitHub Copilot 등 여러 제공자의 기본 모델이 Claude Haiku 5.5로 변경되는 등 최신 모델 지원이 확대되었다. 이 요약은 전체 변경 사항 중 주요 부분만 추려낸 것이며, 상세한 커밋 목록이나 기여자 정보는 공식 릴리즈 노트를 참고해야 한다.
