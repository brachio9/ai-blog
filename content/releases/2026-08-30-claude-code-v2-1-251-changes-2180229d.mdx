이번 업데이트는 개발자가 모델 전환 과정을 더 세밀하게 통제할 수 있도록 PreModelSwitch와 PostModelSwitch 훅 이벤트를 도입했다. 세션 재개 시에도 세션의 신선도와 재캐싱 비용을 추정해 제공하므로, 자동 모드에서의 동작을 더 투명하게 파악할 수 있다. 또한 포그라운드 서브에이전트의 도구 호출 결과를 원격 제어 클라이언트에 실시간으로 스트리밍하는 기능이 추가되어 작업 진행 상황을 즉각 확인할 수 있게 되었다.

보안 측면에서 중요한 수정 사항이 다수 반영되었다. 작업 디렉토리 내 심볼릭 링크가 교체된 후 파일 읽기·쓰기 도구가 승인되지 않은 외부 경로에 접근할 수 있는 취약점이 패치되었으며, 플러그인 명령어가 플러그인 디렉토리 밖을 가리키는 경로 트래버설 시도도 차단된다. 워크플로우 도구와 Grep/Glob 명령어도 심볼릭 링크를 통한 비인가 파일 접근을 방지하도록 수정되어 프로젝트 설정의 보안 경계가 강화되었다.

비용 관리와 사용성 측면에서도 개선이 있었다. /usage 명령어에 지출 한계 표시 바가 추가되고, 프롬프트 캐시 히트율과 미스 횟수 등 상세 비용 정보를 /cost 명령어를 통해 확인할 수 있게 되었다. 이는 API 게이트웨이 뒤에서 지출 한계를 설정한 개발자에게 특히 유용하다. 또한 TUI에서 병렬 서브에이전트가 많을 때 발생하는 지연 현상이 해결되어 진행 상황 표시가 더 매끄러워졌으며, 에이전트 팀 구성원 간의 최종 답변 전달 문제도 수정되었다.

기존 버그들도 광범위하게 해결되었다. Opus 5 모델에서 thinking 기능이 꺼져 있을 때 특정 effort 설정으로 요청이 실패하던 문제가 수정되었고, 대화 중 '텍스트 콘텐츠 블록은 비어 있으면 안 된다'는 오류로 멈추는 현상도 개선되었다. 첫 설치 시 자동 모드로 시작되지 않던 문제와 백그라운드 에이전트 간 메시지 전달 실패 등 다양한 안정성 이슈가 해결되어 전체적인 사용 경험이 향상되었다.
