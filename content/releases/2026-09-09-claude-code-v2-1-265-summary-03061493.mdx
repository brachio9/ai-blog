이번 업데이트는 에이전트 서브프로세스의 프롬프트 캐시 재사용 문제를 해결하는 데 주력했다. 기존에는 포그라운드에서 생성된 서브에이전트나 팀원 에이전트가 중단 후 재개될 때 시스템 프롬프트 접두사가 변경되며 캐시 효율이 떨어지는 문제가 발생했는데, 이를 수정하여 일관성을 유지하도록 했다. 또한 이전 프로세스가 툨 실행 중 종료되었을 때 마지막으로 보낸 프롬프트가 다시 작성되지 않고 중단된 툨 호출 상태를 그대로 유지하는 개선도 적용되어 작업 연속성이 높아졌다.

플러그인 관리 기능이 확장되었다. 이제 --plugin-dir 옵션으로 플러그인 폴더를 지정하면 하위 폴더의 매니페스트를 자동으로 로드하며, 실행 중에도 추가되거나 제거된 플러그인을 실시간으로 감지한다. macOS와 리눅스에서 백슬래시가 포함된 경로가 심볼릭 링크 포함 확인을 우회하는 보안 취약점도 패치되었고, 점 두 개로 시작하는 디렉토리 이름이 잘못 거부되던 문제도 해결되어 플러그인 설치 환경이 더 안정적으로 작동한다.

사용자 경험과 데이터 관리 측면에서도 여러 개선이 있었다. 툨 실행 결과를 디스크에 저장할 때 1GB 한도를 도입하여 과도한 저장 공간을 차지하는 것을 방지하고, 대화 내에서 파일이 잘렸음을 명시적으로 알려준다. 또한 tmux 환경에서 두 키 조합 단축키가 너무 빨리 취소되던 문제를 해결해 대기 시간을 3초로 연장했으며, 전사 화면의 스크롤 점프 현상과 코드 하이라이트 표시 오류도 수정되어 인터페이스가 매끄러워졌다.

기타 안정성 패치로는 VS Code 및 SDK 세션의 토큰 갱신 중 재로그인 요구 문제 해결, 원격 제어 세션의 응답 완료 신호 타이밍 조정, 백그라운드 세션의 비활성 타임아웃 관련 조기 종료 방지 등이 포함되었다. 어드바이저 툨의 모델별 재결정 문제를 한 번의 결정으로 통합하고, 아티팩트 발행 시 존재하지 않는 커넥터 툨 이름에 대한 검증 강화도 적용되었다. 이 외에도 다양한 버그 수정이 포함되어 있으나, 위 주요 변경 사항들이 이번 릴리즈의 핵심이다.
