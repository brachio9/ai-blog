이번 업데이트의 핵심은 에이전트 플러그인 관리 방식의 변화다. 이제 ~/.agents/plugins 폴더에 있는 패키지는 plugin.json 파일을 통해 검증된 후 유효한 에이전트 스킬로 자동 등록된다. stdio, Streamable HTTP, SSE MCP 서버들도 자동으로 시작되며, 설정 메뉴에서 Cline 플러그인과 별도로 에이전트 플러그인을 관리할 수 있게 되었다. 작업 공간 내의 .agents/plugins 디렉토리는 의도적으로 무시되므로 혼동을 피할 수 있다.

사용자 경험 측면에서도 여러 개선이 이루어졌다. 가장 눈에 띄는 변화는 허브 업데이트 알림의 제거다. 동일한 코어 버전을 사용하는 데스크톱과 CLI 간 빌드 지문 차이로 인해 발생하던 무한 루프 알림 문제가 해결되었으며, 실제 앱 업데이트가 준비될 때만 알람을 표시하도록 조정되었다. 또한 로그인 시 브라우저에서 확인하는 코드와 앱 화면에 표시되는 코드를 일치시켜 인증 과정을 더 직관적으로 만들었다.

오류 처리 및 안정성도 강화되었다. 음성 입력 설정 오류 발생 시 사용자를 직접 설정 화면으로 안내하여 조치할 수 있도록 했으며, 마이크 권한 문제는 별도의 명확한 메시지로 구분한다. 또한 완료된 작업 단계가 접힐 때 사라지던 스케줄드 태스크 리포트 버그를 수정하고, 특정 MCP 서버의 고장으로 인해 다른 서버들이 종료되지 않는 프로세스 누수 문제도 해결했다.

이 글은 전체 변경 사항 중 주요 기능 개선과 버그 수정 위주로 요약한 것이다. 플러그인 생태계의 자동화 강화와 함께 일상적인 사용에서 겪을 수 있는 번거로움을 줄이는 데 초점을 맞춘 릴리스다.
