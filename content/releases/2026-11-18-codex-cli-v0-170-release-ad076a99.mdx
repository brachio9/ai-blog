이번 업데이트에서 가장 눈에 띄는 변화는 사용자 인터페이스(TUI)에서의 실시간 음성 통화 지원이다. WebRTC 협상 기능이 추가됨에 따라 더욱 원활한 음성 기반 상호작용이 가능해졌다. 또한 OpenTelemetry HTTP 수출을 위한 인증 헤더 자동 갱신 기능이 도입되어 데이터 추적의 안정성이 개선되었다.

개발 환경의 유연성을 높이기 위한 기능도 포함되었다. 이제 서로 다른 환경에서 동일한 이름을 가진 MCP 서버를 독립적으로 사용할 수 있는 실험적 지원이 추가되었다. 이는 개발자가 여러 프로젝트를 동시에 다룰 때 발생할 수 있는 충돌을 방지하는 데 도움을 준다.

안정성 측면에서는 네트워크 및 권한 관리 관련 버그 수정이 대폭 이루어졌다. 대용량 WebSocket 요청이 발생할 때 불필요한 재시도 없이 HTTP로 전환되도록 개선되었으며, MCP OAuth 자격 증명 관련 경쟁 상태 오류가 해결되었다. 또한 Windows 환경에서의 파일 교체 및 샌드박스 권한 유지와 관련된 여러 결함이 수정되어 실행 환경의 신뢰성을 높였다.

이번 릴리스 노트에는 수많은 세부 수정 사항이 포함되어 있으나, 핵심은 실시간 통신 기능 강화와 멀티 환경에서의 MCP 서버 활용성 개선에 있다. 전체 변경 사항은 공식 릴리스 노트를 통해 확인할 수 있다.
