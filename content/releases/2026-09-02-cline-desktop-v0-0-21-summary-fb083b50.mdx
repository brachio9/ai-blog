이번 업데이트에서 가장 눈에 띄는 변화는 마켓플레이스의 인터페이스 개편이다. 이제 왼쪽에는 목록을, 오른쪽에는 선택한 항목의 상세 메타데이터를 보여주는 두 개의 패널로 구성되었다. 카테고리 필터는 '더보기' 토글 뒤로 숨겨져 공간을 효율적으로 사용한다. 이는 사용자가 원하는 도구를 더 빠르게 찾고 정보를 확인하는 데 도움이 될 것이다.

세션 제어의 안정성도 크게 향상되었다. 이전에는 세션을 중단해도 자식 에이전트나 팀원 작업이 백그라운드에서 계속 실행되는 문제가 있었지만, 이제는 중단 명령이 모든 하위 작업에 전달되어 완전히 정지된다. 취소된 작업 상태도 유지되므로 혼란을 줄일 수 있다. 또한 파일 첨부 시 작은 아이콘 영역뿐만 아니라 채팅 입력창 전체로 파일을 드래그하면 바로 첨부할 수 있어 사용 편의성이 높아졌다.

모델 관리와 오류 처리에도 중요한 개선이 있었다. 이제 앱 업데이트를 기다리지 않고 라이브 카탈로그에서 새로 출시된 모델을 실시간으로 확인할 수 있다. 인증 실패(401/403)가 일반적인 요청 실패와 구분되어 API 키 문제인지 서비스 장애인지 명확히 알 수 있게 되었다. 또한 릴리즈 빌드에서 작동하지 않던 Langfuse 추적 기능이 수정되어 원격 분석 데이터 수집이 정상적으로 이루어진다.

마지막으로 모델 카탈로그가 대폭 갱신되었다. TokenGo와 Volcengine Ark 등 새로운 제공자가 추가되고, 기존 약 36개 제공자의 모델 목록과 가격 정보가 업데이트되었다. 특정 모델을 고정하지 않고 기본값을 사용하는 경우 이전 버전과 다른 모델이 선택될 수 있으므로 주의가 필요하다. 이 외에도 질문 도구 텍스트 넘침 문제 등 여러 버그 수정이 포함되어 있다.
