Cline 데스크톱 앱이 이제 리눅스를 공식 지원한다. x64 아키텍처를 위한 deb와 rpm 패키지를 제공하며, 폴더 열기 기능은 네이티브 GTK 선택기를 사용한다. 업데이트는 백그라운드에서 다운로드되어 재시작 시 설치되므로 예상치 못한 비밀번호 요청을 피할 수 있다. 현재 AppImage 형식은 지원하지 않는다.

플러그인 슬래시 명령어의 동작 방식이 근본적으로 바뀌었다. 기존에는 명령어가 단순 텍스트로 모델에 전달되었지만, 이제는 플러그인의 핸들러가 직접 실행되어 결과를 보여주고 필요 시에만 턴을 시작한다. 이는 대화 작업 공간의 워크스페이스와 워크트리에서 스킬과 워크플로우를 불러올 수 있게 하며, 특정 플러그인 오류가 전체 슬래시 메뉴를 마비시키는 문제를 해결했다.

설정 화면에 진단 항목이 추가되어 GitHub 이슈 첨부용 안전한 텍스트 파일을 내보낼 수 있다. 이 파일에는 앱 버전, OS 정보, 설정, 최근 로그 및 선택한 세션 매니페스트가 포함되지만 API 키나 자격 증명 같은 민감 정보는 자동으로 제거된다. 또한 음성 입력 기능이 제공자 기반 전사 서비스로 복원되어 실시간 스트리밍이 가능해졌으며, 네트워크 끊김 시 브라우저 인식기로 폴백하는 로직이 적용되었다.

모델 목록 조회 시 엔드포인트 연결 실패 시 실제 오류 메시지를 표시하도록 개선되었고, 기업 CA 서명된 인증서도 운영체제 저장소를 신뢰하여 연결 문제를 해결했다. 세션 이름 변경이 재시작 후에도 유지되며, 로컬 모델의 출력 토큰 한계 도달 시 대화 압축 후 재시도하는 기능이 추가되어 실패율을 낮췄다. 이 외에도 CLI 세션 정리 및 메뉴 탐색 편의성 개선 등 다양한 버그 수정이 포함되었으나, 이는 주요 변경 사항 중 일부일 뿐이다.
