이번 업데이트의 가장 큰 변화는 커스텀 프로바이더의 안정성 개선이다. 이전에는 'Add Provider'를 통해 추가한 커스텀 제공자가 모델 선택 화면에서는 정상적으로 표시되었지만, 실제 작업을 실행할 때 'Unknown or disabled provider' 오류가 발생하여 사용이 불가능했다. 이번 패치로 인해 이러한 오류가 해결되어 사용자가 직접 설정한 프로바이더가 작업 수행 단계에서도 정상적으로 작동하게 되었다. 또한 API 키나 엔드포인트를 변경했을 때 모델 목록이 자동으로 새로고침되며, 모델 목록을 가져오지 못하는 상황에서도 자격 증명 저장 과정이 중단되지 않도록 개선되었다.

사용자 경험 측면에서는 새 채팅 시작 시 마지막 사용 환경이 기억되는 기능이 강화되었다. 기존에는 새로운 대화창을 열 때마다 기본값인 로컬(Local) 모드로 초기화되었으나, 이제는 사용자가 마지막으로 선택한 클라우드(Cloud) 모드와 해당 클라우드 모델을 기억한다. 로컬 모드에서 클라우드 모드로 전환할 때도 이전에 설정해 둔 클라우드 모델이 자동으로 적용되어 번거로운 재선택 과정이 생략된다. 이는 자주 특정 클라우드 모델을 사용하는 사용자에게 편의성을 제공한다.

MCP(Model Context Protocol) 관련 설정의 일관성도 확보되었다. `CLINE_MCP_SETTINGS_PATH` 등의 환경 변수가 설정된 경우, 서버 읽기 및 저장, OAuth 로그인, 설정 파일 열기 등 모든 MCP 관련 작업이 동일한 파일을 참조하도록 통일되었다. 이전 버전에서는 일부 기능이 다른 파일을 열어 혼란을 초래할 수 있었으나, 이제 경로 관리가 명확해졌다. 또한 MCP 도구가 컨텍스트 한계를 초과하는 긴 출력을 반환할 경우, 에이전트가 미리보기와 페이지네이션 링크를 통해 나머지 내용을 읽을 수 있게 되어 데이터 손실 문제가 해결되었다.

인터페이스 및 모델 목록에도 일부 변화가 있었다. 도구 차이(diff) 표시 영역의 글꼴 크기가 앱 설정에 따라 동적으로 적용되도록 변경되어 가독성이 개선되었다. 모델 카탈로그는 새로 고쳐졌으며, Cline 권장 목록에 GPT-6.1 Sol이 추가되었다. 302.AI, NanoGPT, Vivgrid, Vultr 등 주요 제공자의 기본 모델도 업데이트되었는데, 특히 Vultr의 경우 모델 ID가 상류(upstream)에서 변경되어 기존에 고정된 모델을 다시 선택해야 할 수 있다. 이번 릴리스에는 언급되지 않은 기타 버그 수정 및 개선 사항들도 포함되어 있을 수 있다.
