이번 업데이트는 반복적인 작업을 효율화하는 데 초점을 맞췄다. 사용자는 `/presets` 명령어를 통해 최대 10개의 슬롯에 재사용 가능한 프롬프트와 슬래시 명령어를 저장할 수 있으며, 키보드 메뉴를 통해 이를 빠르게 호출할 수 있다. 또한 인라인 인자를 통해 모델, 추론 노력도, 속도, 권한 프로파일을 직접 설정하는 기능이 도입되어 워크플로우의 유연성이 높아졌다.

터미널 환경에서의 시각적 피드백도 개선되었다. Kitty 또는 Sixel 그래픽을 지원하는 터미널에서는 대화 기록 전체 화면에서 조회하거나 생성한 이미지를 미리볼 수 있게 되었다. 이는 코드 실행 결과나 데이터 시각화 등을 텍스트만으로 확인하던 기존 방식보다 훨씬 직관적인 경험을 제공한다.

보안과 인증 측면에서도 중요한 변화가 있었다. 기업용 MCP 연결 시 OAuth 클라이언트 비밀키를 포함한 다양한 자격 증명을 통해 인증할 수 있도록 지원이 확대되었다. 또한 원격 Bash 명령어 및 Zsh 스냅샷 세션 실행 시 자격 증명이 노출되지 않도록 마스킹 처리하는 기능이 강화되어, 커스텀 제공자로부터의 민감한 정보 보호가 더욱 철저히 이루어진다.

안정성 측면에서는 대화 기록 압축 실패 시 부분적인 요약이 남는 현상이 해결되었고, 세션 재개 시 저장된 스레드 설정이 올바르게 복원되도록 개선되었다. Windows 환경에서의 프록시 인증 처리와 macOS 샌드박스 보안 검사도 강화되었으며, 사용하지 않는 설치 파일 정리 및 데몬 로그 제한을 통해 디스크 사용량도 최적화되었다.
