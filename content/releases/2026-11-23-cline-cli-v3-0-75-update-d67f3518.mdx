이번 업데이트에서 가장 눈에 띄는 변화는 원샷 실행(One-shot runs)의 기본 동작 방식이다. 이제 프롬프트 인자나 파이프 입력을 통한 실행 시, 사용자가 직접 승인할 수 없는 환경을 고려하여 기본적으로 yolo 모드에서 시작된다. 기존의 act 모드는 자동 승인 설정이나 특정 플래그를 사용할 때만 유지되며, 팀 도구 사용이 필요한 경우에는 별도의 플래그를 통해 활성화해야 한다.

데이터 처리 측면에서도 중요한 개선이 이루어졌다. 파일 읽기(read_files) 결과가 기존 8,000자에서 최대 2,000라인(약 48,000자)까지 제한 없이 전달되도록 변경되어 더 큰 규모의 코드 컨텍스트를 처리할 수 있게 되었다. 또한 실행 시의 타임아웃이나 Ctrl+C 입력이 첫 번째 턴에서 제대로 작동하도록 수정되었으며, 보안을 위해 불필요한 디버그 변수가 제거되었다.

모델 호환성 및 추론 기능도 대폭 강화되었다. 이제 추론(Reasoning) 기능을 껐을 때 커스텀 모델 설정이 제대로 반영되며, OpenAI 네이티브 프로바이더에서 GPT-5.x 및 o-시리즈 모델의 추론 수준이 지원 범위에 맞춰 조정된다. LiteLLM 사용 시에도 출력 토큰 제한이 올바르게 인식되도록 수정되었으며, 모델 카탈로그가 업데이트되어 다양한 프로바이더를 지원한다.

이번 릴리즈에는 이 외에도 많은 변경 사항이 포함되어 있다. 특히 모델 카탈로그의 대대적인 갱신과 특정 모델들의 기본 설정 변경이 포함되었으나, 모든 변경 사항을 이 글에 담지는 못했다. 자세한 내용은 공식 릴리즈 노트를 확인해야 한다.
