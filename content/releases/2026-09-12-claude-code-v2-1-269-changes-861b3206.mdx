이번 업데이트에서 가장 주목할 만한 변화는 `claude plugin eval` 명령어의 도입이다. 이제 사용자는 플러그인의 평가 스위트(suite)를 Claude Code에 대해 실행하고, 점수와 재현 가능한 결과를 JSON 및 HTML 보고서 형태로 얻을 수 있다. 이는 플러그인 개발자가 자신의 코드가 모델과 어떻게 상호작용하는지 정량적으로 분석할 수 있는 길을 열어준다. 또한 `/output-style` 명령어를 통해 원격 제어나 클라우드 세션에서도 출력 스타일을 자유롭게 전환할 수 있게 되어, 헤드리스 환경에서의 작업 편의성이 개선되었다.

원격 및 헤드리스 세션의 안정성도 크게 향상되었다. 이전 버전에서는 백그라운드 에이전트가 실행 중임에도 불구하고 '입력 대기 중'이라는 메시지가 표시되거나, 세션을 재개하는 과정에서 컨텍스트가 손실되는 문제가 있었다. 이번 패치는 이러한 오류를 수정하여 원격 작업 시 중단 없이 이어질 수 있도록 했다. 특히 세션 재개 시 모델 전환이나 요청 재시도 중에 턴(turn)의 응답이 사라지는 현상이 해결되었으며, 동기화된 플러그인 MCP 서버 연결 문제도 함께 개선되었다.

터미널 환경에서의 사용자 경험도 다듬어졌다. kitty 프로토콜 터미널의 기능키(F1/F2/F4 등) 작동 오류와 WezTerm 등의 특정 터미널에서 발생하는 입력 이상 현상이 수정되었다. 또한 Bash 도구를 통해 파일을 수정할 때 변경된 파일의 diff를 결과에 포함하는 기능이 추가되어, 명령어 실행 후 어떤 변화가 있었는지 한눈에 파악하기 쉬워졌다. 프롬프트 캐시 무효화 관련 버그도 해결되어, 출력 토큰 제한으로 인해 응답이 끊겼다가 자동으로 재개될 때 캐시 효율이 떨어지는 문제가 개선되었다.

이 외에도 OpenTelemetry 메트릭에 저장소 속성 태그를 붙일 수 있는 환경 변수가 추가되고, CMYK JPEG 이미지 첨부 오류가 해결되는 등 다양한 세부 사항이 수정되었다. 이번 릴리즈는 플러그인 생태계의 투명성을 높이고 원격 개발 경험의 끊김을 줄이는 데 초점을 맞췄다. 전체 변경 사항은 공식 릴리즈 노트에서 확인할 수 있으며, 여기서는 주요 기능 추가와 안정성 개선 사항만 요약했다.
