이번 릴리즈는 다양한 LLM 제공업체와의 호환성 문제를 해결하는 데 중점을 뒀다. Anthropic과 Google, AWS 포맷터에서 파싱할 수 없는 저장된 도구 호출 인자를 더 잘 견디도록 수정했으며, AWS Bedrock 모델이 온도나 topP 파라미터를 거부하는 경우 이를 생략하도록 처리했다. 또한 Mistral AI의 어시스턴트 종료 대화 컨텍스트 지원과 Google STT chirp_3 모델의 커스텀 프롬프트 설정 지원도 포함되었다.

네트워크 및 연결 안정성 측면에서도 개선이 있었다. OpenAI Responses 이벤트가 불완전하게 도착하는 경우를 처리하고, STT WebSocket 연결 풀을 적절히 닫아 리소스 누수를 방지했다. WebSocket 핸드셰이크가 거부될 때 API 키가 노출되지 않도록 마스킹하는 보안 조치와, 연결 풀 사전 가열 실패 시 재시도 로직 추가도 포함되어 있다.

오디오 처리 및 모니터링 기능도 업데이트되었다. Deepgram STT v2(Flux)에 숫자 처리, 비속어 필터링, 적색화 옵션이 추가되었고, 기본 VAD 사용 시 전사 지연 시간이 0으로 보고되는 버그가 수정되었다. 또한 노이즈 캔슬링 활성화 시 기본 AGC를 비활성화하여 오디오 품질을 개선하고, LLM 메트릭과 트레이스에 추론 토큰 수를 노출시켜 성능 분석을 용이하게 했다.

기타 내부적인 안정성 향상 작업도 진행되었다. 동기 함수가 블로킹 상태에서도 SIGTERM/SIGINT 신호를 올바르게 처리하도록 수정하고, 서드파티 Otel 제공자의 강제 종료 문제를 피했다. 이 외에도 ElevenLabs의 부분 전사 재전송 방지와 Ultravox의 say() 기능 구현 등 다양한 세부 사항이 개선되었으나, 여기서는 가장 중요한 변경 사항만 요약했다.
