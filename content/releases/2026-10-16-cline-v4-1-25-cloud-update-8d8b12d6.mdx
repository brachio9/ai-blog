이번 업데이트의 가장 큰 변화는 Cline Cloud 세션 기능의 점진적 출시다. 사용자는 설정에서 이 기능을 활성화하면 지정한 GitHub 리포지토리와 브랜치에 호스팅된 샌드박스 환경에서 작업을 실행할 수 있다. 클라우드 작업은 최근 기록과 히스토리 탭에서 상태를 확인하며, 에디터를 닫아도 백그라운드에서 계속 실행된다. 작업이 완료되면 알림을 통해 결과를 알려주므로 장시간 걸리는 태스크를 처리하는 데 유용하다.

모델 카탈로그와 기본 모델 설정이 대대적으로 조정되었다. 모델을 명시적으로 선택하지 않았을 때 Cline 제공자는 이제 추천 목록의 첫 번째 모델인 Gemini 4 Argon을 사용하며, OpenRouter는 Claude Sonnet 5.5를 유지한다. Boundless와 Standard Compute 같은 새로운 제공자가 추가되었고, SambaNova의 기본 모델은 MiniMax M3로 변경되었다. 또한 수많은 외부 제공자들의 기본 모델이 교체되었으므로, 특정 모델을 고정하지 않고 사용하는 경우 이전과 다른 모델이 적용될 수 있음을 인지해야 한다.

로컬 모델 사용자의 경험 개선을 위한 수정 사항도 포함되었다. LM Studio나 Ollama 같은 로컬 서버에서 긴 프롬프트 처리 중 5분간 응답이 없으면 'BodyTimeoutError'로 실패하던 문제가 해결되어 서버가 처리하는 동안 더 이상 끊기지 않는다. 또한 OpenAI 호환 URL 입력 시 호스트만 적어도 불필요하게 '/v1' 경로가 추가되는 버그를 수정하여 사용자가 입력한 그대로의 URL을 사용하도록 했다. 기존 설정은 호환성을 위해 한 번만 경로를 추가해 이전처럼 작동한다.

기타 안정성 및 UX 개선 사항도 적용되었다. Cline의 질문에 대한 답변에 첨부된 이미지와 파일이 모델에게 제대로 전달되도록 수정했으며, 제공자 오류로 응답이 중단될 경우 최대 3회까지 재시도하는 로직을 도입했다. JetBrains 환경에서는 작업 실행 카드가 자동 승인 바보다 위에 표시되도록 위치가 조정되었고, 자동 컴팩트 기능과 관련 설정이 다시 함께 묶여 찾기 쉬워졌다.
