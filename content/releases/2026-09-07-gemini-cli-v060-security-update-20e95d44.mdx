Gemini CLI의 v0.60.0 나이트리 버전은 주로 내부 안정성과 보안 강화를 위한 변경사항을 포함한다. 사용자에게 직접적인 기능 추가보다는 시스템의 견고함을 높이는 작업이 중심이다. 이번 업데이트는 특히 외부 서비스와의 연동 시 발생할 수 있는 잠재적 위험 요소를 제거하는 데 초점을 맞췄다.

MCP(Model Context Protocol) OAuth 흐름에서 RFC 9207 표준에 따른 발급자 식별을 강제하도록 수정했다. 이는 인증 과정의 신뢰성을 높이고 잘못된 토큰이나 권한 부여를 방지하기 위한 조치다. 또한 Chrome DevTools MCP 관련 코드에서 하드코딩되어 있던 Google CrUX API 키를 제거하고 정화(sanitize) 처리를 통해 보안 취약점을 사전에 차단했다.

macOS 환경에서의 실행 안정성도 개선되었다. Seatbelt 샌드박스 환경에서 임시 디렉터리를 격리하도록 수정하여 파일 시스템 접근 권한 관련 오류를 줄였다. 더불어 확장 로더의 경로 해석과 경계 검증 로직을 강화해 악의적인 코드 실행이나 예상치 못한 동작을 방지하는 방어적 프로그래밍이 적용되었다.

이 밖에도 버전 관리 및 릴리즈 프로세스 자동화 관련 잡무(chore) 작업들이 포함되어 있다. 나이트리 빌드 특성상 아직 완전히 안정화되지 않은 상태이므로, 주요 기능 변경보다는 이러한 보안 패치와 내부 구조 조정이 더 큰 의미를 가진다. 전체 변경 내역은 공식 저장소의 비교 링크를 통해 확인할 수 있으며, 여기서는 가장 핵심적인 보안 및 안정성 관련 사항만 추렸다.
