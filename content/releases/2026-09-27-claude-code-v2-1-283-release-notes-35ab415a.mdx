모델 관리를 더 세밀하게 제어할 수 있게 되었다. availableModelsMatch 설정을 exact로 지정하면 명시된 모델 버전만 실행되므로, 새로운 릴리즈가 목록에 추가될 때까지 업데이트가 자동으로 차단된다. 또한 deniedModels 설정을 통해 허용 목록에도 불구하고 특정 모델을 강제로 배제할 수 있다. 이는 기업 환경에서 모델 업그레이드 리스크를 관리하거나 테스트용 모델과 프로덕션 모델을 명확히 구분해야 할 때 유용하다.

MCP(Model Context Protocol) 서버와의 상호작용 안정성이 크게 향상되었다. 장시간 실행 중인 도구 호출이 백그라운드로 이동해도 진행 상황 알림이 더 이상 무시되지 않으며, 세션 종료 시 시작 중이던 stdio MCP 서버가 잔존하는 문제가 해결되었다. 또한 상태 없는 원격 MCP 서버의 일시적 오류로 인해 해당 서버가 세션 내내 사용 불가 상태로 고정되던 버그와 유효하지 않은 URL을 가진 서버에 대한 인증 시도 실패 문제도 수정되어 연결 신뢰도가 높아졌다.

개발자 경험과 디버깅 편의성도 개선되었다. /doctor prompt-audit 명령어를 통해 기존 모델에 맞춰 작성된 프롬프트 패턴을 감사할 수 있으며, 전체 화면 모드에서 다른 세션의 잘린 메시지를 클릭하여 확장해 볼 수 있다. 게이트웨이 헤더에 프롬프트 ID를 포함하는 옵션이 추가되어 LLM 게이트웨이가 사용자 요청을 그룹화하기 쉬워졌고, 플러그인 디렉토리 로드 실패 시 정확한 경로가 표시되므로 문제 진단이 용이해졌다.

기존 버그 수정도 광범위하게 적용되었다. SDK 세션에서 도구 호출 결과나 사용량 데이터가 유실되는 현상이 해결되었고, 모델 폴백 시 워크플로우가 의도한 대로 재시도되지 않던 문제가 수정되었다. 또한 /usage 명령어와 VS Code 확장 프로그램에서 텔레메트리가 비활성화되었을 때 주간 Fable 한도가 표시되지 않던 오류와, 특정 모델 ID 접미사 처리 관련 문제들이 모두 해결되어 사용량 추적과 모델 선택의 정확성이 확보되었다.
