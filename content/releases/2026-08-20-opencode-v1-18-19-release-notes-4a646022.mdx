이번 업데이트는 클라우드플레어 AI 게이트웨이 모델을 사용하는 사용자를 위해 OpenAI와 Anthropic 모델에 대한 네이티브 패스스루 기능을 추가했다. 이는 외부 API 게이트웨이를 통한 모델 호출 시 더 원활한 연동을 가능하게 한다. 또한 Codex의 속도 제한을 ChatGPT 구독 플랜의 한도에 더 가깝게 맞췄다. 이는 유료 구독자가 경험하는 서비스 수준과 일관성을 맞추기 위한 조치로, 과도한 요청 차단이나 불필요한 대기 시간을 줄이는 데 도움이 될 것이다.

비용 계산 및 설정 관련 버그 수정도 주요 변경 사항이다. 기존에 내장되어 있던 Qwen 모델의 샘플링 기본값 중 지원되지 않는 설정이 전송되는 문제를 제거했다. 이는 호환되지 않는 파라미터로 인한 에러를 방지한다. 또한 모델 가격 정보가 형식 오류일 경우 전체 비용 계산이 중단되는 것을 막고, 오류가 있는 데이터는 무시하도록 처리해 시스템의 안정성을 높였다. OpenAI 웹소켓 요청 시 메시지 크기 제한을 초과하는 경우에도 대체 경로를 통해 처리되도록 개선되었다.

연결 및 인증 흐름에서도 여러 개선이 이루어졌다. /connect 명령어에서 인증된 제공자를 올바르게 표시하지 않는 문제를 해결했으며, 계정 연결 프로세스에서 사용하는 기본 콘솔 URL도 업데이트했다. OpenCode Go 제공자를 사용할 때 웹 검색 기능이 활성화되었고, ChatGPT 워크스페이스의 컴퓨팅 거주지 정보가 Codex 요청으로 전달되도록 하여 컨텍스트 일관성을 유지한다. 또한 기존 v1 데이터베이스와의 호환성을 보존해 이전 버전 사용자들의 마이그레이션 부담을 줄였다.

데스크톱 애플리케이션에서는 서버 대화창에서 저장된 서버 세부 정보를 수정할 수 있도록 기능을 복원했다. 이는 사용자가 설정한 서버 정보를 쉽게 변경하고 관리할 수 있게 해준다. 이번 릴리스는 커뮤니티 기여자들의 도움으로 문서 경로 수정 및 제공자 목록 업데이트 등 다양한 부분에서 개선되었으나, 여기서는 핵심 기능 안정화와 연동성 강화에 초점을 맞춰 요약했다.
