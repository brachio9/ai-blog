이전 버전에서는 Hub 인스턴스가 재시작하거나 연결이 끊기는 경우 진행 중인 작업이 손실되거나 새로운 작업을 거부하는 문제가 있었다. 이번 업데이트는 이러한 상황을 개선하여, Hub가 재시작 중일 때 현재 실행 중인 작업은 완료하도록 하고 앱은 연결이 끊어졌던 동안 누락된 내용을 자동으로 다시 재생한다. 이를 통해 개발자는 중단 없이 작업을 이어갈 수 있게 되었다.

또한 OpenAI 호환 커스텀 모델에서 도구 호출 기능이 조용히 비활성화되는 버그를 수정했다. 이는 `supportsReasoning` 같은 편의 플래그로부터 기능 목록을 추론하는 과정에서 발생하던 문제였으며, 이제 해당 모델들이 의도대로 도구를 호출할 수 있게 되었다.

모델 카탈로그도 새로 고쳐져 주요 제공업체의 모델 목록과 가격 정보가 업데이트되었다. DeepSeek, Crof, CrossModel, Eden AI, Kilo, NanoGPT 등 여러 서비스의 기본 모델 설정이 변경되었으므로 사용자는 최신 정보를 바탕으로 모델을 선택할 수 있다.

마지막으로 앱은 이제 서버 측 기능 플래그를 존중하며 계정 변경 시 이를 자동으로 새로 고친다. 이는 사용자 계정의 상태에 따라 앱의 동작을 더 정확하게 조정하기 위한 개선 사항이다. 전체 변경 내역은 공식 저장소의 비교 링크에서 확인할 수 있으며, 여기서는 주요 변경점만 요약했다.
