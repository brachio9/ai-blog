사이드바는 다시 기본값으로 시간 순서대로 정렬되며, 고정된 항목과 예약된 세션, 일반 작업을 접을 수 있는 섹션으로 나누어 표시한다. 이전의 드롭다운 메뉴는 사라지고 프로젝트별 그룹화로 전환하는 버튼 하나로 대체되어 공간 활용도가 향상되었다. 예약된 세션은 시계 아이콘으로 구분되며, 리스트가 사이드바 전체 높이를 채우도록 확장되어 빈 공간을 줄였다. 각 세션 행에는 마우스를 올리면 삭제 버튼이 나타나며, 컨텍스트 메뉴와 동일한 확인 절차를 거쳐 빠르게 정리할 수 있다.

마켓플레이스와 커스텀 설정 페이지가 분리되었다. 커스텀 페이지는 이미 설치된 인벤토리만 표시하고, 플러그인과 MCP 서버, 스킬을 한눈에 볼 수 있는 전용 마켓플레이스 페이지로 이동하여 검색 및 필터링할 수 있다. 두 페이지는 헤더와 사이드바 하위 탭을 통해 서로 연결되어 접근성을 높였다. 예약된 작업 카드 전체를 클릭하면 상세 정보가 열리며, 불필요한 아이콘이 제거되고 실행 또는 수정 버튼이 커져 터치나 클릭 실수를 줄였다.

예약된 세션의 상세 뷰는 개요와 실행 기록 탭을 하나의 스크롤 가능한 화면으로 통합했다. 메타 정보, 설정, 최근 실행 기록을 한눈에 볼 수 있으며, 전체 실행 내역을 확장하여 확인할 수 있다. '지금 실행' 버튼을 누르면 해당 세션이 즉시 열리며, 자동화 실행 중 시스템 내부 메시지가 사용자의 입력처럼 표시되지 않아 결과물이 프롬프트와 작업 요약, 답변으로 깔끔하게 정리된다. 실행 중인 예약 세션을 열 때 멈춰 버리는 현상과 마켓플레이스에서 플러그나 MCP 서버 설치 시 CLI 경로 오류가 발생하던 문제도 해결되었다.

구독 기반 제공자(ClinePass, ChatGPT Codex, Claude Code)에 대해 더 이상 API 사용량 기반 비용 추산치를 표시하지 않아 구독료와 중복된 요금으로 오해하는 것을 방지했다. 호버 카드가 클릭 시 깜빡이며 닫혔다 다시 열리는 버그와 macOS DMG 설치 창의 커스텀 아트웤 적용, 그리고 Git 원격 URL에 포함된 자격 증명이 모델에게 전송될 때 자동으로 마스킹되는 보안 개선 사항도 포함되었다. 이 요약은 주요 변경 사항만 추려낸 것이며 전체 변경 내역은 공식 릴리즈 노트를 참조해야 한다.
