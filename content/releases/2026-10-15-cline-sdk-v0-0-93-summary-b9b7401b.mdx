이번 릴리스의 가장 큰 변화는 플러그인 실행 방식이다. 기존에 노드나 번 서브프로세스를 통하던 방식을 프로세스 내 단일 레지스트리로 통합했다. 이로 인해 컴파일된 CLI와 허브가 PATH 상의 런타임에 의존하지 않게 되었으며, 번 기반 허브에서는 번 전역 변수를 플러그인이 사용할 수 있게 되었다. 플러그인 오류가 더 이상 세션 전체를 마비시키거나 도구만 조용히 사라지지 않도록 상태 추적과 타임아웃 기능이 강화되었고, 실패한 플러그인은 개별적으로 격리되어 다른 작업에 영향을 주지 않는다.

추론 기능 제어와 토큰 계산 정확도도 개선되었다. 추론 비활성화 옵션이 특정 제공자에 국한되지 않고 모든 제공자에게 적용되며, 각 모델의 특성에 맞춰 네이티브 설정이나 포터블 옵션 중 적절한 것만 전송한다. 특히 이미지 처리 시 base64 페이로드를 텍스트 토큰으로 잘못 계산하던 문제가 해결되어, 이제 이미지당 고정된 토큰 수로 추정된다. 이는 몇 장의 스크린샷만으로 불필요한 자동 압축이 발생하는 오류를 근본적으로 잡았다.

자동 압축 로직도 더 정확하게 작동한다. 이전에는 카탈로그 엔트리의 컨텍스트 윈도우 제한을 무시하고 오버라이드된 모델 설정과 맞지 않는 예산으로 압축을 시도하는 경우가 있었는데, 이제 해결된 모델의 실제 컨텍스트 윈도우를 기준으로 처리한다. 또한 스케줄된 작업 실행 시 데이터베이스 바인딩 오류로 인한 대기 상태 고착 문제와, 동일한 스케줄의 중복 발생 시 백로그가 쌓이는 현상이 수정되어 더 안정적인 배치 처리가 가능해졌다.

기본 모델 설정도 업데이트되었다. 클라인 제공자의 기본 모델은 추천 목록의 첫 번째 항목이 되며, 폴백 모델과 오픈로이터 제공자의 기본 모델 모두 클로드 소넷 5.5로 변경되었다. 이는 사용자가 명시적으로 모델을 지정하지 않았을 때 최신 성능의 모델을 기본적으로 사용하도록 유도하는 방향이다. 이번 요약은 주요 변경 사항 중 일부를 다루었으며, 전체 커밋 목록이나 기여자 명단은 생략했다.
