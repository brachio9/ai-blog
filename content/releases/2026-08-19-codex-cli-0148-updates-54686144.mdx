이번 업데이트의 가장 눈에 띄는 변화는 작업 흐름의 유연성이다. 이제 `/export` 명령어를 통해 TUI 대화 전체를 마크다운 형식으로 클립보드나 파일로 내보낼 수 있다. 또한 `codex exec fork` 명령을 사용해 현재 세션을 분기하거나, 이전 세션을 복원하는 기능이 강화되었다. 초기화 중에도 프롬프트를 미리 작성할 수 있게 되어 대기 시간을 줄일 수 있으며, `/status` 명령으로 예상 크레딧 사용량을 확인할 수 있게 되었다.

외부 서비스 연동 측면에서는 Amazon Bedrock 런타임을 기본 제공자로 추가했다. AWS 프로필과 리전 설정을 통해 GPT-5.6 라우팅을 지원한다. 또한 훅(Hooks)이 비동기 명령 실행과 MCP 도구 호출을 지원하게 되어 자동화 시나리오의 범위가 넓어졌다.

안정성 측면에서도 상당한 개선이 있었다. 모델 전환이나 설정 변경 시 이전 지시가 남아 있거나 진행 중인 턴이 중단되는 문제가 해결되었다. 세션 복원 시 작업 디렉터리와 승인 정책이 정확히 유지되며, 일시적인 서비스 중단이나 OAuth 재인증 상황에서도 MCP 서버가 자동으로 복구된다. 터미널 입력 버퍼링으로 인한 우발적 실행 방지 및 CRLF 붙여넣기 처리 개선 등 사용자 경험(UX) 관련 버그들도 다수 수정되었다.

문서화 부분에서는 스킬 생성 가이드가 더 명확해졌으며, 미완성 TODO 플레이스홀더를 검증 과정에서 거부하는 기능이 추가되었다. 이번 릴리즈는 대화 관리의 편의성과 외부 인프라와의 통합을 강화하면서도 기존 사용자들이 겪었던 안정성 문제를 해결하는 데 중점을 두었다.
