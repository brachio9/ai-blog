이번 업데이트는 사용자들이 궁금해하던 맥문동(context window) 효율성과 안정성에 초점을 맞췄다. 가장 눈에 띄는 변화는 `/status` 및 `claude doctor` 명령어에 조직 정책 로딩 실패 원인을 명시하는 기능이 추가된 점이다. 프록시 설정 등 네트워크 문제로 인해 정책이 로드되지 않을 때 그 이유를 바로 확인할 수 있게 되었다. 또한 `bashOutputMaxChars`와 `taskOutputMaxChars` 설정을 통해 Claude가 인라인으로 받을 수 있는 명령어 및 백그라운드 작업 출력의 최대 크기를 128K 문자까지 늘릴 수 있게 되었으며, 이는 긴 출력을 파일로 저장하기 전에 더 많은 정보를 모델이 직접 처리할 수 있음을 의미한다. 대용량 시스템 프롬프트를 명령줄 인자로 전달하는 대신 파일에서 읽어올 수 있는 `--append-subagent-system-prompt-file` 옵션도 새로 도입되었다.

맥문동 관리와 관련된 유용한 도구로 `/skill-doctor`가 추가되었다. 이 명령어는 현재 로드된 스킬 중 실제로 사용되지 않는 항목을 식별하고, 해당 스킬이 맥문동에 차지하는 비용을 표시한다. 이를 통해 사용하지 않는 스킬을 정리하여 맥문동을 효율적으로 활용할 수 있다. 또한 빠른 입력이나 키 반복 시 발생하는 문자 순서 뒤바뀜 및 누락 버그를 수정하여 타이핑 경험을 개선했다. `/net` 자동 마운트 디렉토리에서 서브디렉토리를 추가할 때 발생하던 오류 메시지도 정상적으로 처리되도록 고쳤다.

원격 제어(Remote Control) 기능의 안정성 개선이 이번 릴리즈의 핵심 중 하나다. 모바일이나 브라우저에서 세션을 중단하거나 로컬 슬래시 명령어를 실행한 후에도 스피너가 멈추지 않고 작업 중인 것처럼 표시되는 버그를 수정했다. 또한 터미널 세션에 다른 장치가 연결되거나 권한 모드가 변경될 때 원격 제어 화면이 최신 상태를 반영하지 못하던 문제도 해결되었다. TLS 검사 프록시 환경에서 Windows 네이티브 클라이언트의 인바운드 이벤트 스트림이 실패하던 문제와, `/teleport`로 가져온 세션이 원래 세션에 중복으로 표시되던 오류 역시 수정되어 원격 작업의 신뢰성이 높아졌다.

기존 버그 수정 사항도 광범위하게 적용되었다. AWS Bedrock 설정 마법사가 응답을 기다리며 멈춰 서던 문제를 타임아웃 처리로 개선하고, TLS 검사 프록시 뒤에서 모델 확인이 실패하던 문제를 해결했다. 클라우드 세션에서 관리 설정에 의해 강제 활성화된 플러그인이 로컬 동기화 상태와 충돌하여 마켓플레이스 클론으로 대체되다 실패하던 문제도 수정되었다. 또한 백그라운드 에이전트 재개 실패 시 발생하는 높은 CPU 사용률 문제와, GCP 인증 갱신 시 불필요하게 브라우저가 열리던 현상도 개선되었다. 이 외에도 세션 복원 시 병렬 도구 호출 컨텍스트가 손실되던 문제와 초기 프롬프트 직후의 중단 요청이 무시되던 버그 등이 수정되어 전체적인 실행 안정성이 향상되었다.
