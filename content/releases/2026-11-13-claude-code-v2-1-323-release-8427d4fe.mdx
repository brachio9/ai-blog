이번 업데이트에서 가장 눈에 띄는 변화는 실험적 기능인 코드 모드(Code Mode)의 추가다. 이 모드는 Claude가 도구를 호출하기 위해 직접 자바스크립트를 작성하는 방식으로 작동하며, 사용자가 선택적으로 활성화하거나 조직 단위로 비활성화할 수 있다. 또한 플러그인 시스템의 안정성을 위해 타입 체크 기능이 강화되었고, 플러그인 설치 및 업데이트 시 버전 호환성을 확인하는 로직이 개선되었다.

사용자 경험 측면에서는 긴 작업이 실행될 때 호스트 프로그램이 연결 끊김으로 인식하지 않도록 30초마다 진행 상태를 알리는 하트비트 기능이 추가되었다. 또한 문서 파일인 .docx를 아티팩트 도구의 자산 업로드에서 지원하며, 디프(diff) 패널에서 이전 메시지를 요약하거나 이전 세션을 재개할 때 발생하던 오류들이 수정되었다. 

성능 및 안정성 개선도 포함되었다. 특히 매우 큰 파일을 변경한 직후에 발생하던 메모리 급증 현상과 특정 시스템 파일에서 발생하던 메모리 부족 오류가 해결되었다. 보안과 편의를 위해 Bash 허용 규칙에 와일드카드가 포함된 경우 경고를 표시하며, 플러그인의 언어 서버가 시작되지 않을 때 구체적인 확인 사항을 안내하는 기능이 추가되었다. 

이번 릴리스 노트에는 많은 변경 사항이 포함되어 있으나, 핵심은 코드 모드 도입과 대용량 파일 처리 시의 안정성 확보로 요약된다. 상세한 변경 사항은 공식 릴리스 노트를 참조해야 한다.
