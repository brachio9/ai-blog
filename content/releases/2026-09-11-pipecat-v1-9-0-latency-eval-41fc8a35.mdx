이번 업데이트는 봇 응답 속도를 정확히 측정하는 데 집중했다. 기존에는 전체 지연 시간만 알 수 있었지만, 이제 사용자가 말한 순간부터 봇이 응답하기까지의 과정을 VAD 침묵 구간, 턴 감지, 문장 집계 등 세부 단계로 나누어 볼 수 있다. 각 단계가 어떤 서비스나 설정에 의해 발생했는지 명확히 구분되므로, 병목 현상을 찾는 데 유용하다. 특히 파이프라인 준비 완료 시점부터 첫 응답까지의 대기 시간도 포함해 측정하므로, 실제 사용자 경험에 더 가까운 데이터를 제공한다.

평가(Eval) 시나리오 작성 방식이 유연해졌다. 기존에는 텍스트를 합성해 음성으로 변환해야 했지만, 이제 WAV나 MP3 같은 실제 오디오 파일을 직접 입력으로 사용할 수 있다. 파일 경로와 해당 음성이 의미하는 텍스트 내용을 함께 지정하면, 판정 로직이나 텍스트 포함 여부 검증이 정상적으로 작동한다. 이 기능은 특정 발음이나 억양을 테스트할 때 유용하며, 복잡한 음성 합성 설정 없이도 평가 시나리오를 구성할 수 있게 했다.

LLM 스위처의 함수 등록 기능에도 개선이 있었다. `cancellable_by_llm` 인자를 추가해, LLM 측에서 함수 실행을 취소할 수 있는 옵션을 지원하도록 했다. 이는 개별 LLM 서비스에서 제공하던 기능을 스위чер 수준에서도 일관되게 사용할 수 있게 함으로써, 도구 호출의 유연성과 제어를 강화한다. 여러 LLM을 전환하며 사용하는 환경에서 함수 실행 중단을 더 정교하게 관리할 수 있게 되었다.

또한 AssemblyAI 기반의 동기식 음성 인식 서비스인 `AssemblyAISyncSTTService`가 추가되었다. 이 서비스는 스트리밍 세션을 관리하지 않고, VAD로 분할된 오디오 조각을 HTTP 요청으로 전송해 전사한다. 최근 대화 맥락을 자동으로 포함시켜 정확도를 높일 수 있으며, 데이터 거주지 설정이나 모델 선택 등 다양한 설정이 가능하다. 스트리밍 방식의 복잡함을 피하면서도 충분한 문맥 정보를 활용한 전사가 필요한 경우에 적합하다.
