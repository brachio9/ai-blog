llama.cpp b11103 릴리즈는 HunyuanOCR 및 관련 비전-언어 모델에서 DFlash 투기적 디코딩을 사용할 때 발생하던 중단 문제를 해결한다. 기존에는 타겟 그래프가 각 레이어에 들어오는 잔류 스트림(residual stream)을 노출하지 않아, 드래프트 모델이 교차 컨텍스트를 구성하는 과정에서 첫 번째 그래프 빌드 단계에서 에러를 내고 실행이 멈췄다. 이번 업데이트는 Qwen3 등 다른 DFlash 지원 모델과 동일하게 레이어 루프 상단에서 해당 텐서를 등록하도록 수정해 이 문제를 해결했다.

변환 과정에서도 두 가지 주요 오류가 고쳐졌다. 먼저 DFlash 드래프트 모델을 Hunyuan 타겟으로 변환할 때, 어휘 처리 메서드 호출 중 존재하지 않는 인스턴스 메서드를 참조하며 에러가 발생하던 문제가 수정되었다. 이를 위해 어휘 헬퍼 함수를 모듈 레벨로 분리하고 명시적인 모델 인자를 받도록 구조를 변경했다. 또한 변환 시 드래프트 모델의 설정이 타겟 모델의 특수 토큰 ID 확인 로직에 잘못 적용되어 패딩 토큰 ID가 음수인 경우 충돌하거나 불일치하는 값을 기록하던 문제도 해결되었다.

개발진은 tencent/HunyuanOCR 1.5와 그 DFlash 드래프트 모델을 사용해 테스트했으며, 이미지 요청이 정상적으로 실행되고 드래프트 수용률이 약 0.5로 유지됨을 확인했다. 특히 OCR 출력 결과가 투기적 디코딩을 사용하지 않은 일반 실행과 바이트 단위로 동일하게 일치함을 검증해 정확성 저하가 없음을 입증했다.

이번 변경은 DFlash 구현체가 해당 레이어 ID를 활성화할 때만 영향을 미치므로, 별도의 드래프트 모델을 사용하지 않는 일반적인 사용 환경에서는 기존 동작 방식이 유지된다. Hunyuan-dense 모델도 동일한 그래프를 재사용하므로 개선 효과가 적용되지만, 별도 그래프를 사용하는 Hunyuan-moe 모델은 이번 수정 범위에서 제외되었다.
