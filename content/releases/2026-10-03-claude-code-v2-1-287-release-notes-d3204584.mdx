이번 업데이트의 핵심은 플러그인이 Claude의 내부 동작을 더 깊이 수정할 수 있게 된 것이다. 특히 'You should know'라는 내장 모드가 추가되어, 사용자와 Claude가 놓칠 수 있는 부분을 감시하는 사이드 에이전트가 작동한다. 이 기능은 명령어를 통해 활성화하며, 텔레메트리 설정이 켜져 있을 때 사용할 수 있다. 이는 개발자가 코딩 중 실수나 위험한 상황을 사전에 인지하는 데 도움을 줄 것으로 보인다.

사용성 측면에서는 에이전트 뷰에서 세션 이름과 작업을 필터링할 수 있는 기능이 개선되었다. 이제 접힌 섹션에서도 일치 항목을 확인하고 엔터키로 바로 이동할 수 있어 작업 흐름이 더 매끄러워졌다. 또한 MCP 서버의 URL 프롬프트 지원이 강화되어 로그인 같은 상호작용이 원활해졌으며, Windows 환경에서 Bash 도구를 거부할 경우 PowerShell도 함께 비활성화되는 것에 대한 경고 메시지를 추가해 혼란을 줄였다.

안정성과 보안 관련 버그 수정도 다수 포함되었다. 가장 중요한 변경점은 위험한 삭제 명령어 실행 시 항상 확인을 요청하는 안전 장치가 특정 조건에서 우회되는 문제가 해결된 것이다. 또한 원격 제어 연결 끊김 재시도 로직이 개선되어 메시지 수신 지연이 줄어들었고, Bedrock 및 Vertex AI의 모델 체크 오류, Chrome 브라우저 선택기 파싱 오류 등 다양한 환경에서의 작동 문제들이 수정되었다.

마지막으로 모델 전환 시 MCP 도구 선언이 덮어씌워지는 문제와 CLAUDE.md 파일이 중복 첨부되는 버그가 해결되어 일관된 개발 환경을 제공한다. 이 요약은 주요 변경 사항만 추린 것이므로, 전체 커밋 목록이나 기여자 명단은 공식 릴리즈 노트를 참고해야 한다.
