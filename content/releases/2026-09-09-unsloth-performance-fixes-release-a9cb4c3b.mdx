이번 Unsloth 업데이트는 성능 향상과 신뢰성 강화에 중점을 둔 대규모 릴리즈다. 가장 주목할 만한 변화는 AMD 환경에서의 개선으로, Strix Halo와 같은 최신 AMD GPU에서 Vulkan을 기본 백엔드로 사용하도록 변경되었다. 이로 인해 프롬프트 처리 속도가 최대 23%, 생성 속도가 8%까지 빨라졌으며 ROCm 대비 20%의 성능 향상을 보였다. 또한 리눅스 환경에서 ROCm을 지원하지 않는 AMD iGPU도 CPU 대신 Vulkan을 사용하게 되어 추론이 가능해졌다.

애플 실리콘 사용자들을 위한 MLX 최적화도 크게 개선되었다. 게이트드 델타 모델의 학습 속도가 최대 25% 빨라졌고, 양자화된 KV 캐시를 통해 프롬프트 메모리 사용량을 기존 대비 최대 74%까지 줄일 수 있게 되었다. 또한 DoRA 파인튜닝과 다양한 DPO 손실 함수 지원이 추가되었으며, 배치 생성 시 각 채팅을 독립적으로 스트리밍하고 샘플링하는 기능이 구현되어 멀티모달 모델 학습도 더 원활해졌다.

사용자 경험과 안정성 측면에서도 여러 개선 사항이 적용되었다. Windows 환경에서는 llama-server.exe에 서명이 적용되어 스마트 앱 컨트롤(SAC)의 오보가 줄어들었으며, 코드 무결성 차단 시 명확한 안내 메시지가 표시된다. 스튜디오와 API 기능에서는 RAG 문서 업로드가 더 이상 멈추지 않고 진행되며, GPT-6 아스트라가 코덱스 로그인에 기본 적용되어 추론 수준 조절이 가능해졌다. 앱이미지(AppImage)의 지연 문제도 해결되어 실행이 더 매끄러워졌다.

설치 및 배포 환경 역시 업데이트되었다. PyTorch 2.11이 모든 설치 프로그램의 기본 버전으로 변경되었으며, 머신러닝 라이브러리인 Unsloth 파이썬 패키지 크기가 44% 줄어든다. 도커 허브에는 NVIDIA 튜링부터 블랙웰까지 지원하는 새로운 이미지와 AMD64, ARM64 네이티브 이미지가 공개되어 스튜디오와 노트북 환경에서의 실행이 더 용이해졌다. 이번 릴리즈는 전체 커밋 목록 중 주요 변경 사항만 추려낸 것이므로 상세한 기술적 수정 내역은 공식 저장소를 참고해야 한다.
