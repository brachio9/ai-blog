이번 업데이트의 가장 큰 변화는 플러그인 생태계의 확장이다. 개발자는 이제 `turn.step` 훅을 통해 API가 자체적으로 실행한 도구 호출 내역을 상세히 확인할 수 있게 되었다. 또한 `tool.check` 이벤트에 에이전트 식별자와 승인 기준(ceiling)이 추가되어, 메인 세션과 서브 에이전트의 권한 검사를 명확히 구분하고 조직의 승인 정책을 더 정교하게 적용할 수 있다. 에디터에서 테마 색상을 직접 지정할 수 있는 타입 정의도 함께 제공되었다.

사용자 경험 측면에서도 편의 기능이 강화되었다. 게이트웨이 로그인 승인 페이지에 거절 버튼이 추가되어 대기 중인 터미널을 즉시 종료할 수 있게 되었다. 세션 관리 명령어인 `attach`와 `logs`에서 이제 ID 대신 세션 이름의 일부를 입력해도 작동한다. 또한 Managed Agents 패턴 설정 시 외부 파일 링크나 샌드박스 경로 무시 경고가 나타나며, 이를 통해 설정 오류를 사전에 방지할 수 있다.

안정성 개선 역시 이번 릴리즈의 핵심이다. 프록시나 게이트웨이 환경에서 특정 베타 헤더로 인해 요청이 실패하던 문제가 해결되었다. 수백 장의 이미지가 포함된 긴 세션에서 모델 처리 불가 오류로 멈추던 현상과, 응답 필터링 중 갑작스럽게 턴이 종료되던 버그도 수정되었다. 웹 페치 기능은 이제 10만 자를 초과하는 텍스트를 침묵 없이 잘라내지 않고, 읽지 못한 분량을 명시하고 오프셋을 통해 계속 읽도록 개선되었다.

마지막으로 스케줄링 및 자동화 관련 버그들이 다수 해결되었다. 대화 압축 후 사라지던 예약된 작업과 백그라운드 전환 후 실행되지 않던 반복 태스크가 정상 작동하도록 수정되었다. 중첩된 리스트나 인용문으로 인한 스택 오버플로우 크래시와, 구조화된 출력 전송 후 연결 끊김 시 에러 코드가 잘못 반환되던 문제도 함께 패치되었다. 이 외에도 계획 모드에서 읽기 전용이 아닌 도구 승인을 허용하던 보안 관련 결함도 수정되었다.
