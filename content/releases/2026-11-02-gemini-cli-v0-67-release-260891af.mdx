이번 릴리스에서는 터미널 환경에서 발생하던 다양한 시각적 오류들을 수정했다. 특히 터미널 너비가 변경될 때 히스토리가 제대로 다시 그려지지 않던 문제나, 특수 문자가 포함된 텍스트가 잘릴 때 발생하는 UI 깨짐 현상을 해결하여 사용자 경험을 개선했다.

시스템 내부 로직에서도 중요한 개선이 이루어졌다. Windows 환경에서 파일 경로를 인식하는 방식이 개선되었으며, PowerShell을 활용한 IDE 프로세스 조회 기능이 강화되었다. 또한 LLM 프롬프트 템플릿에서 발생하던 패턴 오염 문제를 방지하여 모델과의 상호작용이 더욱 정확해졌다.

사용자 편의를 위한 기능도 포함되었다. API 호출 시 발생하는 429 에러(Rate Limit) 상황에서 대기 시간을 시각적으로 보여주는 인디케이터가 추가되었으며, 확장 프로그램 검증 및 평가 테스트 기능이 새롭게 도입되었다. 이번 업데이트는 전체 변경 사항 중 핵심적인 개선 사항만을 포함하고 있으며, 상세한 변경 내역은 공식 저장소에서 확인할 수 있다.
