Unsloth는 Inkling 2 모델을 다양한 GPU 환경에서 더 빠르게 실행할 수 있도록 최적화했다. 특히 8GB 및 12GB 메모리 GPU에서 Inkling 2 Mini 모델의 디코딩 속도가 최대 1.9배 향상되었으며, 추측적 디코딩(Speculative decoding)을 통해 더 빠른 응답을 제공한다. 또한 메모리 관리 개선을 통해 긴 프롬프트 처리 시 발생하던 메모리 부족 문제를 완화했다.

학습 측면에서는 GRPO 및 AsyncGRPO의 효율성이 대폭 개선되었다. AsyncGRPO는 메모리 내에서 어댑터를 전달하는 방식을 채택해 단계별 소요 시간을 최대 40% 단축했으며, 특정 하드웨어 환경에서 GRPO 롤아웃 속도가 2배 빨라졌다. 이 외에도 MoE 학습 시 발생하던 메모리 누수 문제를 해결하고 다양한 모델의 파인튜닝 지원을 강화했다.

멀티미디어 생성 성능도 눈에 띄게 향상되었다. Qwen-Image-Flash를 통해 이미지 생성 속도를 기존 대비 약 14배 높였으며, FastWan 모델을 통해 비디오 생성 속도를 최대 3배까지 개선했다. 특히 두 개의 GPU를 사용할 경우 비디오 렌더링을 분산 처리하여 더 빠른 결과물을 얻을 수 있다.

이번 업데이트는 추론과 학습, 그리고 멀티미디어 생성 전반에 걸친 성능 최적화를 목표로 한다. 다만 이번 요약은 전체 업데이트 내용 중 주요 성능 개선 사항만을 선별하여 정리한 것이며, 세부적인 기술적 변경 사항은 공식 릴리즈 노트를 참조해야 한다.
