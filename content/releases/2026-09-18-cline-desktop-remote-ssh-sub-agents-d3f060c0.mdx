Cline은 이제 SSH를 통해 원격 머신에서 작업을 수행할 수 있게 되었으며, 앱 자체는 로컬에 남아 있다. 설정의 Remote 메뉴에서 호스트를 추가하고 테스트한 후 웰컴 화면의 환경 선택기에서 이를 선택하면 된다. 연결이 되면 원격 사용자의 홈 디렉토리에서 시작되며, 워크스페이스 선택기에서 프로젝트를 찾거나 Local을 선택해 연결을 끊을 수 있다. 에이전트 도구, 워크스페이스 탐색, Git 메타데이터 및 세션 지속성은 호스트에서 실행되고, 승인 및 라이브 세션 이벤트는 터널을 통해 인증된 Cline Hub 프로토콜만 전달되어 데스크톱으로 돌아온다.

원격 연결 시 SSH 설정 별칭이 지원되며, 포트 공백 시 별칭의 자체 구성을 사용하거나 명시적으로 입력해 덮어쓸 수 있다. 호스트별 최근 및 마지막 사용 워크스페이스가 별도로 기억되고, 호스트 메타데이터는 `~/.cline/data/settings/remote-environments.json`에 저장된다. 이 파일은 개인 키 내용을 기록하지 않고 아이덴티티 파일 경로만 기록하며, SSH 클라이언트가 이미 신뢰하는 호스트 키를 요구한다. 첫 연결 시 Cline은 `~/.cline/remote/`에 자체 헬퍼를 업로드하여 재연결 속도를 높이고 캐시하며, 기존 Cline CLI 허브 실행에는 영향을 주지 않는다.

지원되는 원격 호스트는 Linux x64 및 arm64이며, 32비트 라즈베리파이 운영 체제는 지원되지 않는다. macOS 호스트의 경우 `CLINE_REMOTE_HELPER_BINARY`를 통해 로컬에서 빌드된 헬퍼가 필요하다. 현재 원격 세션에서는 파일 첨부 및 로컬 편집기에서의 원격 파일 열기가 불가능하지만, 텍스트, 이미지, 파일 언급 및 검색, Git 브랜치 작업, 세션 기록 및 원격 에이전트 도구는 사용할 수 있다.

또한 동일한 단계에서 생성된 서브 에이전트가 이제 순차적으로가 아닌 동시에 실행된다. 이로 인해 세 개의 독립적인 작업을 위임할 때 가장 느린 작업의 시간이 소요되며, 모든 작업 시간의 합이 걸리지 않는다. 순서대로 실행해야 하는 도구는 여전히 순차적으로 처리되며, 연속된 병렬 호출만 중복되어 실행된다. 이 릴리스에는 언급되지 않은 다른 변경사항들도 포함되어 있으므로 전체 변경 내역은 공식 저장소를 참고할 것을 권장한다.
