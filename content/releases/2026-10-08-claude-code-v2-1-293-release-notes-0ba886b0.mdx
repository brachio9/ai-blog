이번 업데이트는 Anthropic API에서 새로운 표준이 된 Claude Haiku 5.5 모델을 공식적으로 지원한다. 이 모델은 100만 토큰의 컨텍스트 윈도우를 제공하며, 기존 대비 비용 효율성을 개선한 가격 책정이 적용되었다. 또한 서브에이전트 상태 페이로드에 에이전트 유형 정보가 추가되어 스크립트를 통한 세분화된 제어가 가능해졌다. 개발자들은 도구 등록 시 `isDeferred` 플래그를 사용하여 프롬프트 초기 단계부터 도구의 스키마를 노출시킬 수 있게 되었다.

가장 주목할 만한 개선점은 컨텍스트 압축 과정 중 발생하는 작업 중복 실행 및 취소 오류 해결이다. 이전 버전에서는 모델이 자신의 마지막 행동을 이미 완료된 것으로 오인하여 작업을 되돌리거나 다시 수행하는 문제가 발생했으나, 이번 패치로 이러한 현상이 수정되었다. 또한 HTTP MCP 연결에서 발생한 메모리 누수 문제도 해결되어 장시간 실행 시 시스템 자원을 더 효율적으로 사용할 수 있게 되었다.

사용자 인터페이스 및 세션 관리의 안정성도 크게 강화되었다. 백그라운드 전환 중 메시지 유실, Chrome 브라우저에서의 TUI 연결 끊김, 그리고 긴 대화에서 발생하는 스트리밍 지연 문제들이 해결되었다. 특히 리모트 컨트롤 세션과 클라우드 환경에서의 응답 속도 개선은 실제 개발 워크플로우에 긍정적인 영향을 미칠 것으로 보인다. 또한 `/ultrareview` 명령어 사용 시 발생할 수 있는 Git 인덱스 오류 및 파일 업로드 거부 문제도 수정되어 리포지토리 관리가 원활해졌다.

이 외에도 플러그인 테스트 실패, 커스텀 에이전트 표시 오류, 그리고 세션 폴더 읽기 실패 시 푸터 정보 사라짐 등 다양한 미미하지만 빈번하게 발생하던 버그들이 일괄 처리되었다. 로그인 만료 시 발생하는 비정상적인 로그아웃 문제와 원격 제어 세션의 상태 보고 오류도 함께 수정되어 전체적인 사용 경험의 신뢰도가 높아졌다.
