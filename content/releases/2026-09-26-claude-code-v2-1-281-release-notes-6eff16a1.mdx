이번 릴리즈는 세션 중단 후 복구 시 발생할 수 있는 대화 맥락 손실 문제를 집중적으로 해결했다. 이전 버전에서는 API 재시도 중 인터페이스 오류로 세션이 강제 종료되거나, 큰 용량의 세션을 다시 열 때 마지막 메시지만 불러와지는 현상이 발생했다. 특히 권한 요청 중 재부팅하거나 도구 호출 도중 세션이 끊겼을 때 히스토리가 꼬여 프롬프트 캐시가 무효화되는 치명적인 버그를 수정함으로써, 중단된 작업을 이어갈 때 이전의 추론 과정이 유지되도록 안정성을 크게 높였다.

Claude Apps 게이트웨이의 기능이 확장되어 AWS Bedrock과의 통합이 더 유연해졌다. 이제 게이트웨이가 STS를 통해 다른 AWS 계정의 IAM 역할을 가정하고 Bedrock을 호출할 수 있게 되었으며, 각 요청마다 Amazon Bedrock 가드레일을 적용할 수 있는 설정이 추가되었다. 또한 데스크톱 정책 블록에서 최신 Claude Desktop 키에 대한 지원이 강화되어 작업 디렉토리 외부 읽기 차단 및 우회 권한 모드 비활성화 등 보안 관련 제어가 더 세밀해졌다.

개발자 경험과 관측 가능성 측면에서도 개선 사항이 많다. MCP 서버 설정 파일의 유효성을 검사하는 기능이 강화되어 로드 시 무시될 수 있는 항목이나 안전하지 않은 URL을 사전에 경고하며, 브라우저 기반 흐름을 위한 MCP URL 모드 elicitation가 추가되었다. 또한 /insights 명령어를 통해 최근 세션에서 자동 모드가 처리했을 것으로 추정되는 권한 프롬프트 횟수를 확인할 수 있게 되어, 워크플로우 최적화에 도움이 될 전망이다.

사용성 측면에서는 전체 화면 모드에서 스크롤바가 마우스 호버 시 나타나는 등 인터페이스 편의성이 개선되었고, 설정 파일을 통해 커밋 및 PR 귀속 정보를 숨길 수 있는 옵션이 추가되었다. 다만 이 설정은 구 버전 CLI와의 호환성을 위해 객체 형태를 유지해야 한다. 이번 업데이트는 주요 버그 수정과 게이트웨이 기능 확장에 초점을 맞추었으며, 전체 변경 사항 중 핵심적인 부분만 추려 정리한 것이다.
