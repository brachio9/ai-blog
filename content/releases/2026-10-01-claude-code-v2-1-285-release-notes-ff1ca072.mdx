이번 업데이트는 개발자의 작업 흐름을 끊지 않도록 하는 데 초점을 맞췄다. 가장 눈에 띄는 변화는 `claude --desktop` 명령어를 통해 현재 디렉토리나 기존 세션에서 Claude 데스크톱 앱을 바로 열 수 있게 된 점이다. 또한 플러그인 설정이 훨씬 직관적으로 바뀌었다. 설치 시점에 MCP 서버 설정을 미리 지정하거나, 구성 옵션을 쉽게 확인하고 수정할 수 있는 명령어가 추가되어 복잡한 메뉴 탐색 없이 환경 설정을 완료할 수 있다.

보안과 제어 기능도 강화되었다. `CLAUDE_CODE_DISABLE_WEB_FETCH` 환경 변수를 통해 웹 검색 도구를 완전히 비활성화할 수 있게 되었고, 조직 단위에서 허용할 API 제공자를 제한하는 `allowedProviders` 관리 설정이 도입되었다. 이는 기업 환경에서 특정 클라우드 게이트웨이나 엔드포인트만 사용하도록 강제해야 할 때 유용하다. 또한 스트리밍되지 않은 요청의 타임아웃 재시도 횟수를 제어하는 환경 변수가 추가되어 네트워크 불안정 시 발생하는 중복 요청 문제를 완화한다.

안정성 측면에서도 여러 버그가 수정되었다. SSH를 통한 플러그인 설치 및 업데이트 시 git 설정을 제대로 인식하지 못하던 문제가 해결되었고, 운영체제가 관리 설정 파일 읽기를 차단할 경우 경고만 띄우고 실행을 계속하는 방식으로 변경되어 서비스 중단이 줄었다. 원격 제어 중 파일 첨부 실패 시 재시도 로직이 개선되었으며, 세션 중간에 모델을 변경했을 때 발생하는 토큰 제한 및 컴팩트 창 관련 오류도 수정되었다.

마지막으로 사용성 개선 사항들이 다수 반영되었다. 하위 에이전트의 권한 요청이 프롬프트 도구로 정확히 전달되도록 고쳐졌고, MCP 서버 목록 조회 시 터미널 이스케이프 시퀀스가 섞여 출력되는 문제가 해결되었다. 샌드박스 내 인라인 스크립트 실행 시 매번 승인을 요구하던 과도한 확인 창 문제도 수정되어 반복 작업의 효율이 높아졌다. 이번 릴리스는 이러한 기능 추가와 버그 수정을 통해 더 매끄러운 코딩 경험을 제공하고자 한다.
