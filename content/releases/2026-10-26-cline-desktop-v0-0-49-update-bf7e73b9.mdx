이번 업데이트의 핵심은 개발 워크플로우에 최적화된 인터페이스 변화다. 이제 세션 헤더에서 변경 사항을 한눈에 확인할 수 있는 버튼이 추가되었으며, 프로젝트 파일 패널을 통해 파일 트리와 Git 상태를 동시에 모니터링할 수 있다. 또한 통합 터미널 패널이 추가되어 별도의 창 전환 없이도 명령 실행이 가능해졌다.

사용자 편의성을 위한 세부적인 개선도 눈에 띈다. PR 상태 확인이 헤더 버튼으로 이동하여 접근성이 좋아졌고, 단축키 설정 및 실수로 인한 종료 방지 기능이 강화되었다. 특히 긴 트랜스크립트가 포함된 세션도 안정적으로 재개할 수 있도록 메시지 크기 제한 문제가 해결되었으며, 파일 뷰어의 가독성을 높이기 위한 줄 바꿈 기능이 도입되었다.

로컬 개발 환경을 선호하는 사용자를 위한 기능도 강화되었다. Ollama와 LM Studio를 지원하는 로컬 모델 설정 페이지가 새롭게 추가되었으며, 모델이 사용하는 메모리 양을 확인할 수 있는 지표가 제공된다. 또한 클라우드 채팅 시작 시 기본 모델 설정이 개선되었고, API 키 입력 방식이 개선되어 설정이 더욱 간편해졌다.

이번 업데이트는 대규모 프로젝트를 다루는 개발자들에게 특히 유용할 것으로 보인다. 다만 이번 릴리스 노트에는 많은 변경 사항이 포함되어 있으며, 위 내용은 그중 핵심적인 기능 변화만을 요약한 것이다.
