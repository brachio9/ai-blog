개발자들이 가장 궁금해하는 것은 최신 AI 모델과의 호환성이다. 이번 업데이트는 OpenAI 및 Azure OpenAI 호환 엔드포인트에서 GPT-6 계열 모델을 사용할 때 발생하던 오류를 해결한다. 이전 버전에서는 Cline이 `max_tokens` 파라미터를 보내며 모든 요청이 거부되었으나, 이제 올바른 `max_completion_tokens`로 변경되어 정상 작동한다.

기본 모델 설정도 중요한 변화가 있었다. 사용자가 특정 모델을 선택하지 않은 경우, Cline은 다시 한 번 Claude Sonnet 5.5를 기본 제공자로 사용한다. 이는 Cline이 권장하는 모델 목록의 최상위에 해당 모델이 복귀했음을 의미하며, 안정성과 성능을 고려한 선택으로 보인다.

모델 카탈로그도 대대적으로 새로워졌다. CommandCode와 Reflection이라는 새로운 제공자가 추가되었으며, 기존 제공자들의 기본 모델도 여러 군데에서 변경되었다. 예를 들어 302.AI는 Gemini 4 Argon을, Eden AI와 Prime Inference는 각각 Muse Spark Open과 같은 최신 모델을 기본값으로 채택했다.

이 외에도 CoreWeave, NanoGPT, Pioneer, Scaleway 등 다양한 제공자에서 Reflection Beam 1.0이나 Nemotron 3.5 Super VL, DeepSeek V4.1 Flash 등 각 플랫폼의 최적화된 모델로 기본 설정이 조정되었다. 이번 릴리스는 단순한 버그 수정을 넘어 사용 가능한 모델 생태계를 확장하고 최신 기술에 대한 접근성을 높이는 데 중점을 둔 업데이트다.
