이번 업데이트에서 가장 눈에 띄는 변화는 MCP 앱의 사용자 인터페이스다. 이제 Picture-in-Picture 모드의 창 크기를 자유롭게 조절할 수 있어 작업 흐름을 더 유연하게 다룰 수 있다. 또한 대화 중 특정 텍스트를 선택해 인용하는 기능이 추가되어, 복잡한 맥락을 정확히 전달하는 데 도움이 된다. 모델 메타데이터는 models.dev에서 실시간으로 가져오며, 실패 시 내장된 대체 데이터를 사용해 끊김 없는 경험을 제공한다.

지원되는 AI 모델의 범위가 넓어졌다. Opus 5.5와 GPT-6 시리즈의 일부 모델, 그리고 Meta Muse Code 프로바이더가 새로 추가되었다. 특히 GDK(Goose Development Kit) 기반 에이전트 루프가 wasm32 환경에서 실행될 수 있게 되어 웹 기반 확장성이 높아졌다. CLI에서도 세션 이름 변경 명령어와 작업 디렉토리 표시 기능이 개선되어 터미널에서의 관리 편의성이 향상되었다.

안정성 측면에서는 세션 컨텍스트 유지와 도구 호출 결과 처리에 집중했다. 리플라이 과정에서 세션 컨텍스트가 끊기지 않도록 수정했으며, OpenAI 호환 도구 이미지 출력 시 결과가 연속적으로 유지되도록 고쳤다. 또한 MCP 스트리밍 HTTP 클라이언트의 리디렉션 보안 취약점(SSRF)을 차단하고, 확장 관리자가 스스로 비활성화되는 오류를 방지하는 등 핵심적인 버그들을 해결했다.

다양한 프로바이더와의 호환성 문제도 다수 수정되었다. Bedrock의 토큰 절단 보고와 도구 호출 플러시, Ollama 모델의 사고 노력(thinking effort) 전달, Databricks v2 Claude 모델의 라우팅 문제 등이 개선되었다. 시각적 지원 기능은 모든 프로바이더에 대해 표준 카탈로그를 통해 정확히 해결되도록 수정되어, 도구 결과 이미지가 모델에 제대로 도달할 수 있게 되었다. 이번 릴리스는 전체 변경 사항 중 주요 기능과 안정성 개선을 중심으로 요약한 것이다.
