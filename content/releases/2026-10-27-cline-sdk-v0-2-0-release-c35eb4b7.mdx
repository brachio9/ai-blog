이번 업데이트에서 가장 눈에 띄는 변화는 세션 관리의 안정성이다. 기존에는 실행 중인 세션에 다시 접속할 때 기존 실행을 대체해 버리는 문제가 있었으나, 이제는 활성화된 세션에 정상적으로 다시 연결된다. 또한 연결이 끊겼을 때 모델이 추론(reasoning)만 출력한 상태라면 이를 재시도하도록 개선되어 사용자 경험이 향상되었다.

모델 요청과 관련된 성능 최적화도 포함되었다. 모델 요청의 최대 재시도 횟수가 5회에서 3회로 조정되었으며, 이는 불필요한 반복을 줄이기 위한 조치다. 더불어 AI SDK 업데이트를 통해 Kimi K3 모델의 최대 추론 성능을 지원하고, Gemini 모델의 쿼터 오류 문제를 해결하기 위해 Google Search 연동 방식을 조정했다.

대규모 프로젝트를 다루는 사용자들을 위한 성능 개선도 포함되었다. 체크포인트 차이(diff)를 읽을 때 수천 개의 Git 프로세스를 생성하던 기존 방식에서 단일 프로세스를 사용하는 방식으로 변경되어 시스템 부하를 크게 줄였다. 또한 SSH 원격 접속 시 연결 버퍼와 제한 시간을 늘려 네트워크 환경에서의 안정성을 확보했다.

이 외에도 도구 사용 시 빈 명령어를 거부하거나 PowerShell 환경에서의 백틱 이스케이프 처리 등 세부적인 프롬프트 엔지니어링과 런타임 안정성을 위한 다양한 수정 사항이 포함되었다. 이번 릴리스는 전체 업데이트 내용 중 핵심적인 안정성 개선 사항을 중심으로 구성되었다.
