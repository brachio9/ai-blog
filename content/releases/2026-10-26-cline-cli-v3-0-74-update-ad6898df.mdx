이번 업데이트에서 가장 눈에 띄는 변화는 실행 안정성이다. 이미 실행 중인 작업이 있을 때 중복 실행되는 대신 기존 작업에 연결되도록 개선되었으며, 네트워크 연결이 끊겼을 때 모델이 추론만 진행하고 멈추는 현상을 방지하기 위해 재시도 로직이 강화되었다. 또한 허브 상태 확인 시 발생하던 프리징 현상을 방지하기 위해 3초 타임아웃이 적용되었다.

모델 및 API 활용 측면에서도 중요한 변화가 있었다. Gemini API 사용 시 발생하던 쿼타 오류와 도구 누락 문제를 해결하기 위해 네이티브 Google Search 전송을 중단했다. Kimi K3 모델의 추론 설정이 최적화되었으며, 자동 압축(Auto-compaction) 기능이 컨텍스트 제한이 불분명한 모델에서 불필요하게 작동하던 문제도 수정되었다.

모델 카탈로그는 대대적인 리프레시를 거쳤다. Liquid Inference와 Munito AI가 추가되었고, 기존의 일부 모델들이 제거되었다. 특히 ClinePass의 기본 모델이 Kimi K3.1 Pro로 변경되었으며, DeepSeek V4.1 Flash 1017 등 최신 모델들이 대거 추가되거나 기본 설정으로 변경되었다.

이번 릴리즈 노트에는 많은 변경 사항이 포함되어 있으나, 위 내용은 사용자 경험에 가장 직접적인 영향을 미치는 핵심 개선 사항들이다. 전체 변경 사항은 공식 릴리즈 노트를 참조해야 한다.
