Ollama는 0.35.0 버전에서 TypeSafe의 Jev API 기반인 /v1/systemone 엔드포인트를 통해 결정 모델을 공식 지원한다. 기존 생성형 모델이 텍스트를 출력하는 것과 달리, 이 기능은 선택지, 확률, 점수를 반환한다. 이를 통해 티켓 분류나 콘텐츠 라우팅, 모델 선택 등 명확한 판단이 필요한 작업에 효율적으로 적용할 수 있다. 현재는 Bespoke Labs의 Nimble과 Together AI의 Tev1 모델이 제공되며, 사용자는 간단한 명령어로 모델을 다운로드해 바로 활용할 수 있다.

결정 모델 API는 세 가지 질문 유형을 지원한다. choice 유형은 여러 옵션 중 하나를 선택하고 각 옵션의 확률을 반환하며, noul 유형은 특정 조건이 참일 확률을 계산한다. score 유형은 정렬된 기준 세트에 대해 점수를 부여한다. 예를 들어 고객 문의 티켓의 내용을 입력하면, 해당 티켓이 '결제', '버그', '계정' 중 어떤 레이블에 속하는지 가장 높은 확률과 함께 답변을 받을 수 있다. 이는 복잡한 텍스트 분석 대신 구조화된 데이터를 빠르게 처리해야 하는 개발자에게 유용한 기능이다.

이번 릴리스는 사용자 경험과 안정성 측면에서도 개선되었다. 설정 화면이 모델 탐색을 기다리지 않고 즉시 열리도록 수정되어 초기 로딩 속도가 빨라졌다. macOS 환경에서 업데이트 메뉴와 아이콘이 시작 시점에 사용 가능한 업데이트를 제대로 반영하지 못하는 문제가 해결되었으며, MLX 모델 다운로드가 멈추는 현상도 고쳐졌다. 또한 폐기된 typical_p 파라미터를 사용할 경우 에러가 발생하던 것을 경고 로그로 처리하도록 변경하여 호환성을 높였다.

이번 요약은 주요 기능인 결정 모델 도입과 핵심 버그 수정 위주로 정리했다. Ollama 0.35.0의 전체 변경 내역은 GitHub 릴리즈 노트에서 확인할 수 있다. 결정 모델은 아직 초기 단계이므로 실제 서비스 적용 전에는 충분한 테스트가 필요하며, 제공되는 모델별 성능 차이도 고려해야 한다.
