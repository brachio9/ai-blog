개발자들은 이제 로컬에서 진행하던 작업을 Cline Cloud로 손쉽게 넘겨받아 클라우드 워크스페이스에서 이어서 할 수 있다. 이 과정에서 인터넷 연결 끊김 등으로 전송이 중단되더라도 복구 기능이 작동하며, 프롬프트와 첨부 파일, 세션 상태가 그대로 보존된다. 이는 장소에 구애받지 않고 연속적인 개발 흐름을 유지하고자 하는 사용자에게 중요한 편의성을 제공한다.

데스크톱 앱에서는 이제 로컬 환경, SSH 원격 환경, 그리고 클라우드 환경 중 하나를 선택해 사용할 수 있다. 이 기능에는 실험 단계인 실시간 음성 인터페이스와 아바타 오버레이 경험도 포함되어 있어, 다양한 형태의 상호작용을 시도해 볼 수 있는 기회를 제공한다. 사용자는 자신의 작업 환경과 선호도에 맞춰 가장 적합한 방식을 선택할 수 있게 되었다.

이 릴리스는 0.0.20 버전까지의 모든 안정화된 데스크톱 개선 사항을 포함한다. 여기에는 Windows 버전 출시, 전체 히스토리 세션 검색 기능, 예약된 작업 수정 사항, 인라인 도구 결과 이미지 표시 기능이 있으며, 최신 제공자 및 마켓플레이스 업데이트도 적용되어 있다. 이러한 기능들은 이미 안정화되어 사용자들이 신뢰할 수 있는 기반 위에서 새로운 베타 기능을 체험할 수 있도록 한다.

GitHub 온보딩 단계는 현재 'code-onboarding-github' 기능 플래그 뒤에 숨겨져 있으며 기본 설정에서는 비활성화되어 있다. 이는 아직 초기 단계의 기능이므로 사용자가 명시적으로 활성화하지 않는 한 자동으로 실행되지 않는다. 이 글은 주요 변경 사항 중 일부를 요약한 것이므로, 전체 커밋 목록이나 기여자 명세는 공식 릴리스 노트를 참조해야 한다.
