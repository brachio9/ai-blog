Cline는 공식적으로 네이티브 데스크톱 앱을 출시했다. 이 앱은 오픈 가중치 모델 작업을 위해 설계되었으며, Claude Code나 Codex에서 작업 가져오기, 예약 실행, 웹 검색 및 음성 입력 기능을 제공한다. 또한 플러그인, MCP 서버, 스킬을 위한 마켓플레이스도 함께 도입되었다. 기존 CLI 사용자는 시작 시 데스크톱 앱으로 유도하는 한 번의 알림만 표시되며, 환경 변수를 통해 이를 완전히 비활성화할 수도 있다.

플러그인 관리 방식이 허브(Hub) 중심으로 변경되어 더 직관적으로 되었다. 이제 `~/.agents/plugins/` 디렉토리의 패키지는 자동으로 발견되고 검증되며, 별도의 설정 파일 수정 없이 MCP 서버가 시작된다. 워크스페이스 내의 `.agents/plugins` 디렉토리는 의도적으로 스캔되지 않아, 저장소를 열 때 원치 않게 리포지토리 제어의 MCP 서버가 실행되는 것을 방지한다.

성능과 안정성 측면에서 큰 개선이 있었다. 스트리밍 출력 시 허브를 통한 토크스_PROXY_ 처리로 인한 지연이 제거되어 속도가 빨라졌다. 또한 대용량 워크스페이스에서 체크포인트 생성 시 모든 추적되지 않은 파일을 다시 해싱하던 문제가 해결되어, 변경되지 않은 파일은 건너뛰도록 최적화되었다. 일시적인 제공자 오류 발생 시 실행이 중단되던 대신 최대 3회까지 재시도하는 로직이 적용되어 신뢰성이 높아졌다.

다양한 버그 수정도 포함되었다. 백그라운드 프로세스가 출력 파이프를 유지하며 명령어가 멈추는 현상, 홈 디렉토리에서 `@` 멘션 사용 시 메모리 부족으로 종료되는 문제, 파일 덮어쓰기 오류, PowerShell 명령어 중복 파싱 문제 등이 해결되었다. 또한 보이지 않는 문자(BOM 등)가 포함된 API 키 저장 오류와 Claude Code 로그인 시 불필요한 API 키 요구 문제도 수정되어 사용 편의성이 개선되었다.
