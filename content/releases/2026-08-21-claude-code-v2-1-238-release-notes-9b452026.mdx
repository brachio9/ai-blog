이번 업데이트는 주로 장기 실행 세션에서의 안정성을 높이는 데 초점을 맞췄다. 가장 중요한 변경점은 서브에이전트 도구 결과가 최근 표시 창을 벗어나면 메모리에서 해제되도록 하여, 긴 대화 중 무제한으로 메모리가 증가하던 문제를 해결한 것이다. 이로 인해 장시간 코드 작업을 할 때 시스템 자원이 과도하게 소모되는 현상이 개선될 것으로 보인다.

원격 세션과 네트워크 관련 안정성도 크게 향상되었다. 원격 제어 세션이 시작될 때 실행 셸의 환경 변수를 잘못 상속받던 버그가 수정되었고, 느린 폴링 요청이나 연결 끊김으로 인해 건강한 세션이 다른 러너로 잘못 이전되던 문제도 해결했다. 또한 프록시 서버가 연결을 거부할 때 일반적인 네트워크 오류로만 표시되던 것을 명확히 구분하여 보고하도록 개선했으며, egress 프록시에 대한 인증 헤더 갱신 기능도 추가되었다.

사용자 경험 측면에서도 여러 세부 사항이 다듬어졌다. 터미널에서 백스페이스 입력이 무시되거나 커서가 숨겨지는 현상이 수정되었고, 긴 URL이나 이모지가 포함된 권한 요청 대화창의 텍스트 줄바꿈 오류가 해결되었다. 또한 Bash 명령어 실행 중 중단되었을 때 임시 파일이 남는 문제와 워크트리 격리 환경에서의 잘못된 오류 메시지 표시도 정상화되었다.

기타 설정과 기능 면에서는 프롬프트 입력 시 Ctrl+W 키 동작을 Bash 스타일로 변경할 수 있는 옵션이 추가되었으며, 플러그인 설치 시 HTTP 헤더 생성 명령어 실행에 대한 명시적 동의 절차가 도입되었다. 이 외에도 모델 캐시 경고의 불필요한 표시 문제와 원격 제어 패널에서의 작업 중지 기능 오류 등 다양한 버그 수정이 포함되어 있다.
